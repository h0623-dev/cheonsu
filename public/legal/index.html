저작권과 출처

천수에 사용된 자료의 출처와 이용허락을 안내합니다. 외부 자료별 저작권과 허락문은 원문을 함께 보존합니다.

  • 천수 자료의 권리 안내

    게임 자료와 외부 자료의 적용 범위 및 출처 관리 안내입니다.

  • 웹 구성 요소의 오픈소스 고지

    사용한 라이브러리의 저작자와 라이선스 전문입니다.

  • 웹 배포 코드에 포함된 법적 고지

    앱·웹 제작 과정에서 보존한 배포 코드의 저작권 주석입니다.

  • 안드로이드 구성 요소 안내

    안드로이드에 포함되는 라이브러리와 해당 고지의 제공 범위를 설명합니다.

  • 음악 출처와 이용허락

    FluidR3 원본 음색, MP3 샘플, 저작권·라이선스 전문과 사용 범위입니다.

  • Google 로그인 표장 고지

    로그인 표장의 공식 출처와 사용 목적입니다.
각 자료에는 해당 저작권자의 이용허락이 적용됩니다. 외부 자료의 허락을 천수 전체의 이용허락으로 확대하거나, 원저작자가 천수를 후원한다는 뜻으로 표시하지 않습니다.
