천수 Android 구성 요소 고지 안내

Safari 웹 버전은 Android 네이티브 SDK를 실행하거나 배포하지 않습니다.
이 화면의 공통 JavaScript·앱 고지와 음악·그림 출처를 함께 참고해 주세요.

Android APK를 만들 때 선택된 runtime 의존성의 고지는 이 디렉터리의
generated/NOTICES.txt와 generated/dependencies.json에 생성됩니다.
Maven 구성 요소의 이름·정확한 버전·POM, AAR/JAR의 LICENSE·NOTICE,
Google SDK에 내장된 제3자 고지, 공개 sources JAR의 권리 고지를 보존합니다.
이 두 생성 파일은 최종 APK, 해당 APK와 같은 웹 파일로 만든 서명 OTA,
해당 배포의 개발 소스 ZIP에 들어갑니다.

이 안내만 보이는 환경은 Android 생산 고지를 포함하지 않은 웹 빌드입니다.
공개 배포 APK 또는 그 버전의 개발 소스 ZIP에서 생성 고지를 확인할 수 있습니다.
Android SDK 자체 이용조건은 오픈소스 허용 라이선스와 다릅니다.
이 자료는 출처·고지 보존을 위한 것이며 모든 권리 침해 가능성이 없다는 보증이 아닙니다.

원문 보관 자료의 출처와 범위: sources.json
SDK 이용조건 현행 안내: https://developer.android.com/studio/terms
Google 제3자 고지 안내: https://developers.google.com/android/guides/opensource
