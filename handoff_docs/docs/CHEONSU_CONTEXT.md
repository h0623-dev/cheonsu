# 2. 세계관

## 세계

천수의 배경은 붕괴 직전의 동양풍 왕국입니다.

추천 세계 명칭:

```text
천령국
```

## 핵심 위협

```text
흑야
```

흑야는 세계를 잠식하는 심연의 어둠입니다.

특징:

```text
사람을 타락시킴
괴물화
감정 증폭
세계 붕괴
```

## 천수

천수는 단순한 인물이 아니라 세계를 지키는 마지막 수호의 상징입니다.

의미:

```text
하늘을 지키는 자
심연으로부터 세계를 지키는 마지막 수호
```

## 가론

```text
흑천 가론
```

현재는 마왕군 수장처럼 보이지만, 진실은 흑야를 막기 위해 스스로 타락한 과거의 천수 기사입니다.

## 핵심 주제

```text
희생
구원
동료
타락
마지막 선택
```

# 4. 주요 캐릭터

## 카일

```text
직업: 천수기사 → 천룡기사
역할: 주인공 / 보스 킬러
성격: 이상주의, 정의감, 사람을 포기하지 못함
갈등: 희생 없이 모두를 지킬 수 있는가?
상징: 푸른 불꽃
```

## 리나

```text
직업: 주술사 → 주술대사
역할: 원거리 마법 딜러 / 흑염
성격: 차가워 보이지만 속은 여림
갈등: 자신의 힘을 두려워함
성장: 파괴가 아니라 보호를 위해 마법 사용
상징: 붉은 불꽃
```

## 브람

```text
직업: 기사 → 호국기사
역할: 탱커 / 수호
성격: 현실적, 묵직함, 말보다 행동
과거: 구 천수 기사단 생존자
갈등: 이상만으로 사람을 지킬 수 없다
상징: 방패
```

## 아리아

```text
직업: 무녀 → 성무녀
역할: 힐러 / 정화
합류 예정: 4장
```

## 레온

```text

합류 예정: 5장
```

## 세라

# 7. 현재 전투 시스템

현재 구현:

```text
유닛 선택
이동
이동 1회 제한
공격
스킬
아이템
대기
적 턴
아군 턴 복귀
승리
패배
```

## 이동

- 유닛별 `move` 값 사용
- 이미 이동한 유닛은 같은 턴에 다시 이동 불가
- 이동 후 공격/스킬/대기 가능

## 공격

- 유닛별 `range` 사용
- 리나와 궁병은 사거리 2 가능
- 근접 유닛은 사거리 1

## 명중/치명

v0.13 기준:

```text
명중률 실제 적용
빗나감 가능
치명타 가능
치명타 시 피해 증가
로그에 빗나감 / 치명타 표시
```

## 상태이상

현재 구현:

```text
흑염
혈상
방어감소
```

효과:

```text
흑염: 턴 시작 HP -2
혈상: 턴 시작 HP -3
방어감소: 방어 -3 계산 반영
```
