# v0.14 반격 시스템

```text
전투에 반격 시스템을 추가해 주세요.

규칙:
- 공격받은 대상이 살아있고 공격자에게 사거리 닿으면 반격
- 반격 피해도 HP에 반영
- 반격으로 카일이 사망하면 DEFEAT
- 반격으로 적이 사망하면 EXP 지급
- 전투 예측 창에 반격 피해 표시
- 빗나감/치명타 판정은 반격에도 적용
- 기존 명중/치명/상태이상 시스템은 유지
```

테스트:

```text
카일이 도적 공격 → 도적이 살아있으면 반격
리나 원거리 공격 → 적 사거리 밖이면 반격 없음
궁병 공격 → 사거리 닿으면 반격
반격으로 적 사망 시 EXP 지급
```
