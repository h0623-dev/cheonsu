# AGENTS.md — 천수 Codex 작업 지침

이 저장소는 React + Vite 기반 모바일 세로형 SRPG 게임 **천수** 프로젝트입니다.

## 최우선 원칙

- 기존 동작을 깨지 않는다.
- 한 번에 대규모 리팩토링하지 않는다.
- 기능은 작은 단위로 구현한다.
- 모바일 세로 화면 기준 UI를 유지한다.
- `npm run build`가 통과해야 한다.
- 코드 변경 후 주요 플레이 루프를 점검한다.
- 사용자는 비개발자이므로 변경 내용은 쉽게 설명한다.
- 한국어 UI/텍스트를 유지한다.
- 긴 코드는 사용자에게 채팅으로 붙이지 말고 패치 파일/PR로 제공한다.

## 현재 기술 스택

- React
- Vite
- CSS
- LocalStorage 저장
- 향후 PWA / Capacitor 앱 포장 예정

## 작업 전 확인

작업 전 반드시 다음을 확인한다.

```text
1. 현재 브랜치 상태 확인
2. 요청 범위 확인
3. 작업 범위 밖 리팩토링 금지
4. 기존 기능 유지
```

## 작업 후 확인

작업 후 반드시 다음을 확인한다.

```bash

```

## 금지 사항

- 프로젝트 전체를 한 번에 갈아엎지 않는다.
- 임의로 영어 UI로 바꾸지 않는다.
- 모바일 세로 화면을 깨지 않는다.
- 기존 저장 데이터 복구 로직을 제거하지 않는다.
- 사용자의 의도 없이 TypeScript, Redux, 외부 상태관리 라이브러리를 도입하지 않는다.
- 불필요한 패키지를 설치하지 않는다.
- `App.jsx`가 너무 커졌다는 이유만으로 기능 작업 중 대규모 리팩토링을 하지 않는다.

## 좋은 작업 방식

좋은 작업 방식:

```text
작업 목표 1개
↓
최소 수정
↓
빌드 확인
↓
변경 내용 요약
↓
다음 작업 제안
```

## 응답 스타일

사용자는 전체 코드/패치 형태를 선호한다. Codex 결과 설명은 다음 형식으로 제공한다.

```text
무엇을 바꿨는지
어떤 파일을 수정했는지
어떻게 테스트하면 되는지
주의할 점
다음 추천 작업
```
