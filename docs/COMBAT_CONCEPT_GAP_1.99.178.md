# 전투 콘셉트와 현재 구현의 차이

2026-10-16 KST. 사용자는 **휴대폰에서는 전투가 정상 표시되지만, 보여준 전투 콘셉트의 느낌은 전혀 아니다**라고 확인했습니다. 표시 오류와 아트·연출의 완성도를 구분합니다. 이번 기록은 승인 원화와 기존 한정 재현 화면·현재 코드를 읽어 비교한 결과이며 새 게임 패치나 새 화면 검사를 뜻하지 않습니다.

- 승인 원화: [카일·리나·아리아와 거대 수호자](../public/art/combat-epic-v1/oath-battle-keyframe.png).
- 현재 게임 소스: `13de4da03815dc31772e711d1de74ff451d7769c` / 1.99.178.
- 현재 화면 근거: [실제 게임 리나 스킬의 접촉 시점](qa/1.99.178/lina-665-contact.png). 게시에 사용한 같은 정적 산출물을 로컬 Chromium151에서 실행한 기존 자료이며, 실제 휴대폰이나 실 Site를 직접 캡처한 자료는 아닙니다.

## 실제 차이

| 요소 | 승인 콘셉트 | 현재 구현 |
| --- | --- | --- |
| 시점과 구도 | 낮은 시점, 큰 대각선 돌진, 전경·중경·배경의 깊이 | 두 캐릭터를 좌우에 놓는 평면 결투 |
| 인물 | 큰 전신 동작, 갑옷·망토·머리카락의 입체감, 세 동료의 참여 | 기존 전투 포즈를 교체·이동·회전; 새 콘셉트 전신 동작 자산은 없음 |
| 보스 체급 | 거대 수호자가 화면 대부분을 차지함 | 모바일 일반 배우 폭43%, 보스49%로 원화의 체급 차이에 못 미침 |
| 배경 | 폭포·성소·폐허와 캐릭터 원근이 하나의 장면으로 이어짐 | 새 성소는50장 보스 대결만 사용; 나머지는 기존 스테이지 배경 |
| 새 원화의 사용 | 그림 전체의 구도와 질감이 기대 기준 | 기본 카일·리나·아리아의 스킬 시작 컷인에 해당 인물을 잘라 사용 |
| 타격 | 큰 화염 궤적, 접점 폭발, 잔해와 공간 전체의 반사광 | SVG 궤적·고리·접촉광과 작은 파편; 캐릭터·배경의 통합 조명 부족 |
| 전투 UI | 액션이 화면의 주인공 | 큰 상하 정보 영역과 피해 숫자가 액션보다 눈에 띔 |

근거: `src/components/CombatScene.jsx`, `src/data/combatArt.js`, `src/data/epicCombatArt.js`, `src/components/epic-combat.css`, `src/engine/animateEpicCombat.js`. 스킬 컷인은 전체 시간의2.4~17.5%에 보이고23.5%에 사라지므로62% 접촉 순간의 실제 배우 모습은 기존 아트입니다. 컷신 또는 효과 끄기에서는 지도 효과만 사용합니다.

현재 작업을 **콘셉트 수준의 전투 장면 재구축 완료**라고 표현할 수 없습니다. 실제 반영 범위는 기존 전투에 컷인·일부 배경·타격 장식을 추가한 것입니다. 사용자의 품질 지적을 미완료 개선 사항으로 보존합니다.

## 다음 재구현에서 충족할 기준

1. 카일의 준비·몸 비틀기·돌진·검격·회수 동작을 같은 인물 비례·무기·의상으로 이어지는 전용 전신 자산으로 제작합니다. 원화 확대나 피해 숫자만으로 타격을 대신하지 않습니다.
2. 실제 공격자와 적을 사용하는 낮은 시점의 구도로 구성하고, 일반 적과 거대 보스의 체급·거리·시선 차이를 표현합니다. 관련 없는 동료·적이 그려진 원화 전체를 모든 전투에 재생하지 않습니다.
3. 지형에 맞는 전경·중경·배경, 몸과 무기에 닿는 빛, 타격 지점의 섬광·불꽃·파편을 실제 접촉 시간에 연결합니다. 모바일에서 중요한 실루엣과 조작을 가리지 않습니다.
4. 개선 결과는 생성 콘셉트와 실제 게임에서 렌더링한 장면을 명확히 구분해 제시합니다. 구현·공개·사용자 기기 확인을 각각 기록하고, 기존 저장·판정·전직 외형·축소 모션과 고정 원복 기준을 유지합니다.

위 기준은 후속 작업의 범위와 완료 판단 기준입니다. 이 문서 작성만으로 새 아트·게임 코드·버전·APK·OTA가 변경되거나 후속 구현이 완료된 것은 아닙니다. 무료 FX 아군21명 비교 영상의 별도 적용 승인도 대체하지 않습니다.
