# 천수 1.99.169 · 맵 겹침 수정과 지형 움직임

2026-10-11 KST · Android versionCode 368

## 원인과 변경

실제 전장은 모듈식 지형 타일을 그리는데 바깥 스크롤 셸도 별도의 스테이지 전체 사진을 고정 배경으로 그리고 있었습니다. 드래그하면 안쪽 지도와 바깥 사진이 달라져 두 지도가 겹치거나 갈라지는 인상을 만들었습니다. 셸의 사진을 제거하고 실제 지형만 남깁니다. 전장 바깥 여백은 단색으로 표시합니다.

카메라 이동은 나무·보스 등 돌출 장식을 포함한 scrollWidth/Height를, 칸 선택은 실제 지도 크기를 사용하던 차이도 정리합니다. 이동·확대 중심·칸 선택은 테두리와 패딩을 제외한 같은 지도 크기를 기준으로 계산합니다. 화면보다 작은 전장은 가운데 정렬하며 큰 전장의 첫 열과 스크롤 범위는 유지합니다.

추가 브라우저 검사에서 31장의 마우스 드래그가 기본 이미지·텍스트 선택과 충돌해 반대 방향으로 튀는 현상을 발견했습니다. 유닛 그림에서도 지도 끌기를 시작할 수 있게 입력을 전달하고 브라우저의 기본 이미지 끌기·텍스트 선택을 막습니다. 짧은 유닛 탭은 기존 선택 동작, 터치는 기본 관성 스크롤을 유지합니다.

배경 효과는 실제 지형판 안에서만 표시합니다. 초원·숲의 적절한 칸에 작은 풀을 배치하고 야외 전장에는 천천히 흐르는 구름 그림자를 표현합니다. 전체 지도 사진을 흔들거나 복제하지 않습니다. 실내와 맞지 않는 지형에는 풀을 추가하지 않습니다. 모바일 요소 개수 제한, 효과 끄기, 시스템 동작 줄이기와 화면 숨김 시 정지를 지원합니다.

## 보존 범위

50장 캠페인의 맵 데이터·충돌·이동 가능 칸·전투 판정·저장 구조는 바꾸지 않습니다. 1.99.168의 카일 사망 패배 제외·전멸 패배·1.5배 턴 제한도 그대로입니다. 현재 저장·진행·수집 및 [1.99.165 + Safari 원복 기준](ROLLBACK_BASELINE.md)을 유지합니다.

## 검증과 공개

이번 사용자의 “전체적으로 확인해줘” 요청에 따라 해당 작업의 직접 검증을 진행합니다. 이전의 검증 생략 기본 지시를 영구 변경한 것으로 해석하지 않습니다. [검증 기록](QA_IMPROVEMENT_1.99.169.md)에 직접 실행·기존 자동 Actions·실기기 미실행 범위를 구분합니다.

직접 검사의 최초 하위 프로세스 실행은 sandbox EPERM으로 중단돼 지원되는 추가 권한 설정에서 다시 실행했습니다. 이 오류를 게임 로직 결함으로 처리하거나 검사 기준을 낮추지 않았습니다.

새 맵 정합성 검사를 기존 Cloud 및 Android 워크플로에 추가했습니다. 기존 Cloud 전체 검사 시간이 약 44분이었으므로 추가 맵 검사 시간을 확보하도록 제한을 45분에서 60분으로 늘렸습니다. 기존 검사·서명·배포 보호는 유지합니다.

현재 새 APK·서명 OTA·개발 소스 ZIP·Safari 공개 절차를 준비 중입니다. 완료 시 최종 소스·자동 실행 결과·공개 파일·채널 정보를 기록합니다. 서명키는 기존 GitHub Actions cheonsu-release 환경에 유지합니다.
