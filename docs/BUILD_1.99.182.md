# 천수 1.99.182 · B안 전체 전투 적용

**게임 원화 제작·연결 완료 / 배포 준비 중 · 2026-10-16 KST.** 게임 버전은 **1.99.182 / Android versionCode 381**입니다. 사용자가 아군 21명·일반 적 37종·보스 9종의 B안 시안 23장을 본 뒤 **“적용해줘”**라고 승인하여 새 투명 원본23장으로 **기본67종×3자세·201개** 게임용 전신 원화를 제작하고 B안 효과를 연결했습니다. 이 제작 성공은 QA 통과와 다르며, 아직 새 APK·서명 OTA·아이폰 웹 배포 완료로 표현하지 않습니다.

## 변경 범위와 보존

- 기본 캐릭터 **67종(아군 21·일반 적 37·보스 9)**의 `recover`(준비/회수)·`strike`(일반 공격 접촉)·`skill-a`(스킬 전신) **201개 512px 투명 WebP**를 제작했습니다. `characters-v2` 기존 경로에47종×3=141개, `characters-v3` 기존 경로에20종×3=60개를 연결하여 게임이 바로 사용하는 원화를 바꿨습니다. 원본 3열 검토 보드를 배경째 붙인 것이 아니라 별도 투명 원본23장의 자세를 분리합니다.
- 원본 분할 영역·자세별 손잡이/무기 끝·활 윤곽/전체 화살 축·보조 무기/발톱·몸높이는 생성 입력을 보며 수동 근사 저작했습니다. 생산기는 처음 인코딩하는 메모리의 픽셀로 실루엣·크기·발높이·프레임 바인딩 메타데이터를 함께 제작했습니다. [생산 보고서](art/style-b-v1/production-report.json)의 `outputReread:false`는 완성 WebP를 별도로 다시 읽어 검사하지 않았다는 범위를 나타냅니다.
- 큰 검격 곡선·불꽃 회오리·화살 궤적·겹치는 마법진·접점 빛과 캐릭터별 무기·속성·연출 프로필을 연결합니다. 자신의 컷인과 간결한 전투 HUD, 큰 보스의 체급을 강조합니다.
- 기존 50장 전장에 밝은 환경광과 전경·중경·배경 거리 표현을 보강합니다. 큰 부모의 3D 합성·전체 필터로 전장을 다시 가리지 않습니다.
- 전직 **65형태**는 기존 고유 의상과 무기 원화를 보존하면서 기본67종과 합쳐 **전체132형태에 공통 B안 전투 연출**을 적용합니다. 기본형의 나머지5자세(`run-a`·`run-b`·`windup`·`recoil`·`skill-b`)도 유지합니다. 기본67종의 새 원화를 전직65형태의 새 원화로 확대하여 표현하지 않습니다.
- 저장·진행도·수집·성장·장비·전직 조건·대기·대화·지도/걷기·피해·사거리·반격·행동 순서와 고정 **1.99.165 + Safari 원복 기준**을 보존합니다. `SAVE_VERSION` 표시는182로 올리지만 저장 키를 바꾸거나 초기화하지 않습니다.
- 이전 무료 FX 비교 영상은 이번 B안 승인과 별개의 자료입니다. 해당 외부 에셋을 일괄 적용하지 않습니다.
