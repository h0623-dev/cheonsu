# 1.99.163 신규 캐릭터 제작 기록

기존 아군과 같은 선명한 채색·윤곽·체형을 기준으로 신규 기본20종(동료4·일반 몬스터12·고유 보스4)과21명의 상위 전직42폼을 제작했습니다. 실제 게임 전투 원화는 총109종이며, 이 폴더의 신규62종에는 각각8개 동작과 대화·초상화가 있습니다.

원본은 `sources/<id>.png`의 투명3열3행 원화입니다. 순서는 달리기A/B·준비·타격·복귀·피격·스킬A/B·대화입니다. 원화 제작에는 이미지 생성 도구를 사용했으며, `scripts/prepare-expansion-art.cjs`는 생성 원화를 자르고 크기·발 기준선을 맞춰 WebP로 내보냅니다. 자세를 복제하거나 기존 이미지를 좌우 반전하여 새 달리기 자세로 만들지 않습니다.

동작이 잘리거나 두 다리·무기 표현이 부족한 경우 생성 도구로 다시 그린 `<id>-<pose>-correction.png`를 사용합니다. `public/art/characters-v3/manifest.json`의 `sourceCorrections`에 실제 교정 원본 경로·SHA-256·자르기 경계·크기 보정을 기록합니다. 미완성 원화를 빈칸으로 숨기지 않습니다.

기존17명과 전직폼의 마을·배치 대기는 기존 `/art/map-sprites-v4/<id>.webp`를 공유하여 현재 대기 모습을 유지합니다. 신규4명도 전직 시 기본 대기를 유지합니다. 실반의 게임 ID는 `sylvan`, 원본·파일 ID는 `silvan`이며 명시적 연결을 사용합니다. 새 동료4명의 앞/뒤 걷기4프레임은 별도 `village-walk-v2`에 있으며 기존17명의 대기·걷기 파일을 덮어쓰지 않습니다.

`prompts.json`은 인물 정체성·외형 기준을 보존하며 과거의 미구현 스킬 제안을 포함하지 않습니다. 실제 스킬·능력치는 현재 게임 소스를 기준으로 판단합니다. 무기 효과의 기존47종은 기존 실측 좌표를 유지합니다. 신규62종은 실제512px 원화의 준비·타격·기술2자세를 각각 수동 검토한 부착 좌표와 원화SHA를 `src/data/reviewedSkillWeaponAnchors.json`에 기록합니다. 손이 가려진 경우 실제 노출된 창봉·방패 등의 접점과 관찰 한계를 기록하며, 수동 근삿값을 정밀 실측으로 표시하지 않습니다. 새로운 전직 모습에 기본 모습의 무기 방향을 상속하지 않습니다.

전체 파일·알파·동작 고유성·발 정렬은 `expansion-character-art.test.mjs`, 실제 브라우저 디코딩·전투·대화 표시는 원화와 전투 연출 QA 보고서에서 확인합니다. 이 제작 기록 자체는 검사를 통과했다는 선언이 아닙니다.
