# 캐릭터별 스킬 전용 자세

1.99.147에서 아군 17명의 기본 기술 2개씩, 총 34개 전신 자세를 추가했습니다. 기존 캐릭터의 의상·무기·얼굴과 같은 회화풍을 유지하도록 기존 전투 이미지로 참조 시트를 만들었습니다. 게임에는 투명 WebP를 사용합니다.

## 원본과 제작

- 생성 도구: 이 작업의 내장 `image_gen`, `transparent_background: true`.
- `skills-1`~`skills-4-reference.png`: 기존 전투 recover 자세로 제작한 식별 참조 시트.
- `skills-1`~`skills-4.png`: 생성 도구의 원본 알파 PNG. 마지막 시트만 5행, 나머지는 4행이며 모두 2열입니다.
- 실제 알파 채널을 유지합니다. 일부 뷰어의 컬러 배경 미리보기는 숨겨진 RGB이며 배경을 그림에 합성하지 않았습니다.
- `scripts/prepare-skill-art.mjs`가 연결 성분으로 무기까지 추출하고 크기/발 기준점을 맞추며 WebP·manifest·precache를 생성합니다. 무릎을 꿇는 자세는 낮게, 머리 위 무기는 신체 크기를 줄이지 않게 별도 보정합니다. 외곽에 닿는 실루엣은 오류로 처리합니다.
- `node scripts/prepare-skill-art.mjs --refs`: 참조 시트 재생성. `npm run art:skills`: 포함된 원본에서 게임용 이미지 재생성.

## 생성 지시 기록

공통 지시: 참조 시트의 같은 행 인물 정체성·복장·무기·회화풍을 유지한 고전 판타지 SRPG 전신 스킬 자세. 2열의 서로 다른 자세, 오른쪽을 바라보는 측면 3/4 시점. 모든 발·무기·장식과 행/열 사이 여백을 보존. 진짜 투명 배경. 이펙트, 바닥, 그림자, 글자, 테두리 없이 캐릭터만. 두 자세를 같은 몸의 좌우 반전으로 만들지 말 것.

각 행은 왼쪽이 첫 기술, 오른쪽이 두 번째 기술입니다.
