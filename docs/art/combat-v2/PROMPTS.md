# Combat Motion Assets

Generated with the built-in image generation tool. Existing combat-v1 atlases were used as identity and costume references. Transparent six-pose sheets are preserved in `sources/`; derived game files are in `public/art/combat-v2`.

## Batch 1

Use case: stylized-concept. Production frame-by-frame character animation sprite sheet for CHEONSU. Use input as identity and costume reference ONLY. Genuine transparent RGBA background, no checkerboard, no text, no lines, no ground, no effects. High resolution 3072x3072 square. EXACTLY SIX COLUMNS and SIX ROWS, 36 separate full-body figures. Each ROW is one character repeated in SIX DIFFERENT anatomical poses. All face RIGHT, side-view chest-height camera, soft gouache fantasy, consistent 4-head-tall body, identical costume, face, weapon, scale and baseline throughout each row. Large clear gaps between cells; each pose including weapon contained in central 80% of cell. No touching figures, no cropped feet. Every row's six columns: (1) running stride A, left knee lifted forward/right leg extended back, weapon carried low; (2) running stride B, opposite legs and arms, visually very different leg positions; (3) attack anticipation: deep bend knees, twist torso, draw weapon back and up, or draw bowstring back / gather staff magic hand close; (4) full extension attack: forward planted step and sword/spear/knife/shield thrust or bow release / cast hand extended; (5) follow-through: weapon sweeps across down, torso rotates and weight moves to front knee, archer lowers bow/caster hand settles; (6) recoiling from hit: torso leans BACK to left, bent knees, weapon guarding chest, clear changed silhouette. Real joint changes in shoulders, elbows, knees, hips across every pose, not clones translated. No motion blur or trails. Six rows TOP TO BOTTOM are the reference's first six allies: ROW1 Kyle brown-haired young swordsman blue-teal scarf and silver shoulder plate; ROW2 Bram bearded broad green-tabard silver-armored shield knight; ROW3 Lina long red-haired green-clad female archer; ROW4 Aria long ivory-haired white-and-teal staff healer; ROW5 Leon blonde silver armored red-caped spear knight; ROW6 Sera dark-haired charcoal-and-burgundy dual-dagger woman. All six poses of each row must be that row's character. Show convincing running strides and actual weapon wind-up/swing/followthrough.
