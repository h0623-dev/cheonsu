2026-10-16 KST 사용자가 승인 전투 콘셉트와 실제 화면의 차이를 지적한 뒤, 카일·리나·아리아와 50장 수호체의 실제 전투용 새 자세 제작을 요청했습니다. 기존 컷인에 원화 일부만 표시했던 1.99.177과 구분합니다. 아군 21명 무료 FX 영상은 별도 시안이며 이 원화 제작에 포함하지 않습니다.

4종 각 8개, 총 32개 전투 WebP 산출물과 런타임 메타데이터를 제작했습니다. 수호체의 `skill-a`는 시트에서 긴 검 끝이 누락돼 단일 교정 원화를 생성하여 대체했습니다. 다음 표는 이미지 생성 출력의 출처 기록입니다.

원본 제작은 승인 콘셉트의 카일·리나·아리아를 참조하고, 수호체는 기존 백발·왕관·다섯 의식 검의 정체성을 유지하는 이미지 생성 작업입니다. 정확한 전체 호출 프롬프트·모델 세부 버전·초 단위 생성 시각은 이 문서에 복원하지 않았습니다. 외부 게임의 원화를 새로 반입하지 않았으며 이 출처 기록이 법률상 권리 보증을 뜻하지는 않습니다.

## 제작 범위

- 카일·리나·아리아: `characters-v2/units`의 기존 8개 전투 이미지 경로에 새 원화를 제작합니다.
- 첫맹세수호체 아스테르: `characters-v3/units/oath_guardian-*`의 기존 8개 전투 이미지 경로에 새 원화를 제작합니다. 흰 머리·왕관·다섯 의식 검이라는 기존 정체성을 유지합니다.
- 지도·대기·보행·초상·대화 이미지, 전직 외형과 다른 캐릭터의 이미지는 변경하지 않습니다. 피해·타입·장비·저장·성장 규칙도 이 제작기의 수정 범위가 아닙니다.

각 원본 시트는 4열 2행입니다. 위 행은 `run-a`, `run-b`, `windup`, `strike`, 아래 행은 `recover`, `recoil`, `skill-a`, `skill-b`입니다. 생성 도구가 그린 독립 자세를 분리하며 기존 자세를 변형하거나 팔다리를 합성하지 않습니다. 원본 알파를 유지하고 임의 색상 키로 배경을 지우지 않습니다.

연결 실루엣의 소유 영역은 기존 제작기와 같은 alpha 24 기준으로 구하고, 각 영역 주위 2px의 원본 낮은 알파 경계를 같은 자세에 포함합니다. 원본 RGB에 남은 갈색이 alpha 0인 경우 그 색을 불투명 배경으로 처리하지 않습니다. 원본 자체에서 무기 끝이 누락된 자세는 잘린 부분을 추정해 붙이지 않고 이미지 생성 도구가 완성한 단일 원화로 `overrides`에 지정합니다.

## 산출물 제작

`scripts/prepare-cinematic-art.mjs`는 이미 설치된 `sharp`와 기존 연결 실루엣 분리 함수를 사용합니다. 의존성을 추가하지 않습니다. `packaging.json`에 원본 경로·기술별 자세·직접 읽은 원본 시트 좌표의 무기 앵커를 기록합니다.

캐릭터별 공통 등방 배율로 자세를 줄이고 512×512 투명 캔버스에 발 기준 480으로 배치합니다. 모든 자세에서 가장 넓은 검·활·망토·부유 검의 범위를 함께 계산합니다. 런타임의 recover 기준 재확대에서도 최종 배우 캔버스의 좌우·상단 12px 여유를 지키도록 `visibleFraction`을 생성합니다. 본문을 늘이거나 포즈별 관절을 왜곡하는 방식으로 체급을 만들지 않습니다.

수호체 단일 교정 원화는 1254×1254이며 시트의 한 자세보다 해상도가 큽니다. `bodyHeights`에 시트의 recover와 교정의 왕관~발 신체 높이를 기록하여 교정 자세의 신체 배율을 맞춥니다. 검과 부유 장식까지 포함한 전체 실루엣 높이로 신체를 일괄 축소하지 않습니다. 아리아 recoil은 지팡이가 명확히 보이지 않는 방어 자세이므로 실제 이마 쪽 손을 `focus` 앵커로 사용하고 다른 자세는 지팡이의 파란 구체를 기준으로 합니다.

제작 중 메모리의 알파 경계에서 `metrics`를 계산하고, 같은 변환으로 손잡이·끝·마법 중심·활 양끝/곡선 앵커를 `manifest.units[id].anchors`에 기록합니다. 기술의 `src`, `scale`, `footOffset`도 새 프레임과 함께 기록합니다. 기존 `getCharacterArt`·`getSkillAuraAnchor`가 이 값을 사용합니다. `packaging-report.json`은 이 제작 계산의 기록이며 별도 검사를 통과했다는 보고서가 아닙니다.

```sh
node scripts/prepare-cinematic-art.mjs
```

일부 시트가 먼저 준비되면 `--only=aria`처럼 지정할 수 있습니다. 산출물 제작 이후 테스트·린트·스모크·브라우저·별도 에셋 대조는 이 제작기에서 실행하지 않습니다. 사용자 지시에 따라 수정 후 별도 검증은 실행하지 않았습니다.
