## 웹 제작과 호스팅 구성

웹 전용 진입점은 `web/index.html`, `web/main.jsx`이며, 웹 실행 화면 컴포넌트는 `web/WebGame.jsx`, 화면 대응 스타일은 `web/safari.css`입니다. 웹용 빌드 스크립트, 서비스 워커와 Railway용 정적 파일 서버도 `web/`에서 관리합니다. Sites에는 독립 웹 제작물을 정적 파일로 패키징하여 배포합니다.

제작 명령은 저장소 루트에서 실행하는 다음 명령입니다.

```sh
node web/build.mjs
```

결과는 `tmp/safari-dist`에 생성합니다. 기존 Android용 제작물과 웹 제작물의 경로를 분리합니다. 호스팅에 필요한 제작 빌드는 요청한 웹 산출물을 만드는 작업으로 수행하며, 별도의 검증용 빌드로 취급하지 않습니다.

첫 시도 `d442ba43-1a83-499f-97e6-65cf9c2e797c`는 기존 `web/**` 경로에 변경이 없다는 `no changes detected in watch paths` 사유로 `SKIPPED`됐습니다. 새 버전의 변경은 공유 게임 소스·자산에 있으므로 이 조건으로는 지정한 보스 개선 소스를 제작하지 못했습니다.
