# 1.99.156 마을 카메라 오류 수정

사용자 휴대폰에서 `Uncaught TypeError: Cannot read properties of null (reading 'firstElementChild')`와 오류 보호 모드가 표시되었습니다. 해당 DOM 접근은 `TownHub`의 카메라 위치 계산 한 곳입니다.

마을을 떠나면 지도 ref가 먼저 해제됩니다. 이미 전달 대기 중인 `ResizeObserver` 알림이 정리 전에 실행될 수 있으므로, 카메라 계산에서 지도와 자식의 존재를 확인하고 종료한 observer의 콜백을 차단합니다. 시설 이동·걷기·카메라 추적은 유지합니다.

게임 그림과 전투 규칙, 저장 형식 및 진행·수집 데이터를 바꾸지 않습니다. 적 다양화 12종은 검토 시안으로만 제공했고 이번 수정에 적용하지 않았습니다. 기본 원복 기준은 1.99.154를 유지합니다.

배포 버전은 게임 1.99.156 / Android versionCode 355입니다. 서명은 기존 GitHub Actions `cheonsu-release`에서만 수행합니다.

## 직접 실행한 검사

- 원본 1.99.155 생산 빌드에서 이탈한 마을의 크기 변경 콜백을 비동기로 전달하면 390×844 / 844×390에서 동일 `firstElementChild` 오류와 오류 보호 모드가 재현됐습니다. 단순 화면 전환·회전 40회는 재현되지 않아, 알림 전달 시점을 통제한 회귀 검사로 원인을 확인했습니다.
- 린트·단위 검사 434개·최종 웹 빌드 통과.
- 새 `verify-town-camera.mjs`: 1280×900 / 390×844 / 844×390에서 지연 콜백 각 7회(총 21회), 설정·메뉴·마을 출구 이탈과 재진입, 캐릭터 교체·시설 도착·회전 시 카메라 추적, 저장 문자열 전체 보존을 검사했습니다. 같은 검사를 Cloud Quality와 APK 배포 전에도 실행합니다.
- 기존 마을 보행 검사: 3화면 각각 13개 항목 통과. 전체 화면 스모크 검사: 3화면 통과.

위 기록은 Cloud Chromium 검사이며 실제 휴대폰 설치·재현 여부와 별개입니다. APK/OTA 배포 결과는 GitHub Actions의 최종 main 소스, 새 버전 공개 릴리스와 실제 서명 채널을 별도로 확인합니다.
