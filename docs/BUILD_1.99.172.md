# 천수 1.99.172 · 캐릭터에 맞는 무기 이름

2026-10-13 KST · Android versionCode 371

**1.99.172 / Android 371 배포 준비 중입니다.** 새 APK·서명 OTA·전체 개발 소스 ZIP의 공개가 끝난 상태가 아닙니다. 아래 1.99.171 기록과 산출물을 이번 변경의 결과로 제시하지 않습니다. Safari 웹은 기존 Railway 체험 기간 만료로 중단된 상태이며 요금제 활성화 후 같은 최종 소스의 재배포가 필요합니다.

## 변경 내용

리나가 활을 사용하는데 장비 이름이 “화염 지팡이”로 남아 있던 문제를 **“화염 활”**로 수정합니다. 전체 아군 21명의 기존 무기 이름과 현재 전투 아트 정의를 정적으로 조사하고, 여러 동료가 함께 사용하는 장비도 착용자의 무기 계열에 맞는 이름·분류·아이콘을 표시하도록 정리합니다.

기존 무기 6종과 확장 무기 계열의 표시를 함께 다룹니다. 테오의 철검은 철궁, 레온의 사냥꾼의 활은 사냥꾼의 창, 루카의 같은 장비는 사냥꾼의 검으로 표시합니다. 노아는 마법서, 미호는 부적, 엘라는 류트, 라칸은 도끼, 백호와 하린은 권갑을 사용하도록 명칭을 맞춥니다. 세라가 검 계열 장비를 착용하면 쌍검으로 표시합니다.

특정 동료를 선택한 화면에서는 그 동료의 이름을 표시하고, 착용자를 고르지 않은 전체 목록에서는 공유 장비의 이름을 `/`로 함께 표시합니다. 예를 들어 같은 기존 장비는 전체 목록에서 “철검 / 철궁”으로 보이며 카일에게는 “철검”, 테오에게는 “철궁”으로 보입니다. 새로운 장비로 복제하거나 기존 소유품을 교환하는 방식이 아닙니다.

상점·장비점·명부·전투 중 장비 표시와 획득·강화 안내가 `getGearPresentation`의 공통 표시 규칙을 사용합니다. `gameData.js`에 남은 별도 장비 정의는 공통 `equipment.js`의 재내보내기로 연결하여 화면별 이름 차이가 다시 생기지 않도록 합니다.

## 저장과 기존 규칙

장비의 저장 ID·소유 기록·강화 단계·장착 상태·수치·가격·해금 조건·착용 권한을 그대로 유지합니다. `fireStaff`, `hunterBow` 같은 과거 저장 ID도 이름을 고치기 위해 바꾸지 않습니다. 이미 소유하거나 장착한 장비는 기존 ID를 읽고 수정된 표시를 사용합니다. 방어구와 장신구의 이름·분류는 이번 무기명 수정 대상이 아닙니다.

기존 저장·진행도·수집·성장·전직 외형·전투 규칙을 유지합니다. 기본 **원복** 기준은 **1.99.165 + Safari**, 전체 소스 `5d0f52175792dcaf464fd870db3f6e7c313d9314`이며 [원복 절차](ROLLBACK_BASELINE.md)를 따릅니다. 기존 저장을 지우거나 공유 Git 이력을 강제 되돌리지 않습니다.

## 제작과 검사 구분

사용자 지시에 따라 수정 후 별도 검증은 실행하지 않았습니다. [검증 생략 스킬](../.agents/skills/cheonsu-no-post-change-validation/SKILL.md)에 따라 직접 테스트·린트·스모크·브라우저/화면 QA·검증용 빌드·아티팩트 재다운로드 대조를 실행하지 않습니다. 위 무기 분류 조사는 구현에 필요한 기존 코드·아트 정의의 정적 읽기입니다.

요청한 새 APK·서명 OTA 제작은 기존 GitHub Actions 흐름으로 진행하며 자동 Cloud Quality·Android APK and OTA의 검사·서명·배포 보호를 유지합니다. 서명키는 기존 `cheonsu-release` 환경에 유지합니다. 기존 자동 실행 결과는 실제 완료 후 직접 검사와 구분해 기록합니다. 이전 버전의 성공 결과를 이번 변경의 성공 결과로 대신하지 않습니다.
