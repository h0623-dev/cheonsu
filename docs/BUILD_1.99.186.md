# 천수 1.99.186 / Android 385 · 자동 배치와 직접 배치 선택

2026-10-18 KST. 사용자가 전장 배치 사진을 기준으로, **자동 배치를 누르면 기존 분산 진형으로 배치하고 그 외에는 직접 아군을 배치**하도록 요청했습니다. 새 전장에 들어가자마자 아군이 자동으로 채워지는 동작을 바꾸고, 자동 배치 버튼과 수동 배치를 구분합니다. 현재 소스 반영·필수 산출물 제작·공개 준비 중이며 아래 공개 결과는 아직 확정하지 않았습니다.

## 전장 진입과 직접 배치

- 새 전장에서는 `autoFill: false`인 빈 배치 초안을 시작합니다. 아직 배치하지 않은 아군은 지도에 나타나지 않으며, 보유 캐릭터 카드에서 선택한 뒤 파란 칸을 눌러 배치합니다.
- 출전 예정 명단과 실제 배치 인원을 구분합니다. 상단 인원과 카드의 배치 상태는 실제 좌표를 지정한 아군을 기준으로 표시하고, 아직 배치가 필요한 예정 동료도 안내합니다.
- 배치한 아군은 다른 파란 칸으로 이동할 수 있습니다. 이미 배치한 다른 아군의 칸을 누르면 두 아군의 위치를 교환합니다.
- 아직 배치하지 않은 예정 동료도 출전 명단에서 제외할 수 있습니다. 카일은 필수 출전이며, 아군 출전은 최대 15명입니다. 모든 예정 동료의 배치를 마쳐야 전투를 시작할 수 있습니다.
- 전체 아군 진영을 배치 가능 범위로 열지 않습니다. 기존과 같이 최대 18개의 지정 칸을 사용하며, 같은 연결 지면·안전한 지형·적과 최소 7칸 거리 조건을 유지합니다.

## 자동 배치 버튼

`자동 배치`를 누를 때만 현재 출전 예정 명단을 기존 자동 진형으로 배치합니다. 근접 전열과 원거리·회복 후열, 동료 사이의 분산, 스테이지별 진입 방향을 사용합니다. 사진의 화면 좌표를 모든 맵에 고정하지 않고 1~50장의 기존 전장 방향을 따릅니다.

자동 배치를 마친 뒤에도 사용자가 직접 아군을 이동하거나 서로 자리를 바꿀 수 있습니다. 자동 배치는 현재 배치 위치를 새로 정하는 명시적 동작이며, 다른 아군을 선택하거나 배치 화면을 다시 계산했다는 이유로 실행되지 않습니다.

## 배치 구역과 적 위치의 안정성

전장에 들어갈 때의 출전 예정 명단을 `formationIds`로 보존합니다. 해당 명단의 기준 진형에서 `stage.deploymentAnchors`와 적 좌표를 생성하여, 사용자가 동료를 추가·제외하는 동안 지정 칸이나 이미 배치한 아군의 위치가 함께 흔들리는 문제를 보완합니다.

앵커는 내부 진형 생성의 기준 좌표이며 저장 초안의 임의 좌표를 허용 칸으로 인정하는 기능이 아닙니다. 배치 엔진은 실제 안전 지형과 적 위치 조건을 계속 적용합니다. 적의 수·HP·능력·장비 등은 실제 출전 예정 명단을 사용하는 기존 생성 규칙을 유지하고, 기준 진형은 배치 구역과 적 좌표의 안정성을 위한 것입니다.

## 부분 저장과 이전 저장 호환

일부 동료만 배치한 상태도 저장하고 이어갈 수 있습니다. `autoFill: false`는 저장·복원·전투 시작 경로에 동일하게 전달하며, 비어 있는 자리에 아군을 몰래 추가하지 않습니다. 직접 배치한 유효 좌표를 먼저 보존하고, 중복·금지 지형·소유하지 않은 ID는 기존 안전 규칙으로 처리합니다.

`formationIds`는 초안 자신의 배열 필드만 읽어 안전한 캐릭터 ID를 중복 없이 최대 15개 보존합니다. 이전 저장에 새 필드가 없으면 기존 초안의 반환 형태와 자동 복구 동작을 유지합니다. 진행 중인 전투의 좌표·HP·행동 상태·저장키·진행도·수집·장비·전직과 고정 원복 기준 **1.99.165 + Safari**는 보존합니다.
