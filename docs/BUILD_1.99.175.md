# 천수 1.99.175 · 11~50장 독립 QA와 공통 오류 수정

게임 **1.99.175 / Android versionCode 374**. 직접 QA·오류 수정과 새 APK·서명 OTA·통소스 ZIP의 제작·검증·공개 배포를 완료했습니다. 실제 공개 OTA 채널의 서명과 릴리스 메타데이터도 직접 대조했습니다.

## 수정 결과

- 테오의 활 기본 공격·반격을 정확히 2칸으로 복구했습니다. 인접 1칸은 반격하지 않습니다. 루카·미호·레온·엘라의 구형 무기·기술 정보와 편성 역할을 현재 직업에 맞췄습니다. 기존 동료 저장에서도 성장·장비·HP·좌표·재사용 대기를 보존하며 복구합니다.
- 경험치 획득·레벨업·장비 재계산 후에도 공격·수호 부적 효과가 유지됩니다. 캠프·다음 전장에서는 효과와 사용 플래그를 함께 초기화합니다. 구형 장비 총합을 기본 능력치로 복구할 때 버프가 영구 성장으로 중복되지 않습니다.
- 최초 출전 명단으로 전원 생존·전선 유지·S 등급을 계산합니다. 쓰러진 동료가 전투 목록에서 제거되어도 생존 보상이 잘못 지급되지 않습니다. 살아 있는 적이 남으면 소탕 보너스를 지급하지 않습니다.
- 성공한 공격·지원 스킬의 `advancedMastery`를 보유 동료 원장에 즉시 동기화하여 사망·정산·저장 복원 후에도 전직 숙련을 보존합니다. `skillLevel`과 HP·상태는 이 동기화에서 변경하지 않습니다.
- 과거 적 턴 저장을 복원하면 저장된 전투판에서 적 행동을 재개합니다. 이미 처리된 턴 시작 상태·위험 효과를 다시 적용하지 않습니다.
- 마레의 창·실반의 마법 상성과 표시를 고정했습니다. 기본 기술·전직·장비 변경으로 검 상성에 잘못 떨어지지 않습니다.
- 전장 배치 화면의 중복 장 번호를 제거했습니다.

최신 사용자 요청에 따라 기존 결과를 승계하지 않는 독립 AI QA 팀으로 **11~50장 40/40**을 검사했습니다. **847/847 단위 테스트**, 린트, 최종 웹 빌드, 세 화면 스모크 검사가 통과했습니다. 장별 실제 UI 전투와 별도 승패 정산 저장 시나리오를 구분합니다. 보스 전체 연출 4종, 두 2페이즈 시나리오, 신규 동료 4명 실제 기술·저장·적 턴도 통과했습니다.

## 산출물과 배포

기존 GitHub Actions `cheonsu-release`에서 새 최종 소스로 APK·서명 OTA를 제작했습니다. 서명키를 이 클라우드 작업으로 가져오거나 출력하지 않았습니다. APK 인증서·버전·웹 파일 전체·OTA trust·서명·공개 다운로드를 확인했고 아래에 최종 소스 커밋·Actions 실행·릴리스·파일 해시·실제 OTA 채널을 기록합니다.

기존 저장·진행·수집·전직·성장·장비·강화를 보존하며 고정 원복 기준은 변경하지 않습니다. 실제 공개 OTA 채널은 `updates` 브랜치이며 `main/public/updates/latest.json`의 옛 포인터를 낮추거나 초기화하지 않습니다. Safari 독립 웹 호스팅을 이번 작업에서 새로 배포하지 않았습니다.
