**구현·최종 소스 준비 중 · 2026-10-16 KST.** 목표 버전은 게임 **1.99.180 / Android versionCode 379**입니다. 179의 중간 후보는 기존 자동 보호에 의해 중단돼 공개되지 않았으며 현재 공개 APK·OTA는 1.99.178입니다. 최종 게임 소스와 새 APK·서명 OTA·아이폰 웹 게시 결과는 실제 확정 후 기록합니다. 이전 버전을 이번 새 전신 아트·동작의 결과로 제시하지 않습니다.

## 요청과 실제 구현 범위

- 카일·리나·아리아·첫 맹세 수호체의 새 전신 원화 **4종×8자세·32프레임**, 실제 무기 앵커·기술 자세·크기 메타데이터를 연결합니다. 수호체 칼끝 교정과 2페이즈 기술 자세를 포함합니다.
- 11개 무기 유형의 동작, 큰 보스의 체급·질량감, 압축한 전투 UI, 50장에 연결한 8개 지형 계열·3개 장식 평면과 접점 반사광·충격파·균열을 반영합니다.
- **132형태×8자세의 실제 실루엣 경계**를 게임 데이터로 연결하여 전체 동작 트랙에서 두 유닛·무기·보스가 화면 안에 맞도록 배치를 보완합니다. 체급만 키워 무기가 대상 위치를 지나치거나 잘리는 중간 후보의 문제를 보완합니다.
- 카일 기술의 무기 효과는 실제 선택된 원화 프레임의 앵커를 사용하도록 수정합니다. 새 원화의 직접 실측·검토 카탈로그와 기존 원화 보존을 구분하고 정확한 원화·좌표·제작 근거를 연결합니다.
- 기존 전직 복장·저장·진행도·성장·장비·피해 판정·사거리·행동 순서·접촉 시계와 **1.99.165 + Safari** 원복 기준을 보존합니다. 큰 부모의 3D 변환·필터는 다시 사용하지 않습니다.

이번 변경은 새 원화·동작·구도를 실제로 연결하는 구현이며, 자동 기능 검사만으로 사용자가 기대한 시안과 같은 수준의 시각적 만족을 입증한다고 표현하지 않습니다. 이전 Windows의 검은 화면 원인·해결 미확정과 사용자 휴대폰 정상 표시 확인은 [178 기록](BUILD_1.99.178.md)으로 보존합니다.

## 179 중간 후보와의 구분

[179 기록](BUILD_1.99.179.md)의 첫 후보는 새 원화와 기존 좌표·검토 참조 불일치 3건, 후속 후보는 카일 기술의 실제 프레임·부착 앵커 불일치로 기존 자동 작업이 중단됐습니다. 179는 APK 제작 후에도 OTA·공개 발행 전에 종료됐고 릴리스 조회는 404, 실제 채널은 178을 유지했습니다. 실패 이력을 삭제하거나 179를 최종 결과로 전달하지 않습니다.

180은 중간 후보의 참조·프레임 앵커와 전체 실루엣 배치를 보완하는 상위 새 버전입니다. 기존 테스트·서명·배포 보호를 낮추거나 이전 원화로 돌려 통과시키지 않습니다. 최종 보완과 배포 소스는 실제 완료 후 별도로 기록합니다.
