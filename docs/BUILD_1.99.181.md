# 천수 1.99.181 · 전신 전투와 움직이는 접촉 평면 보완

**구현·최종 소스 준비 중 · 2026-10-16 KST.** 목표 버전은 게임 **1.99.181 / Android versionCode 380**입니다. 전신 전투 원화·보스·원근/조명과 실제 실루엣 배치를 이어받고 모든 움직이는 접점·수직 전투 평면을 보완합니다. 최종 소스와 새 APK·서명 OTA·웹 산출물은 아직 확정·공개 전입니다. 현재 공개 APK·OTA는 178, Sites 게임은 180이며 서로 다른 상태를 구분합니다.

## 반영 범위

- 카일·리나·아리아·첫 맹세 수호체 **4종×8자세·32개 새 전신 원화**, 실제 프레임·무기/화살 앵커·기술·크기 메타데이터를 포함합니다.
- 11개 무기 유형의 동작, 큰 보스의 체급·질량감, 압축 UI, 전체 50장의 8개 지형 계열·3개 장식 평면·접점 반사광·충격파·균열을 연결합니다.
- 132형태×8자세의 실제 실루엣 경계로 두 유닛과 무기를 전체 actor 트랙에 맞추는 배치를 유지하고, 움직이는 실제 접점과 대상의 수직 전투 평면을 추가 보완합니다. 라칸 무기 부착점이 대상의 세로 범위를 벗어난 180의 자동 차단을 해결하기 위한 구현입니다.
- 리나 활 윤곽·전체 화살 축과 카일의 실제 선택 프레임 무기 앵커를 보존합니다. 원화에 부착한 효과를 숨기거나 실측/검토 분류를 거짓으로 바꾸지 않습니다.
- 기존 전직 복장·저장·성장·장비·진행도·피해 판정·사거리·행동 순서·접촉 시계와 **1.99.165 + Safari** 원복 기준을 보존합니다. 큰 부모의 3D 변환·필터를 다시 사용하지 않습니다.
- 이전 아군 21명 무료 FX 비교 영상은 별도 미승인 시안으로 일괄 적용하지 않습니다.

위 범위는 통합 중이며 최종 소스에서 확정합니다. 기능 자동 통과와 사용자가 기대한 원화 수준의 시각적 만족을 동일하게 표현하지 않습니다. 이전 Windows 검은 화면 원인 미확정과 사용자 휴대폰 정상 확인은 [178 기록](BUILD_1.99.178.md)으로 보존합니다.

## 이전 후보와 배포 상태의 구분

[179](BUILD_1.99.179.md)는 좌표 카탈로그·실제 프레임 앵커 자동 차단으로 웹·APK·OTA를 공개하지 않았습니다. [180](BUILD_1.99.180.md)은 리나 활 윤곽·화살 전체 축을 보완해 스킬·50장 확장을 통과하고 Sites를 게시했으나, Android 마지막 타격 검사에서 라칸 수직 접촉 범위가 맞지 않아 APK·OTA 발행 전에 중단됐습니다.

181은 180 웹 게시 이력과 APK·OTA 미공개 상태를 보존하고 상위 버전으로 최종 보완을 전달합니다. 이전 178 APK나 180 웹을 새 181 변경 결과로 제시하지 않습니다.

## 직접 검사 생략과 기존 자동 보호

이번 새 전투 작업에 새 QA 승인은 없습니다. 이전 검은 화면 오류에 한정된 재현 허용을 이번 전투 전체 QA로 확대하지 않습니다. **사용자 지시에 따라 수정 후 별도 검증은 실행하지 않았습니다.** 단위 테스트·린트·브라우저/화면 QA·스크린샷·검증용 빌드·수동 CI·공개 APK/OTA/소스 ZIP 재다운로드·해시·인증서·RSA 서명 대조를 직접 실행하거나 다른 에이전트에 맡기지 않습니다.

필수 산출물 빌드·패키징·서명·배포는 수행합니다. 기존 **Cloud Quality**와 **Android APK and OTA**의 검사·서명·배포 보호는 유지하고, 최종 소스 main push로 자동 시작된 실행의 상태·완료/실패 로그와 공개 릴리스·채널 메타데이터만 읽어 기록합니다. 과거 검사 수치를 이번 실행 결과로 재사용하지 않고 수동 검증 CI도 시작하지 않습니다.

서명은 기존 main 전용 `cheonsu-release` 환경에서만 수행합니다. 키·장기 토큰을 Cloud·Git·ZIP으로 반출하거나 출력하지 않습니다. 실제 공개 채널은 `updates/latest.json`이며 오래된 main 포인터를 초기화·다운그레이드하거나 이미 공개된 버전을 덮어쓰지 않습니다.
