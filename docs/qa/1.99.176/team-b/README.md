# 독립 QA B팀 · 1.99.176

검사일: 2026-10-16 KST. 이번 사용자의 전체 QA 요청에 따라 새로 실행한 브라우저 검사입니다. 별도 에이전트가 기존 보고서의 통과 판정을 승계하지 않고 독립 시나리오를 수행했습니다.

현재 상태: 최종 1.99.176 번들 `/assets/index-CPjDjwM-.js`에서 전체 50장 검사를 진행 중입니다. 아래 설정·저장 검사는 완료했습니다. 최종 장별 결과는 같은 문서에 갱신합니다.

## 검사 방식

- 1~50장 각각 해당 장 직전의 QA 전용 진행 저장으로 진입합니다. 실제 전장 미션, 다음 장 잠금, 제한된 18칸 배치, 수동 배치와 저장·복원, 지도 드래그, 화면 넘침과 이미지 로딩을 확인합니다.
- 자연 전투 구간은 원래 HP·공격·방어를 유지하고 실제 이동·가능한 공격/스킬과 2회의 적 턴을 실행합니다. 이 구간의 저장·복원에서 HP·좌표·능력치·행동·상태·전투 통계를 대조합니다.
- 모든 장의 공격·스킬 UI 실행을 보장하는 별도 접촉 저장은 HP·공격·방어를 바꾸지 않고 카일·리나와 적의 좌표만 조정합니다. 카일의 일반 공격과 리나의 스킬을 실제 버튼과 대상으로 실행합니다.
- 승패와 보상 경계는 자연 전투와 구분합니다. 카일만 없는 저장에서 전투 지속, 적 대장 HP 1·인접 저장에서 실제 공격 후 승리, 정산한 전장의 중복 보상 차단, 아군 없는 저장에서 패배 후 훈련 차단·같은 장 재도전을 검사합니다. 50장에서는 51장 버튼이 없는지도 확인합니다.
- 모바일 세로 390×844, 가로 844×390, 데스크톱 1280×900을 장별로 분산합니다. 브라우저 저장은 생성한 QA 데이터만 사용하며 실제 사용자 저장을 가져오지 않습니다.
