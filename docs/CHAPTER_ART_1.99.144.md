# 1.99.144 전 장 환경 아트 확장

## 범위

1~30장 모두 새 환경 일러스트를 사용합니다. 기존에는 5종의 지역 배경을 반복했지만 이제 30종의 서로 다른 장소를 사용합니다. 1.99.143의 "타이틀 1장"은 메인 메뉴 그림 한 장을 뜻하며 스테이지 범위가 아닙니다.

아군과 같은 손그림 애니메이션풍의 윤곽선과 채색, 전투 인물이 설 수 있는 넓은 전경을 공통 기준으로 사용했습니다. 초소, 협곡, 성문, 불탄 숲, 항구, 감옥, 설원 묘역, 얼음 도서관, 성소, 천공 관문, 최종 왕좌를 각각 별도 생성했습니다. [30장 원본 및 프롬프트 목록](art/chapters-v1/README.md).

## 적용 화면

- 원정 목록: 각 장의 고유 전장 미리보기 및 장 번호.
- 출전 편성: 가로 전경 이미지 확대와 기존 상황 설명.
- 전투 전/후 대화 60장면: 해당 장의 공통 배경.
- 기록실 이야기 다시보기: 장별 경량 미리보기와 같은 대화 배경.
- 일대일 공격/스킬 연출: 해당 장의 배경.
- 실제 타일 전장의 외곽: 해당 장의 배경. 타일 위 지형은 이동 가능한 실제 맵 데이터로 계속 그립니다.
- PWA 오프라인 캐시와 APK/OTA에 60개 파일 포함.

## 보존 사항

이번 변경은 환경 원화 확장입니다. 캐릭터·보스 일러스트와 모션은 이전 개선본을 유지합니다. 모든 유닛을 다시 그린 패치는 아닙니다. 전장 타일, 장애물, 크기·배치, 공격 사거리, 행동/반격 규칙, 육성, 보상과 저장 구조도 변경하지 않습니다. 기존 전투 저장을 다시 생성하거나 초기화하지 않습니다.

## 파일 및 성능

- `src/data/worldArt.js`: 장 번호별 원화/미리보기 선택. 잘못된 번호와 과거 저장의 참조도 유효한 장으로 처리.
- `public/art/chapters-v1`: 1536×1024 WebP 30개 + 480×320 미리보기 30개, 총 13,777,506바이트.
- 목록 이미지는 지연 로드, 비동기 디코딩, 고정 크기로 화면 배치 유지.
- `scripts/prepare-chapter-art.mjs`: 원본 30개 존재 확인 후 인코딩.
- `scripts/chapter-art.test.mjs`: 30개 고유 이미지·해상도·용량·미리보기·원본 확인.
- `scripts/verify-chapter-art.mjs`: 5개 화면 크기 × 30장 출전/기록실/전투 확인, 저장 불변 검사.
- `scripts/verify-story-art.mjs`: 전체 대사에 장별 배경 연결 및 이미지 디코딩 확인.

APK는 개발용 디버그 서명입니다. 호환되는 기존 Android 335 이상 앱에는 서명된 자동 패치로 전달합니다. 실제 휴대폰 설치/OTA 적용 체감은 이 PC의 브라우저 검사와 별도입니다.
