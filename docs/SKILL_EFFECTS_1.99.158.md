# 1.99.158 스킬 효과

개발 버전은 **1.99.158 / Android versionCode 357**입니다. 이번 변경은 기존 기술의 시각 연출을 강화합니다. 새로운 기술을 만들거나 피해량·회복량·쿨다운·사거리·행동 소모를 변경하지 않습니다.

## 카일과 아군 기술

- 카일의 **돌풍 베기**는 실제 검 자세를 따라가는 불꽃 회오리와 타격 후 잔광을 표시합니다.
- 습득 기술 **여명참**은 검의 화염과 황금 여명광을 사용합니다. 기술 ID `hero-dawn-slash`와 기존 습득 조건을 유지합니다.
- **수호의 맹세**는 금빛 방벽을 표시합니다. 보호 효과와 기존 자신 대상 사용 방식은 유지합니다.
- 아군 17명의 기본 기술 34종과 습득 기술 4종, 총 **38종**에 불꽃·바람·성광·치유·방벽·번개·얼음·그림자·대지·음악·격투 계열의 충전·접촉·잔광을 연결합니다. 기술별 기존 속성과 공격 자세에 맞춰 색과 형태를 구분합니다.

## 동작과 성능

검에 붙는 효과는 캐릭터 몸체와 자세 안에서 움직이며 캐릭터의 이동·회전·공격 자세를 함께 따릅니다. 효과를 갱신하기 위해 매 프레임 화면 좌표를 재측정하거나 무한 `requestAnimationFrame` 루프를 만들지 않습니다. 타격 위치의 효과는 기존 전투 위치 계산을 사용합니다.

효과 그림은 SVG로 구성하고 유한 시간의 Web Animations API와 `transform`·`opacity`를 중심으로 재생합니다. 휴대폰에서 화면 전체의 큰 블러·필터를 계속 계산하는 방식은 사용하지 않습니다. 크기 변경 알림과 애니메이션은 화면 종료 시 정리하고, 효과 끄기와 동작 줄이기 설정을 존중합니다. 빗나감은 공격 동작을 유지하면서 명중 전용 접촉 효과를 표시하지 않도록 검사합니다.

기존 기술 계획의 `contacts`와 `releases`를 변경하지 않습니다. 스킬 장면에서 HP 표시와 결과를 전환하는 기존 `duration * .62` 시점도 유지합니다. 추가 효과가 실제 전투 결과를 다시 계산하거나 다른 시점에 적용하지 않습니다.

## 저장과 기존 콘텐츠

저장 키·저장 구조와 기존 진행도·성장·장비·수집 기록을 보존합니다. 반격 규칙과 활의 정확히 2칸 반격, 현재 캐릭터·적·보스 원화 및 마을 걷기 동작을 유지합니다. 기본 “원복” 기준은 **1.99.154 / Android353**, 커밋 `801234d1c99d0cdc7c11d645e111f64336e80672`와 태그 `codex/rollback-1.99.154`입니다. [복원 절차](ROLLBACK_BASELINE.md)를 따르며 현재 저장을 버리거나 공개 업데이트 포인터를 낮추지 않습니다.
