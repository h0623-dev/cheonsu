# 천수 1.99.165 전투 행동·경험치·도구 개선과 검증 구분

게임 1.99.165 / Android 364. 작성일: 2026-10-06 KST.

적의 소극적인 행동을 개선하고 경험치 획득량을 늘리며 전투 명령 영역을 정리하는 작업입니다. **사용자 지시에 따라 수정 후 별도 검증은 실행하지 않았습니다.** 이 문서는 구현 범위와 기존 자동 Actions의 상태를 구분하며 직접 QA 통과 보고서가 아닙니다.

## 적 행동

적은 실제로 공격할 수 있는 위치까지 지형 이동 비용이 가장 낮은 경로로 접근합니다. 벽을 우회하고 접근이 막힌 선호 표적 대신 도달 가능한 다른 아군을 선택합니다. 당장 공격할 수 있는 이동을 우선하며, 공격 가능한 적과 가까운 전열이 먼저 행동해 후열의 통로 정체를 줄입니다. 이동 전후에 공격을 먼저 고려하고 지원기는 공격할 수 없을 때 사용합니다.

궁수는 2칸 등 본래 최소·최대 사거리를 지키며, 보스도 임의의 선호 거리 대신 현재 일반 공격·스킬 사거리로 접근합니다. 적의 공격력·체력·이동력을 올리거나 금지 지형을 통과하도록 바꾸지 않습니다. 최소 힙을 사용하는 경로 탐색으로 모바일에서 탐색 비용을 줄이되 실제 기기 성능을 측정한 결과로 표현하지 않습니다.

## 경험치

앞으로 획득하는 경험치에 기존 대비 **1.6배**, 즉 **60% 증가**를 적용하고 정수로 반올림합니다. 보상이 생성되는 시점에만 늘리며 이미 저장된 경험치를 다시 곱하거나 기존 캐릭터의 레벨을 강제로 바꾸지 않습니다. 100 EXP 레벨업 기준과 기존 보상 지급·수령 여부 규칙을 유지합니다.

| 경험치 획득 경로 | 기존 → 변경 |
| --- | --- |
| 일반 적 처치 | 처치자 30 → 48, 다른 출전 아군 각각 9 → 14 |
| 보스 처치 | 처치자 50 → 80, 다른 출전 아군 각각 15 → 24 |
| 훈련 | 20 → 32, 30 → 48 |
| 탐색 수련 | 35 → 56, 60 → 96 |
| 파견 | 25 → 40, 45 → 72, 20 → 32, 30 → 48 |

공유 경험치는 기존 기본 공유량에 1.6배를 적용한 뒤 반올림하므로 일반 적의 공유 경험치는 14입니다. 반격·범위 공격·지속 피해 처치도 같은 처치 보상 경로를 사용합니다. 쓰러진 출전 아군의 공유 경험치 보존과 미출전 아군 제외 규칙도 유지합니다. 일반 공격·치유·지원·스테이지 완료 자체에 없던 별도 경험치 보상을 새로 만들지는 않습니다. 안내·실제 지급·로그·팝업에서 동일한 보상값을 사용합니다.

## 전투 도구 위치와 속도 버튼

하단 명령 영역에 있던 `미션 보기`·`저장`·속도 조절을 `정보 표시`로 여는 우측 상단 도구 영역에 배치합니다. 정보를 표시한 상태에서만 미션·저장·배속·위험 범위·탐색·설정·정보 숨김의 7개 도구가 나타납니다.

속도는 버튼 하나로 통합합니다. 버튼 문구에는 현재 **1배·2배·3배** 중 선택된 값을 한국어로 표시하며 누를 때마다 **1배 → 2배 → 3배 → 1배**로 바뀝니다. 접근성 안내에는 다음 속도 값도 제공합니다. 기존 전투 속도 상태와 저장 설정을 사용하며 전투 행동 자체를 추가로 소비하지 않습니다.
