## 발견한 문제와 반영

### P2 · 모션 축소 상태의 턴 배너와 카메라 표식

OS의 ‘모션 줄이기’를 켜도 전투 시작 직후 `turnPhaseBannerIn`과 `cameraFocusPulse`가 실행됐습니다. 주요 전투·보스·풀·구름 연출은 이미 축소 모션을 따르고 있었지만, 보조 표식의 이동·확대가 남았습니다.

`src/battle-art.css`에 축소 모션 전용 규칙을 추가했습니다. 턴 안내, 카메라 초점, 위험/공격/이동/광역 범위는 정적으로 남기고 이동·회전·확대만 제거합니다. 보통 모션 설정의 연출과 표식의 색·위험 정보는 유지합니다.

배너 1,350ms와 카메라 표식 900ms의 제거는 `App.jsx`의 예약 타이머가 담당하며 CSS `animationend`에 의존하지 않습니다. 이번 CSS 변경은 저장·전투 규칙·아트 자산을 바꾸지 않습니다. 최종 빌드에서 축소/보통 모션을 직접 비교했고, 축소에서는 애니메이션 없이 표식이 보이며 보통에서는 기존 두 애니메이션이 유지됩니다. 두 모드 모두 타이머로 표식이 제거됩니다. 이동·공격·위험·광역 장식 표식은 비어 있는 통행 가능 칸에 일시적으로 넣은 CSS 시나리오로 별도 확인했으며 전투 저장·유닛·규칙은 바꾸지 않았습니다.

### 최종 맵 카메라와 새 미션 안내

- 3장의 최종 소스 화면에서 축소/보통 모션 각각 실제 스크롤을 수행했습니다. 가로 스크롤 250→390px, 세로 0→182px로 이동해도 지도는 하나이고 타일의 지도 기준 상대 좌표는 각각 0px로 일정했습니다. 두 배경이 따로 이동하거나 중복되는 현상은 재현되지 않았습니다. 전체 50장의 장시간·모든 줌 조합을 아트 담당이 별도로 재검사했다는 뜻은 아닙니다.
- 새 미션 설명은 50장으로 320×568·390×844·844×390 세 화면에서 확인했습니다. 작은 세로/가로 화면은 본문만 44px/12px 스크롤되고, 확인 버튼은 고정된 하단에서 46px 이상의 터치 높이를 유지합니다. 설명 마지막 줄과 버튼의 겹침, 모달의 화면 이탈, 가로 넘침, 페이지 오류는 0건입니다. 세 화면에서 모두 ‘미션 확인’을 터치하여 배치로 복귀했습니다.
- 적 대장만 처치해도 승리한다는 설명, 카일이 쓰러져도 생존 아군이 있으면 계속한다는 설명과 추가 보상 목표를 승패 조건과 구분하는 안내를 확인했습니다. 턴 배너의 보조 표시도 ‘아군 행동 단계’로 표시됩니다.
