사용자가 아군 화풍에 맞춘 6종과 대기·전투 준비·타격 동작 시안을 확인한 뒤 적용을 승인했습니다. 부드러운 전술 RPG 그림체로 코볼트·도마뱀·오거·하피·해골·바위정령을 제작하고 기존 전장 슬롯에 배치합니다. 이전 검토용 1~6번 인간형 적 시안은 이번 적용에 포함하지 않습니다.

## 외형과 전투

각 종은 전진 2장·공격 준비·타격·복귀·피격·기술 2장, 대화 원화와 얼굴 초상, 전장 앞뒤 대기를 갖습니다. 무기를 들 때 인물이 작아지지 않도록 공통 크기를 유지하고 프레임의 발 위치를 실측합니다. 하피의 날개가 팔이며 사람 팔을 별도로 추가하지 않습니다. 원화와 프롬프트는 `docs/art/characters-v2`, 게임 이미지는 기존 아트 카탈로그와 새 앞뒤 대기 파일에 연결합니다. 기존 아군·적·스토리 보스 그림과 앞뒤 대기 원본 이미지 82개를 SHA-256 기준으로 보존합니다. 두 아트 카탈로그와 캐시 목록에는 기존 항목을 유지하면서 신규 6종만 추가합니다.

외형 ID `artId`는 전투 유닛 ID와 분리합니다. 석궁·창·곤봉·발톱·도끼·주먹의 준비·타격·피격과 기술 연출을 따로 선택합니다. 도감은 47종(아군 17·일반/정예 적 25·스토리 보스 5)입니다. 신규 적의 대화 초상은 외형 카탈로그에 연결하며 별도의 이야기나 새 대사를 추가하지 않습니다.

기존 전투 슬롯의 HP·공격·방어·이동·AI·최대 사거리는 유지합니다. 석궁은 기존 2칸 원거리 슬롯부터 배치하되 근접 공격/반격을 금지하고 석궁 병과·정밀 석궁으로 연결합니다. 나머지 적은 기존 병과와 기술 규칙을 유지하며 표시 이름을 바꿀 때 원래 상성 분류 이름을 별도로 보존합니다.

## 저장과 원복

새 적은 업데이트 후 새로 시작하는 전투부터 적용합니다. 재개 중인 기존 1.99.156 전투는 외형·이름을 포함한 유닛 필드를 변환하지 않고 이어갑니다. 성장·장비·골드·진행도·수집 데이터와 기존 도감의 옛 전장 해금 기록을 유지합니다. 저장 스키마를 초기화하지 않습니다.

기본 원복 기준은 1.99.154 / `801234d1c99d0cdc7c11d645e111f64336e80672`로 유지합니다. 이번 적용 전 1.99.156 소스와 APK/OTA는 Git 이력과 공개 릴리스에 보존됩니다. 강제 Git reset이나 공개 채널 버전 낮추기는 하지 않습니다.
