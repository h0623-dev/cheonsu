# 천수 1.99.173 · 전장 지형과 조사 지점의 자연스러운 표현

2026-10-14 KST · Android versionCode 372

**1.99.173 / Android 372 변경 소스 준비 중. 새 APK·서명 OTA·전체 개발 소스 ZIP은 아직 공개하지 않았습니다.** 아래 1.99.172의 공개 파일은 이전 버전이며 이번 지형 수정이 포함된 새 산출물로 안내하지 않습니다. Safari 웹은 기존 Railway 체험 기간 만료로 중단된 상태이며 같은 최종 소스의 웹 배포는 요금제 활성화 후 진행해야 합니다.

## 3장의 작은 상자가 생긴 이유

3장의 작은 상자는 전장 원화에 그려진 상자가 아니라 **요새 칸에 공통으로 추가되던 상자 소품**에서 발생한 표현입니다. 기존 `getWorldTileVisual`은 `fort` 칸에 `crates`를 항상 올리고 `gate` 칸에는 기념비를 올렸습니다. 엄폐 칸이나 일부 지역의 통행 불가 칸에도 작은 상자가 자동으로 배치되어, 실제 상호작용 보상이나 전장의 배경 구조물과 구분하기 어려웠습니다.

전장 50개의 원화 축소본을 각각 읽고 3장과 실내·지역 전장의 대표 원본을 읽었습니다. 3장 원화에는 이 작은 상자가 없으며 보급 자재가 필요한 전장의 배경은 기존 맥락을 유지합니다. 이번 작업은 게임을 실행한 후 화면 QA를 한 결과가 아니라 구현에 필요한 기존 원화·지도·렌더링 정의를 읽은 조사입니다.

## 전체 50장에 적용하는 표현 정리

- 요새·성문 칸에 항상 추가되던 상자·기념비를 제거합니다. 칸의 지형 종류와 엄폐 효과는 유지합니다.
- 낮은 잔해 엄폐 칸 위의 상자 소품을 제거하고, 해안·공방의 통행 불가 칸에 임의로 올라가던 상자를 바위로 바꿉니다.
- 눈·성채·요새·해안·공방·별빛 지역의 숲 속성 칸은 주변 지역과 같은 기본 바닥 재질을 사용합니다. 초원·숲 지역의 자연스러운 녹색 덤불 표현을 해당 지역에 한정합니다.
- 건축·실내 전장인 **12·18·25·30장**의 죽은 나무 차단 소품을 원화의 벽·기둥·바위와 어울리는 표현으로 바꿉니다. **16장 감옥 앞·21장 빙굴 도서관·40장 빙정 제단**의 눈 소나무는 벽·기둥·빙정·바위로, **34장 창고 하역장**은 벽·기둥·바위로 정리합니다. **26장 야외 숲 성소**는 살아 있는 숲 배경에 맞는 나무를 유지합니다.
- 실제 보상을 주는 발견 지점은 상자 장식과 구분되는 조사 표식으로 표시합니다. 유물은 수정, 다른 조사 지점은 기념비로 표시하고 **조사** 안내를 붙입니다.

단순 지형 칸과 실제 조사 지점은 같은 상자 그림을 사용하지 않습니다. 실제 조사 지점의 좌표·보상·발견 ID·수집 기록과 비전 전직·기술 해금은 그대로 유지합니다. 발견 표식에는 실제 이름과 “이 칸으로 이동해 조사” 안내가 표시됩니다.

전장 원화를 통째로 교체하거나 전장의 군수품·공방 시설·제단 등 맥락에 맞는 기존 배경까지 일괄 제거하지 않습니다. 나무를 모든 스테이지에서 제거하는 작업도 아니며 각 지역의 다양성과 야외 산림의 고유 분위기를 유지합니다. 새 지형 종류를 추가하거나 칸을 이동하지 않습니다. 이번 공통 표현 변경은 기존 저장으로 이어 하는 전투에도 지형·발견 상태를 읽어 반영됩니다.
