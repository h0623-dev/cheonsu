## 변경 내용

적은 실제로 공격할 수 있는 위치까지 지형 이동 비용이 가장 낮은 경로로 접근하고 벽을 우회합니다. 접근이 막힌 선호 표적 대신 도달 가능한 다른 아군을 선택하며, 공격 가능한 적과 가까운 전열이 먼저 행동해 후열의 길막을 줄입니다. 이동 전후에 공격을 우선하고 지원기는 공격할 수 없을 때 사용합니다. 궁수의 최소 사거리 2칸을 비롯한 기존 사거리와 적 능력치·이동력·금지 지형 규칙은 유지합니다. 경로 탐색에는 최소 힙을 사용해 모바일에서 반복 탐색 비용을 줄입니다.

새로 획득하는 경험치는 기존 대비 **60% 증가(1.6배)**하고 정수로 반올림합니다. 사용자 요청의 “지금보다 0.6배 올려줘”는 기존 획득량에 60%를 더하는 의미로 적용합니다. 일반 적 처치는 30 → 48, 보스는 50 → 80이며 다른 출전 아군의 공유 경험치는 각각 9 → 14, 15 → 24가 됩니다. 훈련·탐색 수련·파견 보상에도 적용하며 이미 저장된 경험치·레벨과 100 EXP 레벨업 기준은 그대로 유지합니다.

전투 하단의 `미션 보기`·`저장`·전투 속도 조절을 `정보 표시`로 여는 우측 상단 도구 영역으로 옮깁니다. 이 영역에는 미션·저장·배속·위험 범위·탐색·설정·정보 숨김의 7개 도구를 표시합니다. 속도 조절은 버튼 하나로 통합하고 현재 값을 한국어 `1배`·`2배`·`3배`로 표시하며 누를 때마다 **1배 → 2배 → 3배 → 1배** 순서로 전환합니다. 접근성 안내에는 다음에 선택할 값도 포함합니다.

컷신 뒤 실제 전장에서 수행하는 제한 칸 배치와 기존 진행 중 전투·성장·장비·진행·수집 데이터를 보존합니다. 기본 원복 기준은 [1.99.154](ROLLBACK_BASELINE.md)를 유지합니다.
