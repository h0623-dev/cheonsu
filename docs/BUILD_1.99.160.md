## 배포 절차와 보존 기준

- 예정 산출물은 `cheonsu_1.99.160_update_debug.apk`, `cheonsu_1.99.160_ota.zip`, `cheonsu_development_1.99.160.zip`입니다. 공개 다운로드 링크는 실제 배포 검증 후 안내합니다.
- APK·OTA 서명은 `main` 전용 GitHub Actions **`cheonsu-release`** 환경의 기존 Secrets로만 수행합니다. 개인 서명키와 장기 토큰을 클라우드 작업·소스·ZIP으로 복사하거나 출력하지 않습니다.
