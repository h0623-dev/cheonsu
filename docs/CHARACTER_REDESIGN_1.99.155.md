# 1.99.155 캐릭터 리디자인 및 마을 걷기

## 사용자 지정 범위

사용자가 비교 시안을 확인한 뒤 대기 모습은 현재 상태로 유지하고, 전투·대화 모습을 새 시안으로 적용하도록 요청했습니다. 아군 17종·일반 적 19종·보스 5종 전체가 대상입니다. 마을 이동은 기존 지도 캐릭터의 의상·비율을 유지한 걷기 이미지로 표현합니다.

새 기본 "원복" 대상은 이 변경 직전 배포된 **1.99.154 / Android 353 / 801234d1c99d0cdc7c11d645e111f64336e80672**입니다. 공개 보존 태그 `codex/rollback-1.99.154`를 생성했습니다. 변경 후에도 이 기준을 자동으로 갱신하지 않습니다. [복원 절차](ROLLBACK_BASELINE.md).

## 아트 연결

- 카일·브람·리나의 승인 시안과 같은 부드러운 수작업 애니메이션 화풍을 전체 캐릭터로 확장합니다. 각 캐릭터의 머리·종족·무기·역할은 구별되도록 유지합니다.
- 전투 캐릭터마다 전진 2자세·공격 준비·타격·전투 대기·피격·기술 2자세, 대화용 허리 위 이미지와 정보용 초상화를 제공합니다.
- `public/art/characters-v2/manifest.json`을 통해 일반 공격·기술·스토리·도감·보스 등장에 같은 새 정체성을 사용합니다. 기술 효과·공격 사거리·반격·피해·행동·성장 규칙은 유지합니다.
- `public/art/map-sprites-v4` 및 `public/art/directions-v1`은 원본 그대로 보존합니다. 기준 파일 86개의 SHA-256은 `docs/art/characters-v2/idle-baseline.json`에 기록합니다.
- 기존 보스 일부의 전투·대화 그림에 서로 다른 성별·헤어가 있던 경우 실제 전투의 정체성을 기준으로 새 대화까지 맞춥니다.

## 마을 이동

아군 17명마다 기존 대기 모습에 맞춘 정면/후면 2자세씩을 제공합니다. 이동하는 동안만 220ms 간격으로 발을 교대하며 좌우 방향은 반전합니다. 이동 완료·취소·시설 대화에서 원래 대기 이미지로 돌아옵니다. 전체 캐릭터 이미지를 기울이거나 뛰게 만드는 이전 CSS 흔들림은 제거합니다. 운영체제 동작 줄이기 설정을 따르고, 모바일 카메라는 이동을 부드럽게 따라갑니다. 걷기 DOM 이미지 4개를 먼저 디코딩하고 표시 클래스만 바꾸어 프레임 전환 시 빈 화면을 막습니다. 빠른 캐릭터 재선택도 새 DOM 이미지가 준비될 때까지 기존 대기로 표시합니다.

## 원화 및 추출

원본 PNG와 인물별 프롬프트는 `docs/art/characters-v2` 및 `docs/art/village-walk-v2`에 보관합니다. `scripts/prepare-character-redesign.cjs`는 독립 투명 실루엣만 추출하고 발 기준을 정규화합니다. 복제한 대기 자세를 새 동작으로 제출하지 않으며, 서로 다른 실제 생성 포즈를 사용합니다. 전투 328장·대화 41장·초상화 41장을 적용합니다. 마을 걷기는 68장을 제공합니다. 두 개 보행 프레임을 반복하는 방식이며, 8방향의 독립 원화를 만드는 방식은 아닙니다.

## 검증 및 배포

최종 린트·단위 검사·웹 빌드·3화면 클라우드 스모크 외에 전체 아트 경로/투명도/발 정렬/기술/대화/대기 원본 보존과 마을 걷기를 검사합니다. 기존 저장·진행·수집 데이터와 반격 2칸/1칸 규칙을 보존합니다. Android 354의 새 APK와 서명 OTA는 GitHub Actions에서 최종 main 소스로 제작·검증하고 공개 다운로드와 실제 업데이트 채널을 확인합니다. 실제 실행 결과는 아래에 기록합니다.

- 최종 `npm run lint`, `npm test`(434개), `npm run build`, `verify-cloud-smoke.mjs` 세 화면 검사 모두 통과했습니다. 최종 production 빌드의 마을 보행 검사도 같은 세 화면에서 각 13개씩 통과했습니다.
- 최종 웹 소스 SHA-256: `3dada5f55a258ff8cfb09776df04d7bf8d8f64d054587d90b20d9ad4dd18f1a7`.
- 전투·기술·대화 321개 브라우저 시나리오: 1280×900 / 390×844 / 844×390 전체 통과, 브라우저 오류 0개. 역병 의술사의 분리된 약병 소속을 추출 단계에서 바로잡은 후 해당 캐릭터의 15개 시나리오를 같은 세 화면에서 추가 검증했습니다.
- 마을 이동: 같은 세 화면에서 각 13개 검사 통과. 앞뒤 a/b 보행, 좌우 반전, 시설 도착·취소·대화 중 정지, 동작 줄이기, 빠른 A→B→A 캐릭터 재선택의 지연 디코딩, 기존 진행도·소지품 보존을 직접 확인했습니다.
- 전투 아트 단위 검사 6개 통과: 41종·328자세·410아트의 실제 투명도·영역·고유 해시·기술 연결과 대기 원본 86개의 SHA-256 일치.
- 별도 보스 등장 검사에서 Linux CJK 글꼴의 능력치 하단 2px 넘침을 확인하여 행 높이에 여유를 추가했습니다. 검사의 허용치는 유지하며, 보스 50개 장면·5화면 크기·이미지 대체·실제 등장·자동 종료·저장 보존 재검사가 모두 통과했습니다.
- 네이티브 지문은 기존 `e4a96c16ff95a60f9cf68440c9bf9fd72d5710729264d2464199f400a559dfc6`과 일치하며 OTA 최소 Android 버전 350을 유지합니다.

이 기록은 Cloud 브라우저 검사입니다. 실제 Android 기기의 설치·터치·OTA 적용은 포함하지 않습니다.
