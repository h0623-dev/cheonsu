# 천수 1.99.166 빌드·배포 기록

작성일: 2026-10-07 KST. 게임 버전은 **1.99.166**, Android versionCode는 **365**입니다.

**현재 상태: 전체 50장 보스 연출 개선 소스와 새 버전의 제작 준비를 반영했으며 APK·서명 OTA·Safari 웹 배포는 대기 중입니다.** 이번 최종 소스의 자동 Actions 결과와 공개 산출물이 확정되기 전에는 배포 완료로 표시하지 않습니다. 직전 공개 게임은 1.99.165 / Android 364이며 기존 APK·OTA에는 이번 보스 연출 개선이 포함되지 않습니다.

## 변경 내용

엘든 링, 옥토패스 트래블러 II, 파이어 엠블렘 인게이지, 몬스터 헌터 와일즈의 공식 소개를 조사했습니다. 보스의 소속·역할·실루엣을 드러내고 실제 전투 대응 정보를 함께 보여주는 원리를 천수의 기존 세계관과 그림체에 적용합니다. 원작 이미지·캐릭터·음원을 추출하거나 복제하지 않습니다. 출처와 설계 해석은 [보스 연출 조사](BOSS_RESEARCH_1.99.166.md)에 구분해 기록했습니다.

전체 50개 스테이지의 보스 소개를 장별 고유 부제·선전포고와 실제 기술·사거리·각성 조건·위험 안내로 바꿉니다. 기존 이름을 유지하여 미션 대상·도감·전투 로그·저장 데이터의 인물이 서로 다르게 보이지 않도록 합니다. 31~50장은 기존 종족형 지휘관과 해안·설원·공방·별빛 봉인지의 지역 보스 정체성을 유지합니다.

검은 바탕에 얼굴을 크게 확대한 카드 대신, 실제 전장 배경과 발끝·무기를 읽을 수 있는 전신 구도로 등장 장면을 구성합니다. 지휘관·빙결·불꽃·예언자·심연 계열의 새 등장 전신 5개(`commander`, `frost`, `ember`, `oracle`, `abyss`)를 추가합니다. 50장마다 전신 원화를 새로 50개 제작했다는 뜻은 아니며, 각 장의 기존 인물·종족과 새로운 구도를 연결합니다. 런타임에 사용하는 새 WebP 5개의 제작 크기는 합계 1,996,242 bytes(약 1.90 MiB), 개별 약 344~427 KB입니다. 이는 제작 산출물 정보이며 기기 로딩 속도를 측정한 결과가 아닙니다. 휴대폰 세로와 가로 화면에서 이름·대사·안내·닫기 버튼을 배치하는 구성을 나눕니다.

전장의 모든 보스에게 발밑 문양과 보스 표식을 표시하고, 보스 정보창에 현재 체력과 실제 각성 문턱을 보여줍니다. 장식 문양은 별도의 피해 범위나 능력치 증가를 뜻하지 않습니다. 기존 공격·지원 기술, 사거리, 각성 발동 조건과 위험 패턴을 기준으로 설명합니다.

등장·각성에는 저음과 상승 화음을 추가하며 기존 효과음 설정을 따릅니다. 등장 4.2초, 각성 3.4초의 안내 시간을 전투 배속과 분리하고, **전장으로** 버튼으로 닫을 수 있게 합니다. 연출이 끝나거나 닫힌 뒤 전투 흐름을 이어갑니다. 소리가 없어도 같은 이름·대사·위협 안내를 읽을 수 있습니다.

## 보존 범위와 새 원복 기준

이번 변경으로 적의 체력·공격력·레벨·경험치 보상, 맵 지형·이동 규칙, 승리·패배 미션, 저장 데이터 구조를 바꾸지 않습니다. 기존 전장 배치, 진행 중 전투, 성장·장비·진행·수집 데이터를 보존합니다. 1.99.165의 공격적인 적 AI, 경험치 1.6배, 정보 표시와 단일 배속 버튼도 유지합니다.

사용자의 2026-10-07 KST 명시적 요청에 따라 개선 전 전체 상태를 새 원복 기준으로 고정했습니다. 기준은 **1.99.165 / Android 364 + Safari 웹 지원**, 전체 소스 `5d0f52175792dcaf464fd870db3f6e7c313d9314`, 고정 보존 브랜치는 [`codex/rollback-1.99.165-safari`](https://github.com/h0623-dev/cheonsu/tree/codex/rollback-1.99.165-safari)입니다. 원복 시 현재 저장을 지우거나 과거 APK로 다운그레이드하지 않습니다. 이전 1.99.154·1.99.148의 커밋과 태그도 역사적 기준으로 보존합니다. ## 직접 실행과 자동 Actions 구분

**사용자 지시에 따라 수정 후 별도 검증은 실행하지 않았습니다.** [검증 생략 스킬](../.agents/skills/cheonsu-no-post-change-validation/SKILL.md)에 따라 에이전트가 린트·테스트·브라우저 QA·검증용 빌드·APK/OTA 재다운로드 대조를 직접 실행하거나 수동 검사 CI를 시작하지 않습니다. 요청한 산출물을 제작하기 위한 필수 빌드·패키징·서명·배포는 계속 수행합니다.

기존 자동 Actions와 서명·배포 보호 설정을 유지합니다. 자동 실행이 완료되면 그 로그와 공개 메타데이터에서 읽은 결과를 직접 검사와 구분하여 기록합니다. 실제 Android·iPhone 설치·터치·저장·오디오·성능을 직접 확인한 것으로 표현하지 않습니다. Firebase 연결·Google 로그인·Play Store 정식 출시는 이 변경에 포함되지 않습니다.

구현과 확인 범위는 [1.99.166 변경·검증 구분](QA_IMPROVEMENT_1.99.166.md)에 기록합니다.
