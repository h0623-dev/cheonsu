전투의 실제 공격자와 상대를 사용합니다. 카일·리나·아리아가 모두 그려진 원화 전체를 실제 참여 인원과 무관하게 재생하지 않습니다. 새 전신 원화는 위4명의 기본 전투 외형이며, 나머지 캐릭터와 전직 외형도 이번 공통 동작·구도·빛을 사용하되 고유 의상·무기 이미지를 유지합니다.
