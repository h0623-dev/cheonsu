# 천수 1.99.169 · 맵과 배경 효과 검증

2026-10-11 KST 사용자 요청: 맵 이동 시 사진이 겹친 듯 분리되는 현상과 지형 배경 움직임, “전체적으로 확인해줘”. 이번 범위에서 직접 검사와 브라우저 QA를 실행합니다. 이전 검증 생략 지시를 향후 모든 작업에서 해제한 것은 아닙니다.

전체 린트·단위 검사·제작과 맵 표시의 전장별 정합성, 대표 모바일·데스크톱 실제 이동·확대·회전·효과 설정·저장 불변을 확인합니다. 결과는 실행 후 기록합니다. 기존 자동 Actions의 전투·성장·배치·미션·50장·APK/OTA 검사도 유지합니다.

실제 Android·아이폰 기기 설치/플레이와 브라우저의 모바일 화면 검사를 구분하며 실행하지 않은 범위를 통과로 보고하지 않습니다. [변경·배포 기록](BUILD_1.99.169.md).

## 직접 실행 경과

- npm 캐시를 이용한 오프라인 의존성 설치와 Node 24.19.0 환경 준비를 완료했습니다.
- 최종 게임 코드의 린트와 단위 803개가 통과했고 일반 게임 및 Safari 독립 산출물 제작도 성공했습니다. 처음 제한된 sandbox의 spawnSync EPERM은 지원되는 실행 권한 설정에서 해결했습니다.
- 기본 스모크는 1280×900, 390×844, 844×390에서 타이틀·설정·도감·저장·이어하기·이미지·화면 너비·콘솔 검사를 통과했습니다.
- 현재 산출물에 이전 셸 배경 CSS와 이미지 변수만 임시 재적용한 통제 재현에서 전장 아래 별도 큰 흙길 사진과 경계가 나타났습니다. 이는 1.99.168 전체 원본을 별도 실행한 기록이 아닙니다. 복원된 현재 CSS에서는 중복 장면이 없습니다.
- 31장 마우스의 기본 이미지/텍스트 선택이 지도 이동과 충돌하는 추가 결함을 수정했습니다. 31장 PC·모바일 세로·가로 입력은 모두 통과했으며 최종 전체 지도 검사도 통과했습니다.
- 가로 화면 검사의 준비 스크롤은 CSS의 부드러운 이동 도중 좌표를 읽던 절차 문제였습니다. 검사 준비에 즉시 이동과 실제 pointerdown 좌표 대조를 적용했고 기존 드래그 판정 기준과 게임의 자동 카메라 이동은 유지했습니다.
- Safari 검사의 초기 시작화면 대기는 게임 오류가 아니라 웹 전용 “게임 시작” 버튼을 검사 절차에 포함하지 않은 원인이었고 해당 절차를 추가했습니다. Chromium에서 Safari용 산출물을 확인하는 검사이며 실제 iOS/WebKit 검사가 아닙니다.

- Safari용 산출물은 1·7·31·50장 × 1280×900/390×844/844×390의 12회 전투와 효과 설정 3회를 통과했습니다. 지도·지형 좌표, 실제 마우스/터치 드래그와 유닛 탭, 줌·회전, 저장 데이터 보존, 효과 끄기·동작 줄이기·숨김 중지를 확인했으며 브라우저 오류는 0입니다. 실제 iOS/WebKit 검사와 구분합니다.
- 넓고 낮은 2장 모바일 전장의 드래그 검사는 가용 스크롤 축을 먼저 측정하도록 보완했습니다. 세로 스크롤이 없는 화면에 세로 이동을 강제하던 검사 전제를 수정했고 실제 이동·유닛 입력·저장 불변 기준은 유지했습니다. 2장도 세 화면 모두 통과했습니다.
