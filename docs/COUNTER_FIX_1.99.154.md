# 1.99.154 반격 수정

게임 1.99.154 / Android versionCode 353 / API 36.

## 원인과 변경

`canCounter`가 일반 공격의 행동 완료(`acted`) 검사까지 공유하여, 자기 턴에 공격·스킬·대기를 마친 캐릭터가 적 턴에 반격하지 못했습니다. 반격은 별도의 턴당 1회 기회를 사용하므로 반격 모드에서만 행동 완료 검사를 제외했습니다.

- 활은 기본 공격 사거리인 정확히 2칸(대각선 합산 포함)에서 반격합니다. 1칸과 3칸에서는 반격하지 않습니다.
- 근접 캐릭터도 행동 완료와 별도로 기본 사거리에서 반격할 수 있습니다.
- 기존의 명중 후 생존한 방어자, 기본 공격 사거리, 적대 진영, 지도/지형, 턴당 반격 1회 조건을 유지합니다. 스킬 사거리로 반격 범위를 늘리지 않습니다.
- 반격 검사로 행동 완료 상태를 되돌리지 않습니다. 기존 저장·성장·수집·진행도와 네이티브 호환성을 유지합니다.

## Cloud 직접 검증

- 새 회귀 검사는 수정 전 행동을 끝낸 활의 2칸 반격에서 실패했고 수정 후 통과했습니다.
- 아군·적·보스의 행동 완료 후 반격, 2칸 대각선, 1/3칸 거절, 근접 반격, 일반 공격 재사용 금지, 상태 불변을 검사했습니다.
- `npm run lint`, `npm test`(31개 테스트 파일), `npm run build` 성공. 기존 큰 번들 안내는 남습니다.
- `verify-cloud-smoke.mjs`: 1280×900 / 390×844 / 844×390 모두 통과했습니다.
- 같은 세 화면에서 최종 production 빌드로 실제 대기→적 턴의 반격 6개 시나리오를 검증했습니다. 1칸 피격에서는 활 HP 200→188, 적 HP 9999 유지/반격 0회. 2칸 피격에서는 활 HP 200→188, 적 HP 9999→9987/반격 1회. 로그·통계와 일치하며 브라우저 오류는 없었습니다.
- 서비스워커 버전 갱신에 맞춰 오프라인 캐시 검사의 고정 구버전 캐시명을 현재 캐시명 참조로 바꿨습니다. 캐시 보존·정리 검증은 유지합니다.

## APK와 자동 패치

최종 소스의 `Android APK and OTA` Actions가 APK 인증서·버전·웹 파일 전체 및 signed OTA를 검증한 뒤 버전별 Release와 `updates` 채널을 게시합니다. 실제 성공 여부와 다운로드 파일은 [Actions](https://github.com/h0623-dev/cheonsu/actions) 및 [1.99.154 Release](https://github.com/h0623-dev/cheonsu/releases/tag/v1.99.154)에서 확인합니다. 실제 Android 기기의 설치·터치·OTA 적용은 이 Cloud 브라우저 검증에 포함되지 않습니다.
