# 천수 1.99.171 · 전직에 따라 달라지는 캐릭터 외형

2026-10-12 KST · Android versionCode 370

**배포 준비 중입니다.** 새 APK·서명 OTA·Safari는 최종 게임 소스의 제작·공개가 끝난 뒤 아래 배포 기록을 갱신합니다. 이전 1.99.170 APK를 이번 외형 변경이 포함된 결과로 안내하지 않습니다.

## 변경 내용

전직해도 기본 모습이 남던 일반·비전 전직과 지도 표시를 개선합니다. 일반 전직 **21종**, 카일의 **여명검사**와 브람의 **서약수호자** 비전 전직 **2종**에 새 복장·갑옷·어깨 장식·망토·무기 장식을 제작합니다. 색상만 바꾸는 대신 각 병과를 알아볼 수 있도록 실루엣을 바꾸며 얼굴·머리·성별·고유 무기 역할과 기존 그림체를 유지합니다.

| 전직 범위 | 이번 외형 적용 |
| --- | --- |
| 일반 전직 21종 | 전투 8자세, 대화, 초상, 지도 앞뒤 대기, 앞뒤 걷기 |
| 비전 전직 2종 | 일반 전직과 구별되는 전투·대화·초상·지도·걷기 |
| 최상위 전직 42종 | 기존 분기별 전투·대화 외형에 맞춘 지도 앞뒤 대기와 걷기 |

전투 원화는 달리기 A/B, 공격 준비, 타격, 전투 대기, 피격, 스킬 준비·발동으로 구성합니다. 전직 후 마을·전장의 대기와 보행, 대화·명부·도감의 초상, 실제 전투·스킬 모습이 현재 전직 상태를 따릅니다. 전직 화면에서 전후 외형을 미리 보고 선택할 수 있습니다.

예를 들어 라칸의 야왕은 큰 짐승 모피와 금속 허리갑, 미호의 환영도사는 비취·보라 겹도포와 부적띠, 테오의 정밀명궁은 흰 어깨망토와 정밀 장궁, 진의 용검성은 붉은 금빛 비늘갑주와 검정 하카마로 구분합니다. 장비점의 개별 착용품을 바꿀 때마다 모든 그림을 다시 바꾸는 기능과는 별개이며, 이번 외형 선택의 기준은 전직 상태입니다.

## 기존 저장과 규칙

이미 전직한 저장에도 남아 있는 전직 상태를 읽어 해당 외형을 표시합니다. 새 외형을 얻기 위해 전직을 다시 하거나 골드·인장을 추가로 소모할 필요가 없습니다. 기존 기본형 원화와 최상위 전직 전투·대화 원화는 보존합니다.

기존 저장·진행도·수집·캐릭터 성장·장착 장비·강화·전직 기록을 보존하며 전직 조건과 능력치를 이번 외형 작업 때문에 바꾸지 않습니다. 50장 캠페인, 장비 68종, 아군 전멸 패배 조건, 확대된 턴 제한과 지도 환경 효과도 유지합니다.

사용자가 별도 대상을 지정하지 않고 “원복”이라고 할 때 돌아갈 기준은 **1.99.165 + Safari**, 전체 소스 `5d0f52175792dcaf464fd870db3f6e7c313d9314`로 유지합니다. [원복 절차](ROLLBACK_BASELINE.md)를 따르며 저장을 지우거나 공유 Git 이력을 강제 되돌리지 않습니다.

## 원화 제작과 출처

이번 원화는 이미지 생성 도구에 **기존 천수 캐릭터·전직 원화**를 참조해 새로 제작했습니다. 다른 게임의 원화·스크린샷을 가져와 복사하거나 참조 입력으로 사용하지 않았습니다. 캐릭터 정체성은 기존 천수 원화로 이어받고 전직별 복장과 동작을 새로 표현합니다.

[전직 원화 제작 기록](art/promotions-v1/README.md)에 원화 배치와 분할 규칙을, `docs/art/promotions-v1/sources/`에 투명 WebP 원화를 보존합니다. 생성 PNG는 작업 공간에 남기고 제작 중 기록한 파일명·출력 경로·경계·크기 정보는 [제작 보고서](art/promotions-v1/extraction-report.json)에 보존합니다. 출처의 확인 범위는 [아트 출처 대장](legal/ASSET_PROVENANCE.md)에서 기존 조사 기록과 구분합니다. 생성 사실을 모든 유사성·권리 관계의 법률상 보증으로 표현하지 않습니다.

## 제작과 검사 구분

사용자 지시에 따라 수정 후 별도 검증은 실행하지 않았습니다. [검증 생략 스킬](../.agents/skills/cheonsu-no-post-change-validation/SKILL.md)에 따라 직접 테스트·린트·브라우저/화면 QA·검증용 빌드·아티팩트 재다운로드 대조를 하지 않습니다. 원화를 게임 파일로 분할·축소·인코딩하는 제작과 요청한 APK·OTA·Safari 산출물 제작은 진행합니다.

기존 자동 Cloud Quality·Android APK and OTA의 검사·서명·공개 보호는 유지합니다. 자동 실행 결과는 직접 검사와 구분해 기록합니다. 서명키는 기존 GitHub Actions `cheonsu-release` 환경에서만 사용합니다. 이전 버전의 [미해결 의존성 보안 경고](QA_IMPROVEMENT_1.99.169.md#별도-미해결-의존성-보안-경고)를 이번 외형 변경으로 해결했다고 표시하지 않습니다.

첫 자동 Android 실행 `38245914039`는 lint와 단위 검사 825개를 통과한 뒤 Gradle 8.11.1 배포 ZIP 다운로드의 HTTP 504로 중단됐습니다. APK·OTA는 공개되지 않았습니다. 빌드 도구는 Gradle 배포 다운로드의 일시적 500/502/503/504·읽기 시간 초과·연결 끊김에만 최대 3회 재시도하도록 보완했습니다. 컴파일·서명·권한·TLS 오류와 서명·배포 보호는 그대로 실패 처리합니다. 빌드 도구 변경도 기존 자동 APK 제작을 시작하도록 경로에 추가했습니다.

다음 자동 실행 `38246786287`(Cloud)·`38246786190`(Android)는 리나 일반 전직의 스킬 준비 자세에서 활 곡선 하단 일부가 원화에서 벗어난 것을 보고했습니다. APK 제작·APK 검사와 기본 실행·지도·마을·적군 단계는 통과했으나 OTA·릴리스 공개 전에 중단됐습니다. 해당 활 곡선을 실제 활 하단 윤곽에 맞춰 수정하며 자동 검사의 부착 기준은 유지합니다.

리나 수정 후 Cloud 자동 실행 `38248606562`는 테오 일반 전직의 화살 시작점이 활 앞쪽에 너무 가깝게 지정된 문제를 보고했습니다. 네 자세의 화살 시작점을 원화의 실제 화살 뒤쪽으로 수정했습니다. 이어진 `38249869231` 자동 실행은 테오 타격 자세의 활 하단 끝점이 빈 공간에 있는 문제를 보고하여 타격·스킬 자세의 끝점과 굴곡을 원화의 실제 활 장식 위치로 보완했습니다. 스킬 준비 자세에서 망토 끝을 활 끝으로 잘못 잡았던 좌표도 수정했습니다. 원화와 자동 검사 기준은 유지합니다.

활 좌표 보완 후 Cloud 자동 실행 `38251210276`의 스킬 연출 단계가 통과했습니다. Android 실행 `38251210362`는 PC·휴대폰 세로 스킬 검사를 통과한 뒤 검사 도구의 로컬 이미지 중계에서 `route.fetch: read ECONNRESET`으로 중단됐습니다. 기존 타격 검사와 동일하게 연결 reset만 최대 두 번 재시도하고 페이지 종료 전에 진행 중인 중계를 마치도록 보완했습니다. HTTP 오류·누락 원화·손상 이미지·게임 동작 단언은 유지하며 해당 제작 보호 스크립트 변경도 기존 자동 APK 흐름으로 이어집니다.
