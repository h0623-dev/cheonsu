# 1.99.134 전투 범위와 조작 수정

## 적용 내용

- 선택한 공격/스킬의 범위를 표시할 때 적의 위험 범위를 겹쳐 그리지 않습니다. 선택을 취소하면 기존 위험 범위 설정으로 돌아갑니다.
- 일반 공격은 붉은색, 공격 스킬은 금색 타일로 표시합니다. 범위 내 적이 있는 칸은 테두리를 강조합니다.
- 범위 표시는 실제 타일 안쪽 1px에 고정합니다. 과거 스타일의 회전, 높이, 여백과 섞이지 않도록 크기와 변형을 명시했습니다.
- 사거리는 선택한 스킬 정의를 우선하며, 0칸을 일반 무기 사거리로 대체하지 않습니다. 수호/회복 기술은 공격 사거리 타일을 그리지 않습니다.
- 광역 스킬 대상에 포인터를 올리거나 대상 버튼에 키보드 초점을 맞추면 중심 칸과 주변 피해 범위를 점선으로 표시합니다. 모바일에서 대상을 눌러 예측창을 연 뒤에도 같은 범위가 표시됩니다.
- 광역 표시와 실제 대상 판정은 같은 맨해튼 거리 계산과 막힌 지형 제외 규칙을 사용합니다. 아군은 광역 공격 피해 대상에서 제외합니다.
- 정보 숨김에 화면 맞춤/확대/축소 버튼도 포함했습니다. 정보 표시로 복원해도 선택한 배율은 유지됩니다.
- 자동 연계공격의 후보 계산, 추가 피해, 컷신, 전투 예측 수치, 동료 행동 소모 및 협공 상태 표기를 제거했습니다. 궁수가 공격해도 주변 검사는 대기 상태를 유지합니다.
- 반격, 광역 스킬, 기존 지원 관계와 포위 보너스는 유지합니다. 이전 저장의 협공 누적 기록은 호환성을 위해 삭제하지 않습니다.

## 관련 파일

- `src/engine/movement.js`: 공통 사거리/반경 타일 계산.
- `src/App.jsx`: 표시 상태, 광역 대상, 자동 연계공격 제거, 정보 숨김.
- `src/world-art.css`, `src/battle-controls.css`: 범위 타일 및 사거리 상태 표시.
- `scripts/targeting.test.mjs`, `scripts/verify-battle-controls.cjs`: 계산과 브라우저 회귀 검사.

기존 저장 키와 데이터 구조는 그대로입니다. APK 빌드 결과와 검사 범위는 `BUILD_1.99.134.md`에 기록합니다. 이번 작업은 로컬 수정이며 GitHub에 자동 게시하지 않았습니다.
