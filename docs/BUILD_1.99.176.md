## 이번 작업의 범위

- 별도 관점의 AI QA 2개 팀이 전체 50장과 공통 시스템을 점검하고 결과를 교차 확인합니다. 실제 외부 인력을 채용한 것으로 표현하지 않습니다.
- 기획·아트·개발 역할이 재현된 결함과 흐름·가독성 보완을 함께 검토합니다. 기존 저장·진행·수집·성장·전직·장비를 보존합니다.

- 결과 기획안·진행안·문제 목록은 확인 근거, 실제 반영, 미완료·다음 단계가 구분되도록 작성합니다.

## 실제 반영

- 불완전한 JSON을 정상 여정으로 오인해 기존 저장을 덮는 문제를 막았습니다. 메뉴·요약·이어하기·수동 슬롯·자동/이전 백업·가져오기에 같은 최소 구조 검사를 적용하고, 손상된 입력은 쓰기 전에 거절합니다. 유효한 구형 저장과 가져오기 전 기존 기본 저장을 보존합니다.
- 완료 장 목록이 없는 초기 구형 저장도 타이틀에서 오류 없이 `0/50장 완료`로 표시하도록 보완했습니다. 저장 원문과 기존 완료 장 목록이 있는 저장의 표시는 유지합니다.
- 과거 적 턴 저장을 이어갈 때 이미 행동을 마친 지원형 적이 다시 지원하는 문제를 수정했습니다. 다음 라운드에는 기존 초기화에 따라 정상 행동합니다. 아군 반격으로 적을 격파하면 부대·개인 격파 통계도 한 번 기록합니다.
- 승리 정산에서 누락된 밸런스 프리셋을 기본·추가 목표 골드에 전달했습니다. 난이도·프리셋은 한 번만 적용하고 이미 획득한 전리품은 별도로 보존합니다.
- 49장의 이동력 1 잉크덩굴이 비용 2 여울에 갇히는 문제를 수정했습니다. 해당 확장 적 종족의 여울 비용만 1로 바꾸며 이동력·좌표·지도·아군·다른 적과 지형 비용은 유지합니다.
- 설정의 진행도 복구 선택을 실제 캠페인 길이에 연결해 0~50장을 지원합니다. 동료·장비·골드·대기실 선택·수집을 보존하고 복구 전 최초 원본 백업과 되돌리기를 유지합니다.
- 추천 편성·브리핑·보급 추천을 공통 주요 보스 기준에 연결해 확장 35·40·45·50장까지 총 9개 보스 장을 안내합니다. 미션과 추가 보상을 구분하고 실제 카일 HP 조건을 ‘지휘관 엄호’로 표시합니다. 15인 편성 기준 예상, 5/10레벨 전직, 신규 합류 70% 성장과 패배 훈련 차단 안내도 보완했습니다.
- 턴 안내를 한국어로 정리했습니다. OS ‘모션 줄이기’에서는 턴 배너·카메라 초점·이동/공격/광역/위험 장식의 이동·회전·확대만 줄이고 위험 정보와 표시 시간은 유지합니다. 작은 화면의 미션 본문은 스크롤하고 확인 버튼은 하단에 유지합니다.

## 최종 APK·서명 OTA 제작 계약

최종 게임 소스와 버전을 `main`에 반영하면 기존 **Android APK and OTA** 워크플로가 실행됩니다. `cheonsu-release` 환경은 `main`만 사용하며 서명키·장기 토큰을 클라우드 작업으로 가져오거나 출력하지 않습니다. 공개 버전은 덮어쓰지 않습니다.

기존 자동 경로는 새 버전 불변성 확인 → 린트·단위 검사 → 기존 서명 정체성으로 fresh APK 제작 → APK 인증서·버전·내장 웹 파일 전체·OTA trust 확인 → 화면 QA → signed OTA 제작·APK/OTA 전체 파일 대조 → 통소스 ZIP → 로컬 파일 전체 SHA와 공개 asset digest·size·state 대조 및 APK·OTA 공개 HEAD 확인 → `updates/latest.json` 전환입니다. 이 보호와 실패 시 중단 조건은 유지합니다. 공개 파일 바이트를 별도로 전체 재다운로드한 결과는 실제 실행한 경우에만 직접 검사로 기록합니다.
