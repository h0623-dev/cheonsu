# 천수 1.99.132 패치

## 전투와 클리어
- 자기 턴의 일반 공격/공격 스킬/협공은 행동 1회를 공유합니다. 협공도 명중 여부와 관계없이 행동을 사용합니다. 반격은 적 턴에 별도로 유닛당 1회 가능합니다.
- 실행 중 중복 입력 차단, 최신 유닛 상태 확인, EXP 획득 및 저장 후에도 행동 완료 유지.
- 스테이지의 보스를 처치하면 일반 적이 남아 있어도 승리합니다. 여러 보스가 있으면 모두 처치해야 합니다. 보스 없는 전장은 적 전멸, 카일 사망 시 패배가 우선입니다.
- 직접 공격/광역 기술/협공/반격/턴 시작 상태 피해와 저장 복원 경로를 반영합니다.
- 승리창 폭은 최대 380px. 상세 항목은 접고, 화면 하단 이동 버튼은 항상 접근할 수 있습니다.
- 다음 스테이지 출전 편성, 상점, 대기실로 이동하며 최초 보상/새 동료/해금은 한 번만 정산합니다. 이미 클리어한 장의 재전투는 기존 무보상 규칙을 유지합니다.

## 이미지와 지형
- 일반 적과 구별되는 지휘관/서리 여왕/잿불 군주/대사제/심연 군주 5종, 30자세와 5초상화. 이름/속성에 맞춰 자동 선택합니다.
- 맵 유닛 41종의 실제 실루엣 높이와 발 위치를 정규화했습니다. 인간형은 400px 높이, 448px 발 기준선. 늑대는 네발 체형의 낮은 높이를 유지합니다.
- 전투 컷신도 대기 자세 기준 높이를 맞추고, 동일한 보정 비율을 모든 동작에 적용합니다.
- 장별 갈림길/쌍둑 여울/굽이 고갯길/숲속 우회로/성문 회랑/중앙 요새의 여섯 경로를 사용합니다. ACT별 숲·요새·설원·심연 재질과 좌우 변형이 적용됩니다.
- 실제 표시 타일과 이동 가능 지형은 같은 데이터를 사용하며 경로와 양측 배치 구역이 연결됩니다.
- 진행 중 저장에 담긴 기존 맵과 위치는 유지하고, 다음 전투부터 새 지형을 사용합니다. 기존 숨겨진 보물/기술/전직 진행도도 유지합니다.
- 생성 원본/프롬프트/추출 절차: `docs/art/bosses-v1/GENERATION.md`.

## 속도와 사운드
- 기본 전장 확대 130%, 기본 2배속. 이전 기본 1배속 설정은 최초 한 번 2배속으로 전환합니다. 이후 사용자가 고른 1/2/3배속은 유지됩니다.
- 전장/대기실/월드에 서로 다른 반복 합성 BGM을 적용했습니다. 짧은 진입 효과음만 나오던 방식을 교체했습니다.
- 전용 발소리, 활/찌르기/중병기/번개/신성 효과음. 컷신에서 타격 시점에 재생하며 컷신을 꺼도 공격/스킬 소리는 나옵니다.
- 전체 음량 0에서 오디오 오류 방지, 음악 OFF 및 전체 사운드 OFF 즉시 정지, 숨김 시 음악 정지와 복귀 재생, 완료된 오디오 노드 정리.

## 저장 호환
- 저장된 전투 유닛 목록이 있으면 이를 기준으로 복원합니다. 처치된 적/보스나 미출전 아군을 초기 명단에서 되살리던 문제를 수정했습니다.
- 저장 키와 기존 데이터 형식은 유지합니다. 파일 삭제/저장 초기화/외부 업로드는 하지 않았습니다.
