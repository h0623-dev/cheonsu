# 1.99.162 미션 진입 안내와 QA 상태

기록일: 2026-10-05. 대상 버전 **1.99.162 / Android361**입니다.

## 구현 동작

1. 출전 배치 준비에 현재 전장의 승리·패배 미션 조건과 실제 보스명을 계속 표시합니다.
2. 새 전투 진입 시 미션 창을 자동으로 열고 확인 뒤 기존 전장 시작·보스 등장 연출을 진행합니다. 미션을 반복 확인해도 시작 연출을 중복 실행하지 않습니다.
3. 전투 중 `미션 보기`로 다시 확인할 수 있으며 확인 버튼이나Esc로 닫습니다. 안내 확인·닫기는 턴·행동을 소모하거나 보상을 정산하지 않습니다.
4. 기존 전투 이어하기에는 미션 창을 자동으로 열지 않으며 수동으로 확인할 수 있습니다. 저장된 유닛·능력치·좌표·행동과 라운드를 보존합니다.

승리·패배의 여러 조건 중 하나라도 충족하면 해당 결과로 처리된다는 점을 실제 판정에 맞춰 안내합니다. 제한 라운드는 해당 라운드의 아군 턴 종료까지 승리하지 못한 경우라는 시점을 명시합니다. 전투HUD의 승리 미션 표기도 실제 조건에 맞췄습니다. 패배 목록은 배치 카드와 미션 창에서 확인합니다. 저장·진행·훈련·적 능력치와 레벨·수동 배치·원복 기준을 새 안내 때문에 재작성하거나 초기화하지 않습니다. 전투 화면에서 후퇴하면 예약된 미션·보스·시작 턴 연출도 정리합니다.
