## 기본 모습과 전직 전후를 한눈에

현재 **천수 1.99.170**에 들어 있는 모습입니다. 새 시안이나 미적용 아트를 섞지 않았습니다.

**합본 27장에 396개 장면을 모두 담았습니다.** 각 행은 하나의 상태이며 왼쪽부터 **대기 / 전투 / 대표 스킬** 순서입니다. 휴대폰에서는 이미지를 눌러 크게 연 뒤 확대하세요.

- **대기 모습**: 현재 전술지도 대기 아트와 전투 대기 아트를 나란히 확대한 비교 도판입니다. 아군은 마을에서도 같은 대기 모습을 사용합니다.
- **전투·스킬 모습**: 현재 게임의 전투 컴포넌트에서 대표 장면을 촬영했습니다. 스킬은 대표 1종의 한 순간이며 전체 애니메이션은 아닙니다.
- **일반 전직 21종·비전 전직 2종은 현재 기본과 같은 외형입니다.** 능력치·기술이 달라집니다.
- **최상위 전직 42종은 전투 외형이 달라집니다.** 지도·마을 대기 모습은 모든 전직에서 기본 외형을 유지합니다.
- 적·보스에는 아군식 전직이 없습니다. 보스의 2페이즈는 같은 몸체에 효과·표시·공격 패턴이 달라집니다.

게임 소스·저장·APK·OTA는 변경하지 않은 열람 자료입니다.

## 외형을 해석하는 기준

- 대기 모습은 현재 지도·마을 스프라이트입니다. 모든 전직에서 같은 기본 대기 모습을 사용합니다.
- 일반 전직 21종과 비전 전직 2종은 현재 별도 외형이 없습니다. 전후 이미지가 같은 것은 실제 구현을 그대로 보여주는 것입니다.
- 최상위 전직 42종은 전투·대화·초상 외형이 변경됩니다.
- 일반→비전→최상위가 하나의 필수 직선 경로는 아닙니다. 비전은 카일·브람만 가능하며 최상위와 함께 유지될 수 있습니다. 외형 선택은 최상위가 우선합니다.
- 전투 화면은 장비 종류로 외형을 바꾸지 않습니다.
- 적37종·보스전용9종은 독립 외형 기준입니다. 스테이지별 대장50명은 같은 몸체 외형을 여러 장에서 공유할 수 있습니다.
- 스킬 그림은 단일 포즈에 게임의 이동·입자·검광·카메라 연출이 합쳐집니다. 이미지 한 장만으로 전체 애니메이션이 표현되지는 않습니다.

스킬 사용 이미지는 대표 기술 1종을 보여줍니다. 배운 모든 기술의 전체 동작을 나열한 동영상 자료는 아닙니다.
