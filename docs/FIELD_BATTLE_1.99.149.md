# 1.99.149 전장 전투 연출

이 문서는 과거 구현 기록입니다. 사용자 요청으로 1.99.150에서 1.99.148로 원복하여 아래 전장 연출은 현재 게임에 적용되지 않습니다. 코드는 `v1.99.149` Git 이력과 릴리스에 보존합니다.

## 방향과 적용 범위

참고: [창세기전3 Part1 살라딘-천지파열무](https://www.youtube.com/shorts/AvZcUwc3KgY).
영상의 전장 위 시전, 집중 충전, 강한 타격과 잔류 효과를 참고했습니다. 원작 영상·음원·이미지를 게임에 복사하지 않았습니다.

- 기존 좌우 2인 대결 창을 실제 맵과 유닛 좌표를 등각으로 투영한 전체 화면 전투로 교체했습니다.
- 아군 17종, 일반 적 19종, 보스 5종 모두 공통 렌더 경로를 사용합니다. 맵은 30장별 현재 타일과 환경을 사용하며 주변 출전 유닛도 표시합니다.
- 달리기 교대 자세, 발디딤, 무기 준비, 타격, 피격·회피, 처치 후 사라짐, 원위치 복귀를 연결합니다. 공격 중 그리는 이동은 연출용이며 실제 타일 좌표를 바꾸지 않습니다.
- 기본 공격 11개 무기 유형과 아군 기본·습득 기술 38개, 적/보스 24종 기술 계획을 재사용하면서 동선·카메라·효과를 전장 좌표계로 새로 그립니다.
- 검격 궤적, 창 찌르기, 화살 발사/탄착, 포탄 포물선, 채찍/발톱, 약병, 화염 기둥, 얼음, 연쇄 번개, 대지 균열, 잔상, 음파, 회복 광선과 보호 방벽을 분리했습니다.
- 범위 피해/회복/보호는 실제 대상 위치에 표시하고 화면은 시전자와 모든 대상이 들어오도록 맞춥니다. 양측 반격도 동일 경로입니다.
- 1/2/3배속, 효과 끄기, 화면 흔들림 끄기, 시스템 저동작 설정을 유지합니다. 정적 지형은 한 번 그려 캐시하고 이미지 캐시는 96개로 제한했습니다.
- 별도의 3D 모델·스켈레톤 모션으로 바꾼 것은 아닙니다. 기존 비트맵 6자세와 스킬 전용 34자세를 활용하는 Canvas 2D 전투입니다. 이동/명령을 하는 원래 전장은 기존 시점을 유지합니다.

## 보존

피해, 정확한 사거리, 반격 제한, 턴, 기술 비용/쿨다운, 성장/장비/해금/저장 구조는 바꾸지 않았습니다. 전체 훈련, 처치 100%/30% 경험치, 자신 전용 보호 즉시 시전도 유지합니다.

이 작업 시작 전 버전은 [고정 원복 기준](ROLLBACK_BASELINE.md)으로 보관합니다. 사용자가 별도 버전 없이 "원복"이라고 하면 1.99.148을 기준으로 새 상위 버전 APK/OTA를 만듭니다. 사용자 세이브를 과거 시점으로 되돌리는 뜻은 아닙니다.

## 구현과 검사

- `src/components/FieldBattleScene.jsx`, `field-battle.css`: 장면 수명, 상태/체력 표시, 안전 영역.
- `src/engine/fieldBattlePlan.js`: 등각 좌표·동선·카메라·반응 계산.
- `fieldBattleAssets.js`, `fieldBattleRenderer.js`: 사전 로딩, 지형 캐시, 깊이 순서와 전장 효과.
- `scripts/field-battle.test.mjs`: 전 유닛/기술, 복귀, 좌표, 화면 경계, 투사체 발사 시점과 상태 불변성.
- `npm run test:field`: 실제 컴포넌트의 Canvas 픽셀, 자세 변화, 전 유닛 이미지, 모바일 화면, 배속, 저동작/정리 검사.
- 최종 결과와 실기기 미검증 범위는 `BUILD_1.99.149.md`를 참조합니다.
