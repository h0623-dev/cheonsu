# 1.99.139 사거리와 장비점

## 전투 규칙

- 일반 공격의 숫자 하나는 정확한 맨해튼 거리입니다. 사거리 2는 상하좌우 2칸 또는 대각선 1+1칸이며 바로 앞 1칸은 제외됩니다.
- 여러 거리를 허용하는 공격은 `minRange`와 `range`를 함께 선언하고 `2~3칸`처럼 표시합니다. 기존 저장의 사거리 수치를 변경하거나 보너스를 누적하지 않습니다.
- 스킬은 자신의 범위를 사용합니다. 리나/테오의 화살과 리나의 불사조 비전은 최소 2칸. 마법과 찌르기 등은 명시한 1~최대 거리이며 회복/수호의 아군 선택·자기 자신 대상 규칙은 유지합니다.
- `movement.js`가 범위 타일, 대상 판정, 반격, 거리 표시를 담당합니다. 실행 직전 아군·적 모두 실제 좌표를 다시 확인합니다.
- 반격은 방어자의 일반 공격 사거리만 사용합니다. 공격 스킬의 긴 사거리가 반격에 전용되지 않습니다. 기존 반격 1회/행동 제한 유지.
- 적은 자신의 사거리에 맞는 위치를 찾으며 스킬이 닿지 않으면 가능한 일반 공격을 선택합니다. 이동 불가인 적을 강제로 한 칸 움직이던 보정 제거.
- 광역 스킬의 중심 대상 사거리와 중심 주위 파급 범위는 별개입니다. 기존 광역 피해/아군 제외/지형 패턴은 유지합니다.

## 장비점

- `ArmoryPanel.jsx` 및 `armory-ui.css`. 기존 인물 초상화를 선택 버튼으로 사용하고 가로 스크롤, 방향키/Home/End 이동을 지원합니다.
- 무기/방어구를 구분하고 해당 캐릭터가 장착할 수 있는 보유 장비만 표시합니다.
- 현재 장비, 강화 수준, 교체 전후 공격·방어, 증감 수치를 표시합니다. 비교도 실제 장착과 동일한 `applyEquipmentStats` 함수를 사용합니다.
- 장비 선택은 미리보기만 바꾸고 장착하기/해제하기로 확정합니다. 다른 인물을 선택하면 이전 인물의 미확정 비교를 초기화합니다.
- 세로 휴대폰에서 확정/저장 버튼은 고정하고 내용만 스크롤합니다. 낮은 가로 화면은 본문 스크롤로 모두 접근합니다. 기존 APK의 시스템 바 보호 여백도 적용합니다.
- 상점의 품목 분류/아이콘과 시설 공통 제목·골드·저장 영역도 정리했습니다. 장비 ID, 인벤토리 공유 방식, 강화/육성/저장 형식은 바꾸지 않았습니다.

## 검증

- `scripts/attack-range.test.mjs`: 정확한 거리/경계/반격/화살 스킬/적 이동/장비 강화 비교.
- `scripts/verify-battle-controls.cjs`: 공격 1/2/3칸, 사거리별 반격 예측과 실제 HP, 움직일 수 없는 인접 적, 기존 전투 명령/스킬/패배/연계 제거 회귀.
- `scripts/verify-armory.mjs`: 초상화 선택/키보드 이동, 장착/교체/해제, 강화 증감, 불가능한 장비 제외, 선택 취소, 저장 후 재접속, 5개 화면/네이티브 여백 조건.
- Android 실기기는 연결되어 있지 않습니다. 브라우저 및 모의 WebView 검증과 최종 APK 내부 파일/서명 검증을 구분합니다.
