# 천수 권리 정리의 범위와 출시 판단

기준일: **2026-10-07 한국시간**

이 문서는 천수의 소스·그림·음원·글꼴·외부 라이브러리를 정리할 때 적용하는 권리 기준과 조사 한계를 기록합니다. 파일별 제작·입수 기록과 라이선스 고지는 [RIGHTS.md](../../RIGHTS.md) 및 해당 자료의 기록을 기준으로 판단합니다. 이 문서 자체는 기술 수정·APK 제작·배포 완료 기록이나 모든 자료의 비침해 확인서가 아닙니다.

## 저작권 등록은 출시의 필수 조건이 아닙니다

한국에서는 사람이 창작한 보호대상 저작물의 저작권이 창작 때 발생하며 별도의 신고·등록을 발생 요건으로 하지 않습니다. 따라서 **저작권 등록을 하지 않았다는 이유만으로 천수를 출시할 수 없는 것은 아닙니다.** 등록은 권리 입증 등에 도움이 되는 별도 절차입니다. 게임을 등록하더라도 타인의 그림·음원·프로그램을 이용할 권리가 새로 생기는 것은 아닙니다. [저작권법 제10조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0010&lsiSeq=283335&urlMode=lsScJoRltInfoR)

게임물 등급분류, 스토어 심사, 사업·개인정보 관련 의무는 저작권 등록과 다른 사항이며, 이 문서에서는 완료 여부를 판정하지 않습니다.

## 자료를 정리할 때 적용하는 구분

| 상태 | 의미 |
| --- | --- |
| 이용 조건 확인 | 해당 파일의 원저작자·입수 경로·라이선스와 필요한 이용 범위를 연결할 수 있음 |
| 제작 기록 있음 | 생성·제작 기록은 있으나 그것만으로 모든 제3자 권리와 독점권까지 확인한 것은 아님 |
| 확인 범위 제한 | 원본이나 계약, 당시 서비스 조건을 현재 기록만으로 완전히 연결하지 못함 |
| 배포 제외 | 이번 배포에 포함하지 않는 자료. 과거 공개본까지 삭제되었다는 뜻은 아님 |

정리는 저장소·제작 기록·공식 제공처에서 확보 가능한 근거를 개발 과정에서 수집해 진행합니다. 확인되지 않은 제작자나 이용 허락을 추정하여 채우지 않습니다. 출처 표시나 라이선스 파일 추가는 필요한 고지 의무를 이행하는 수단이며, 허락되지 않은 사용을 허용된 사용으로 바꾸지는 않습니다.

## AI 이미지와 참고 게임

AI가 만든 결과물과 사람이 창작적으로 수정·구성한 부분은 구분합니다. 프롬프트, 생성 결과, 참조 이미지, 후속 편집을 연결해 기록하되, 파일 형식 변환·크기 조절이나 생성 명령만으로 그림 전체의 독점저작권을 확보했다고 표시하지 않습니다. 인간의 창작적 기여가 없는 부분은 저작권 보호와 등록의 범위가 제한될 수 있습니다. [한국저작권위원회 등록 안내서](https://www.copyright.or.kr/information-materials/publication/research-report/view.do?brdctsno=54253)

**AI로 새로 생성했다는 사실은 제3자 권리 비침해 보증이 아닙니다.** 참조 이미지의 이용권과 생성 결과의 구체적 유사성은 별도 판단 대상입니다. 화풍·추상적인 게임 원리와 특정 캐릭터의 고유한 표현·구도·대사·선율을 구분하며, 다른 게임의 공식 자료가 공개되어 있다는 사정만으로 재사용을 허용된 것으로 보지 않습니다. [한국저작권위원회 분쟁 예방 안내서](https://www.copyright.or.kr/gov/nuri/view.do?brdctsno=54252)

또한 게임의 개별 요소가 흔하더라도 주요 요소의 선택·배열·유기적인 조합이 창작적 표현으로 보호될 수 있습니다. ‘그림 파일이 다르다’는 이유만으로 전체 게임 표현의 비침해를 확정하지 않습니다. [대법원 2019.6.27. 선고 2017다212095](https://law.go.kr/LSW/precInfoP.do?precSeq=208504)

OpenAI의 2026-01-01 시행 개인용 약관은 적용 법률이 허용하는 범위에서 이용자와 OpenAI 사이의 출력물 권리 귀속을 정하고, 유사 출력 가능성 및 비침해 보증 배제도 명시합니다. 한국법상 저작물성이나 제3자의 권리를 대신 판정하는 조항은 아닙니다. 기업·API 서비스에는 별도 약관이 적용될 수 있어, 현재 공개된 개인용 약관을 과거 모든 생성 파일의 계약 증거로 취급하지 않습니다. 생성 당시 계정·서비스·약관과 입력물 권원이 기록으로 연결되지 않은 부분은 그 한계를 유지합니다. [OpenAI Terms of Use](https://openai.com/policies/terms-of-use/)

## 음악·폰트·오픈소스의 배포 범위

- 음악은 작사·작곡의 저작권과 연주·녹음의 저작인접권을 구분합니다. 외부 음원·샘플의 게임 삽입·앱 배포·웹 전송·소스 ZIP 내 원본 제공이 각각 허용되는지 확인합니다. 코드 합성음도 타인의 보호 선율을 그대로 재현한 경우까지 자동으로 허용되는 것은 아닙니다. [한국저작권위원회 음악 이용 FAQ](https://www.copyright.or.kr/customer-center/faq/list.do?categorycode1=&counselfaqno=47337&pageIndex=4&portalcode=04&searchkeyword=)
- 폰트는 ‘무료’라는 설명만으로 APK 탑재·웹폰트 제공·재배포까지 허용된다고 판단하지 않습니다. 실제 파일의 라이선스와 고지·동봉 조건을 적용합니다. 운영체제가 제공하는 글꼴 이름을 지정하는 것과 글꼴 파일을 배포하는 것은 구분합니다. [한국저작권위원회 공유마당 이용조건 안내](https://gongu.copyright.or.kr/gongu/bbs/B0000018/list.do?bbsSeCd=04&menuNo=20&pageIndex=5)
- 오픈소스는 실제 배포되는 구성요소와 적용 라이선스를 연결합니다. 웹의 npm 의존성뿐 아니라 Android 네이티브 SDK·전이 의존성도 별도 범위입니다. Google Play services가 사용하는 오픈소스 고지 역시 앱 개발자가 적절히 제공해야 하며, 특정 고지 도구 설치 자체가 모든 조건의 이행을 보증하지는 않습니다. [Google Play services OSS 고지 안내](https://developers.google.com/android/guides/opensource)

## ‘천수 / CHEONSU’ 상표 조사 상태

게임의 저작권과 제목·로고의 상표 사용 가능성은 별개입니다. 상표권은 설정등록으로 발생하며, 표장과 지정상품·서비스의 동일·유사 여부 및 권리 상태가 중요합니다. [지식재산처 상표 안내](https://www.kipo.go.kr/ko/kpoContentView.do?menuCd=SCD0200154)

2026-10-07 KST에 수행한 조회는 다음과 같습니다.

| 조회 | 확인한 범위와 결과 |
| --- | --- |
| KIPRIS 공식 홈페이지·공식 검색 도움말 | 상표 명칭·상품분류·유사군을 이용하는 검색 방식 확인 |
| 공식 검색 URL의 `천수` 조회 | 결과 페이지에 도구로 접근하지 못해 출원·등록번호와 지정상품을 확보하지 못함 |
| 공식 검색 URL의 `CHEONSU` 조회 | 결과 페이지에 도구로 접근하지 못해 출원·등록번호와 지정상품을 확보하지 못함 |
| KIPRIS 도메인 대상 일반 웹 검색 | 관련 권리의 존재 또는 부존재를 판단할 수 있는 개별 상표 기록을 확보하지 못함 |

참조한 공식 검색 서비스: [KIPRIS](https://www.kipris.or.kr/khome/main.do). 시도한 검색 경로는 `/khome/search/searchResult.do?queryText=천수` 및 `?queryText=CHEONSU`입니다.

이는 **상표 검색 결과가 0건이라는 뜻이 아닙니다.** 게임 소프트웨어·게임 서비스의 지정상품을 연결한 동일 상표 기본 조사도 완료하지 못했으므로 **명칭 사용 가능성은 미확인**으로 남깁니다. 발음·외관·관념이 비슷한 표장, 출원 중인 권리, 출시국별 권리까지 포함하는 사용 가능성 판단도 이번 결과에 포함되지 않습니다. 사업자명이나 일반 웹의 동명 콘텐츠만으로 침해 또는 안전을 확정하지 않습니다.

## 출시 판단에 남는 한계

출처·라이선스·고지를 정리하는 것은 확인 가능한 위험을 줄이는 작업입니다. 현재 기록만으로 **모든 파일의 독점권과 전 세계 상용 출시의 비침해를 완전히 보증할 수는 없습니다.** 특히 제작 기록만 남은 AI 산출물의 권리 범위와 상표 조회 미완료는 별도로 남습니다. 이 상태를 침해 확정으로 표현하지도 않습니다.

이 문서는 이번 자료 정리의 범위를 설명하며 저작권 등록·상표 출원을 신청하거나 유료 법률 심사를 의뢰한 기록이 아닙니다. 향후 개별 분쟁이나 상용 계약에서 확정적인 권리 보증이 요구되면 해당 파일·계약·표장을 특정한 전문 검토가 필요합니다.

## 근거 확인의 범위

법령·판례·공식 공개 약관·고지 안내를 읽고 정리했습니다. AI 등록 안내서는 공식 발행정보·검색 색인을 확인했으며, 그 사이트의 첨부 PDF 전체는 웹 도구로 읽지 못했습니다. 인간 창작 기여와 AI 결과물의 침해 판단 기준은 [분쟁 예방 안내서의 정부 재게시 PDF](https://ai.wiseuser.go.kr/uploads/information/한국저작권위원회_생성형_인공지능_결과물에_의한_저작권_분쟁_예방_안내서.pdf) 20쪽, 24~25쪽, 28~33쪽에서 직접 확인했습니다. 읽지 못한 원문이나 조회하지 못한 권리 기록을 확인 완료로 표시하지 않습니다.
