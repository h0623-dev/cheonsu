# 천수 1.99.174 · 장비 확장과 동료 성장 개선

2026-10-14 KST · Android versionCode 373

**1.99.174 / Android 373 새 APK·서명 OTA·전체 개발 소스 ZIP 제작 준비 중이며 아직 공개하지 않았습니다.** 이 문서는 이번 변경과 배포 준비 상태를 기록합니다. 기존 1.99.173 APK에는 이번 변경이 포함되지 않습니다. 최종 게임 소스와 자동 Actions·공개 파일·실제 OTA 채널 결과는 새 배포가 완료된 뒤 기록합니다.

## 장비 선택 확장

장비를 기존 68종에서 **110종**으로 늘립니다. 새 장비는 **42종(무기 30·방어구 6·장신구 6)**이며 전체 구성은 **무기 70·방어구 22·장신구 18**입니다. 새 무기는 5·15·40장, 새 방어구와 장신구는 10·30장 진행에 맞춰 해금합니다. 기존 장비와 함께 상점·장비점에서 선택하고 기존 장착·강화 규칙을 사용합니다.

기존 장비 ID·능력치·가격·소유·강화 기록을 보존합니다. 리나의 활을 비롯한 1.99.172의 캐릭터별 무기 이름 표시도 유지합니다. 이미 착용한 장비를 임의로 교체하거나 기존 저장의 장비를 다시 지급하지 않습니다.

## 대기실에서 선택한 동료 유지

대기실에서 선택한 캐릭터를 부모 화면의 `campWalkerId`로 관리합니다. 전투에서 돌아올 때 마을 화면이 새로 표시되어도 카일로 초기화하지 않고 마지막으로 선택한 동료를 다시 표시합니다. 승리·패배 후 기존 저장 상태를 이어받는 경로에서도 선택을 보존합니다.

`getSaveData`와 `normalizeSaveData`에 선택 기록을 연결해 저장 후 이어하기에도 해당 동료를 복원합니다. 선택 기록이 없거나 보유하지 않은 동료를 가리키는 구저장은 보유한 동료로 안전하게 복원하며 기존 진행·명부·수집 데이터를 유지합니다.

## 5레벨 간격의 전직

기존 두 단계의 전직 레벨을 **상급 5레벨 → 최상위 10레벨**로 맞춥니다. 비전 전직은 **10레벨**부터 가능하고 기존 전용 유물 조건은 유지합니다. 최상위 전직의 31장 진행 잠금을 제거해 레벨과 스킬 숙련 조건을 갖추면 더 일찍 선택할 수 있습니다. 15·20레벨에 새 전직 단계를 추가하는 변경은 아닙니다.

기존 성장 인장 소비·보너스 기록과 이미 전직한 캐릭터의 직업·분기를 보존합니다. 기존 최상위 분기 변경 규칙, 전직 능력치와 외형·기술을 유지합니다. 새 레벨 조건에 맞춰 기존 동료를 임의로 전직시키거나 기존 직업을 낮추지 않습니다.

## 새 동료의 시작 레벨

새 동료가 합류하는 순간 **보유 아군 중 최고 레벨의 70%를 내림한 값**으로 시작하며 최소 1레벨을 보장합니다. 최고 레벨이 10이면 새 동료는 7레벨, 20이면 14레벨입니다. 동료가 합류하는 정산에서는 해당 전투의 성장 기록을 명부에 반영한 다음 최고 레벨을 계산합니다.

시작 레벨이 올라간 만큼 기존 레벨 성장 규칙인 **레벨당 최대 HP +2·공격 +1·방어 +1**을 반영합니다. 전직이나 장비를 자동으로 지급하는 방식은 아니며 동료의 고유 병과·기술·장비와 합류 기록을 유지합니다. 공통 합류 처리 함수를 기존 캠페인과 31~50장 확장 캠페인의 모든 신규 합류 경로에 연결합니다.

이미 얻은 동료의 레벨은 소급해 변경하지 않습니다. 과거에 얻은 1레벨 동료를 자동으로 올리거나 기존 성장·경험치·전투 저장을 덮어쓰지 않습니다.
