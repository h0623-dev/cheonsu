# 천수 새 채팅과 Notion 프로젝트 기억

2026-10-15 KST 사용자 요청에 따라 개발 맥락은 비공개 Notion 기준 페이지에 저장하고, 작업 과정의 중요한 상태 변경과 완료 때 같은 기록을 갱신합니다. 공개 GitHub에는 비공개 페이지 URL·ID·본문을 복제하지 않습니다.

## 새 채팅에서 찾는 문서

- 기준 페이지의 정확한 제목: **천수 개발 기억·인수인계**
- 반복 절차를 담은 Notion 스킬: **천수 개발 기억 읽기·갱신**
- 저장소용 절차: [노션 기억 연결 스킬](../.agents/skills/cheonsu-notion-memory/SKILL.md)

사용자가 받은 비공개 링크를 새 채팅에 붙여 넣거나 연결된 Notion에서 제목으로 찾습니다. Notion과 GitHub 연결을 사용할 수 있게 하고, 코드 작업에는 게시된 `cheonsu` Cloud 환경을 선택합니다. 페이지는 같은 주소로 유지합니다. 새 페이지를 매 작업마다 만들지 않습니다.

새 채팅에 보낼 문구:

> 이 노션 인수인계를 읽고 천수 개발을 이어가 줘. 사용자 요구, 현재 배포 상태, 원복 기준, 미적용 시안과 다음 할 일을 먼저 확인하고, 수정·결정이 생기면 같은 노션 페이지도 갱신해 줘.

## 기록하는 것

사용자의 최신 요청·승인 범위·협업 선호, 현재 구현과 공개 배포, 버전·브랜치·커밋, 저장과 원복 기준, 적용하지 않은 시안, 검사 범위·제작/배포 장애·미완료 결정, 산출물 링크와 다음 단계를 근거와 함께 기록합니다. 직접 실행·자동 Actions·이전 기록을 구분합니다.

Notion 기록은 프로젝트의 이어받기 자료이며 실제 최신 코드·작업 트리·배포 상태를 대신하지 않습니다. 새 세션의 최신 사용자 지시와 실제 근거를 먼저 따르고, 오래된 요청을 중복 적용하지 않습니다.

## 갱신 시점과 범위

작업 착수, 중요한 결정·구현·차단·검사·시안 공개·배포 상태 변경 후와 최종 응답 전에 기준 페이지를 읽고 필요한 부분만 갱신합니다. 사용자 메모·관련 없는 문단·기존 이력은 보존합니다. 활성화된 스킬은 관련 작업에서 절차를 불러오게 하는 설정이며 상시 감시 서비스나 백그라운드 스케줄이 아닙니다.

연결·권한이 없으면 미반영 내역과 재개 지점을 현재 대화에 남기고 저장 완료라고 말하지 않습니다. 비공개 페이지를 공개로 공유하거나 다른 대상으로 옮기는 일은 이 갱신 요청에 포함하지 않습니다. 개인키·토큰·개인 저장 원문은 어느 문서에도 기록하지 않습니다.

기억 갱신을 이유로 게임 테스트·린트·QA·검증 빌드를 실행하지 않습니다. 기존 사용자 검증 방침, 저장 보존, Actions 서명·배포 보호는 그대로 유지합니다. 이 문서·지침 추가는 게임 패치가 아니므로 새 게임 버전·APK·OTA를 만들지 않습니다.
