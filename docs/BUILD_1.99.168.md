## 변경 사항

- 전체 50장 공통 패배 판정에서 카일 사망을 제외합니다. 생존 아군이 없으면 전멸 패배가 되며 적도 동시에 전멸한 경우 아군 전멸 판정을 우선합니다.
- 카일이 쓰러져도 다른 아군의 행동, 적 AI, 다음 아군 턴, 보스 각성, 기존 승리 조건을 계속 처리합니다.
- 일반 공격·반격·위험 칸·상태이상·턴 시작 지형 효과·진행 중 저장 복원에 같은 전멸 판정을 적용합니다.
- 전멸 배너와 패배 창에 아군 전멸을 안내하고 제한 초과는 별도 사유로 표시합니다. 미션 목록에서 카일 사망을 삭제합니다.
- 기존 장별 기본 제한과 적 수·전장 크기 가산 및 기존 상한 30을 계산한 뒤 `Math.ceil(기존 최종 제한 * 1.5)`를 적용합니다. 예: 14→21, 19→29, 30→45. 확대된 제한 초과 시 패배는 유지합니다.
- 마지막 허용 라운드의 아군 행동으로 승리하면 제한 초과보다 승리를 먼저 처리합니다. 저장된 라운드 자체를 늘리거나 초기화하지 않고 새 제한을 계산하므로 반복 로드로 배율이 중첩되지 않습니다.
