# 천수 1.99.168 · 패배 조건과 턴 제한 완화

작성 기준: 2026-10-07 KST · Android versionCode 367

## 변경 사항

- 전체 50장 공통 패배 판정에서 카일 사망을 제외합니다. 생존 아군이 없으면 전멸 패배가 되며 적도 동시에 전멸한 경우 아군 전멸 판정을 우선합니다.
- 카일이 쓰러져도 다른 아군의 행동, 적 AI, 다음 아군 턴, 보스 각성, 기존 승리 조건을 계속 처리합니다.
- 일반 공격·반격·위험 칸·상태이상·턴 시작 지형 효과·진행 중 저장 복원에 같은 전멸 판정을 적용합니다.
- 전멸 배너와 패배 창에 아군 전멸을 안내하고 제한 초과는 별도 사유로 표시합니다. 미션 목록에서 카일 사망을 삭제합니다.
- 기존 장별 기본 제한과 적 수·전장 크기 가산 및 기존 상한 30을 계산한 뒤 `Math.ceil(기존 최종 제한 * 1.5)`를 적용합니다. 예: 14→21, 19→29, 30→45. 확대된 제한 초과 시 패배는 유지합니다.
- 마지막 허용 라운드의 아군 행동으로 승리하면 제한 초과보다 승리를 먼저 처리합니다. 저장된 라운드 자체를 늘리거나 초기화하지 않고 새 제한을 계산하므로 반복 로드로 배율이 중첩되지 않습니다.

## 저장과 보존 범위

명시적으로 저장한 생존 명단을 복원하며 쓰러진 카일을 전투 중 임의로 되살리지 않습니다. 보유 캐릭터 명단은 유지하므로 전투 후 회복 및 다음 전투 출전 규칙은 그대로입니다. 이전에 확정된 패배 기록·훈련 제한·스테이지 해금은 소급 변경하지 않습니다. 카일 체력 유지 보너스 목표는 선택 보상이며 패배 조건이 아닙니다.

기존 저장·진행·수집, 아트·음악·권리 안내, 승리 조건, 기본 원복 기준 [1.99.165 + Safari](ROLLBACK_BASELINE.md)는 보존합니다. 서명키는 기존 GitHub Actions cheonsu-release 환경에서만 사용합니다.

## 제작과 배포

새 APK·서명 OTA·개발 소스 ZIP 및 Safari 공개를 진행 중입니다. 이번 버전의 완료 결과와 최종 소스는 발행 후 기록합니다. 이전 버전의 APK나 자동 검사 결과를 이번 변경 결과로 대신하지 않습니다.

## 검사 범위

사용자 지시에 따라 수정 후 별도 검증은 실행하지 않았습니다.

직접 린트·단위 검사·브라우저 QA·검증 빌드·아티팩트 재다운로드 대조 또는 수동 검사 CI를 실행하지 않습니다. 기존 자동 Actions의 검사·서명·배포 보호는 유지합니다. 자동 검사 코드의 기대값은 새 규칙에 맞게 갱신하며 카일 사망 후 계속/승리·전멸·새 제한 경계·저장 보존 사례를 포함합니다. 이 문서 작성 시 새 버전의 자동 실행 완료 결과는 아직 없습니다.
