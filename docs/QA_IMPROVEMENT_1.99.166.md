# 천수 1.99.166 보스 연출 개선과 검증 구분

게임 1.99.166 / Android 365. 작성일: 2026-10-07 KST.

전체 50개 스테이지에서 보스의 정체성·전장·위협이 함께 보이도록 등장과 각성 연출을 개선하는 작업입니다. **현재 APK·서명 OTA·Safari 웹 반영과 최종 자동 Actions 결과는 대기 중입니다.** 이 문서는 구현 범위를 기록하며 직접 QA 통과 보고서가 아닙니다.

## 조사와 적용 범위

[보스 연출 조사](BOSS_RESEARCH_1.99.166.md)는 엘든 링·옥토패스 트래블러 II·파이어 엠블렘 인게이지·몬스터 헌터 와일즈의 공식 소개와 천수에 적용할 해석을 구분합니다. 보스의 위엄을 얼굴 확대나 수치 증가에만 의존하지 않고 장의 장소·소속·무기·실루엣·대사와 실제 위협 안내로 전달합니다. 원작의 그림·음원·로고를 게임 파일에 복사하지 않습니다.

| 대상 | 반영 범위 |
| --- | --- |
| 1~50장 보스 소개 | 장별 고유 부제·대사와 실제 기술·사거리·각성·위험 안내 |
| 등장 구도 | 전장 배경 위 전신·무기·발밑을 보여주는 넓은 구도 |
| 새 등장 그림 | 지휘관·빙결·불꽃·예언자·심연 계열 5개 |
| 31~50장 정체성 | 기존 종족형 지휘관과 지역 보스의 종족·외형·역할 유지 |
| 전장 표식 | 모든 보스의 발밑 문양과 보스 표식 |
| 보스 정보창 | 실제 현재 체력과 각성 문턱 표시 |
| 등장·각성 음향 | 기존 효과음 설정을 따르는 저음·상승 화음 |
| 안내 시간 | 등장 4.2초·각성 3.4초, 전투 배속과 분리 |
| 닫기와 재개 | 전장으로 버튼 또는 연출 종료 뒤 기존 전투 흐름 재개 |
| 휴대폰 화면 | 세로·가로 화면에 맞춘 전신·문구·조작 배치 |

50장별 소개 데이터와 전신 원화 수는 구분합니다. 새 원화는 5개이며 50개 고유 원화를 새로 제작했다는 의미가 아닙니다. 등장에 사용하는 그림을 대화·대기·공격 원화 전체의 교체로 표현하지 않습니다. 각성 안내도 새로운 전투 페이즈·추가 행동·불사 상태를 도입하는 변경이 아닙니다.

## 안내와 실제 전투의 관계

기술명·일반 공격 및 기술 사거리·각성 문턱·장판과 지원 조건은 기존 런타임의 실제 보스 상태와 연결합니다. 미션에서 사용하는 보스 이름을 바꾸거나 장식 문양을 실제 피해 범위로 취급하지 않습니다. 공격형과 지원형, 최소 사거리가 있는 원거리 적의 역할을 유지합니다.

전투 배속은 기존 1배·2배·3배 선택을 유지하지만 보스의 글을 읽는 등장·각성 시간은 별도로 둡니다. 사용자가 전장으로 버튼을 눌러 닫을 수 있으며 닫기 때문에 턴이나 공격 행동을 추가로 소비하지 않습니다. 실제 기기에서 시간을 측정하거나 버튼 흐름을 실행해 확인한 결과가 아니라 구현 범위 설명입니다.
