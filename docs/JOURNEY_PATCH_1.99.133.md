# 1.99.133 배치·이야기·화면 개선

## 시작 배치

- 같은 행부터 채우던 방식에서 지형과 역할을 함께 보는 결정적 배치로 변경했습니다.
- 근접 전열, 원거리·회복 후열, 보스와 호위병의 위치가 엇갈립니다. 장마다 기준 위치가 달라집니다.
- 같은 편의 맨해튼 거리 3칸을 우선하며, 대규모 편성은 가용 지형에 맞춰 간격을 조정합니다. 실제 30개 전장과 4/15/17인 검사에서는 최소 2칸, 상대 진영까지 최소 7칸을 확보합니다.
- 보스와 일반 적도 같은 간격 검사를 받습니다. 겹침, 막힌 타일, 분리된 섬에 배치하지 않습니다.
- 새로 시작하는 전투에만 적용합니다. 기존 전투 저장의 지형·좌표·행동 완료 상태는 유지합니다.

## 30장 이야기

전투 전 30개, 전투 후 30개 장면을 새로 작성했습니다. 기존 인물과 전장에 맞춘 천수 고유 이야기이며 다른 게임의 대사를 복제하지 않았습니다.

| 장 | 이야기 |
| --- | --- |
| 1~6 | 꺼진 국경 봉화, 위조된 명령서, 봉인의 연결점 발견 |
| 7~12 | 실종된 주민과 기억의 수정, 재의 왕좌의 의식 |
| 13~18 | 지워진 이름, 기사단 해산의 기록, 감옥 생존자 구출 |
| 19~24 | 가론의 책임과 옛 계약의 진실, 희생을 나누는 새로운 약속 |
| 25~30 | 마지막 성소, 가론과의 대면, 흑야의 종결과 귀환 |

- 실제 동료 합류 장에서 해당 인물이 인사하고 이후 장에 등장합니다.
- 선택적으로 찾는 보물은 발견했다고 단정하지 않고 흔적으로 언급합니다.
- 전투 후 이야기를 읽거나 건너뛴 다음, 승리창에서 선택한 다음 스테이지·상점·대기실로 이동합니다. 보상은 기존과 같이 한 번만 정산합니다.
- 인물 전신 이미지, 대사 이전/다음, 진행 수, 이번 장면의 지나온 대화 기록을 제공합니다.
- 대화 기록은 모달 창으로 열리며 닫기와 Esc를 지원합니다. 대화 화면에 초점이 있을 때 방향키·Enter·Space로도 진행합니다.
- 대사 자동 재생이나 음성 더빙은 추가하지 않았습니다.

## 화면·조작

- 원정 지도: 장식적인 상자와 중복 정보를 줄이고, 지역 바로가기·진행도·전장 목록을 정리했습니다.
- 편성: 목표와 출전 동료를 우선 표시합니다. 전장 정보와 편성/보급 관리는 펼쳐 확인할 수 있습니다.
- 역할 필터·정렬 선택, 출전 체크 표시, HP/공격/이동 요약, 하단 출전 버튼을 제공합니다.
- 야영지: 아이콘 탭, 접히는 소식, 하단 저장·상점·다음 전투를 정리했습니다. 다음 전투는 다음 장 편성으로 직접 연결합니다.
- 전투: 첫 시점을 선택한 아군에 맞추고 공격/스킬/아이템/대기에 아이콘을 추가했습니다. 기존 130%와 2배속 기본값을 유지합니다.
- 320px 세로형부터 PC 및 모바일 가로형까지 대화와 주요 화면을 검사합니다.

## 검증 명령

```sh
npm test
node scripts/verify-journey.cjs
node scripts/verify-refinement.cjs
node scripts/verify-battle-controls.cjs --viewport 390
npm run build
npm run android:apk
```

실제 실행 결과, APK 해시 및 서명은 `BUILD_1.99.133.md`에 기록합니다. 브라우저 화면 검사는 Android 실기기 검사를 대신하지 않습니다.
