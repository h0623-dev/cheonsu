# 1.99.159 전체 캐릭터 스킬 효과

개발 버전은 **1.99.159 / Android versionCode 358**입니다. 사용자의 요청에 따라 주인공 외의 모든 캐릭터로 스킬 효과를 확장합니다. 이번 작업 범위는 **아군 17종·일반/정예 적 25종·스토리 보스 5종, 총 47종**입니다. 1.99.157에서 승인·적용한 신규 적 6종도 포함합니다.

## 캐릭터와 무기를 따르는 효과

각 캐릭터의 기존 공격·스킬 그림에서 무기나 시전 집중점에 붙는 효과를 구성합니다. 검과 창은 무기 방향, 활과 석궁은 발사 지점, 중병기는 타격 부위, 주먹·발톱은 실제 공격 부위, 마법·회복·보호 기술은 시전 집중점을 기준으로 충전·타격·잔광을 연결합니다. 캐릭터의 이동·회전·자세 변화와 효과가 함께 움직이고 기술의 속성·역할에 맞춰 색과 형태를 구분하는 것이 이번 확장의 기준입니다.

기존 **1.99.158 카일의 돌풍 베기 불꽃 회오리, 여명참 황금 여명광, 수호의 맹세 금빛 방벽**은 유지합니다. 다른 캐릭터는 각자의 무기와 기술에 맞춘 고유 효과를 사용합니다. 신규 캐릭터 원화나 새로운 기술을 추가하는 작업은 아닙니다.

기존 전투 계획의 `contacts`·`releases`, 공격 준비·타격·복귀 동작과 스킬 장면의 HP 표시 시점 `duration * .62`를 유지합니다. 추가 시각 효과가 피해·회복·보호 결과를 다시 계산하지 않습니다. 명중·빗나감·지원 기술을 구분하고 기존 전투 속도 설정을 따릅니다.

## 휴대폰과 효과 설정

기존 SVG 및 유한 시간의 Web Animations API 구조를 확장합니다. 캐릭터 몸체와 자세 안에 붙인 효과는 같은 좌표 변환을 따르며, 매 프레임 화면 좌표를 측정하는 무한 `requestAnimationFrame` 루프나 화면 전체의 큰 블러·필터 계산을 추가하지 않습니다.

효과 끄기·동작 줄이기 설정, 실행 중 설정 전환, 화면 회전과 장면 해제에 대응해야 합니다. 장면을 끝내면 분리된 DOM에 걸린 애니메이션까지 취소하고 크기 변경 관찰자를 정리합니다. 추가 DOM·유한 애니메이션 수와 실제 프레임 성능은 새 검사 결과로 확인하며, 이전 1.99.158 결과를 이번 버전의 검증으로 대신하지 않습니다.

## 저장과 기존 콘텐츠

스킬 ID·피해량·회복량·쿨다운·사거리·행동 소모·AI·반격 규칙을 보존합니다. 활의 일반 반격은 정확히 2칸에서만 가능하고 인접 1칸에서는 반격하지 않는 현재 규칙을 유지합니다. 현재 캐릭터·적·보스 원화와 마을 걷기 동작을 보존합니다.

저장 키·저장 구조, 진행도·파티·성장·장비·골드·아이템·교류·탐색·도감 수집과 재개 중인 전투를 초기화하지 않습니다. 기본 “원복” 기준은 **1.99.154 / Android353**, 커밋 `801234d1c99d0cdc7c11d645e111f64336e80672`, 태그 `codex/rollback-1.99.154`입니다. [복원 절차](ROLLBACK_BASELINE.md)에 따라 현재 저장과 무관한 사용자 작업을 보존하며 새 상위 버전으로 전달합니다.
