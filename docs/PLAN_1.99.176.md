# 천수 1.99.176 · 전체 점검 기획안과 진행안

작성일: 2026-10-16 KST. 착수 기준은 게임 1.99.175 / Android 374이며, 구현·버전 동기화를 마친 배포 대상은 **1.99.176 / 375**입니다. 두 독립 AI QA의 엔진·단위 **1,068/1,068**, 실제 브라우저 전장 **50/50장**, 후반 복구·저장 안전 **3/3프로필**과 아트·모션 점검을 완료했습니다. 이후 구형 저장의 타이틀 한 줄 표시를 보완한 새 번들도 별도 실제 UI 회귀·전체 단위 재검사·최종 린트·빌드·3화면 스모크를 통과했습니다. 현재는 소스 반영 후 자동 Actions의 새 APK·서명 OTA 공개를 기다리는 단계입니다. 직접 검사와 공개 배포 상태는 [진행안](PROGRESS_1.99.176.md)·[이번 QA](QA_1.99.176.md)·[빌드 기록](BUILD_1.99.176.md)에서 구분합니다.

## 이번 요청과 진행 원칙

사용자는 서로 독립된 QA 두 팀의 전체 점검, 기획·아트·개발 역할의 동시 보완, 필요한 개선의 실제 적용과 마지막 기획안·진행안을 요청했습니다. 여기서 팀은 병렬로 작업하는 **독립 AI 역할**이며, 외부 인력을 새로 채용했다는 의미가 아닙니다. 이번 명시 요청 범위에서는 직접 QA와 회귀 검사를 수행합니다. 평소의 검증 생략 규칙을 모든 후속 작업에서 해제한 것으로 해석하지 않습니다.

현재 동작을 확인한 뒤 문제를 고칩니다. 이미 구현된 콘텐츠를 미완료로 간주해 중복 적용하지 않고, 저장·진행·수집·전직·장비와 관련 없는 사용자 변경을 보존합니다. 전체 난이도 수치나 신규 성장 시스템은 근거 없이 크게 바꾸지 않습니다. 공개 허용만 받은 무료 이펙트 비교 시안은 게임 적용 승인과 구분합니다.

공동 QA에서 추가 확정한 수정도 기획에 반영했습니다. 정상 저장은 파싱 성공과 별도로 최소 여정 구조를 확인해 보호합니다. 과거 적 턴 저장에서는 행동 완료한 지원 적을 다시 지원시키지 않고, 아군 반격 처치는 경험치·전리품과 함께 격파 기록에도 한 번만 반영합니다. 49장에서 이동력 1 잉크덩굴이 여울에 갇히는 문제는 해당 종족의 여울 비용만 1로 조정했으며 지도·이동력·타 종·아군·다른 지형 비용은 유지합니다. 실제 47~50장 생성 보드의 잉크덩굴 회귀 6개가 통과했습니다. OS 모션 줄이기에서는 보조 표식을 정적으로 유지하고, 턴 안내는 한국어로 맞췄습니다. 자세한 원인과 검사 근거는 [QA 기록](QA_1.99.176.md)과 [아트 기록](ART_REVIEW_1.99.176.md)을 따릅니다.

최종 전장 집계 뒤에는 `clearedStages`를 기록하지 않은 유효 구형 저장을 허용하면서 타이틀 표시가 배열 길이를 직접 읽는 호환성 문제가 발견됐습니다. 실제 브라우저에서 오류를 재현하고 타이틀 완료 장수만 안전하게 0으로 표시하도록 한 줄을 보완했습니다. 새 번들에서 타이틀·기록실·도감·이어하기·수동 저장과 골드·동료 성장·장비·강화·대기실 캐릭터 보존이 통과했습니다. 전투·엔진·CSS는 바꾸지 않았고, 앞선 50장 전투 결과를 이 새 번들에서 다시 실행한 결과로 표기하지 않습니다. [전후 UI 근거](qa/1.99.176/dev/findings.md).

전체 적 HP를 일괄 하향하거나 장비·전직을 다시 늘리는 변경은 이번 정적 검토만으로 채택하지 않습니다. 난이도 문제를 재현한 장에서는 원인과 실제 편성·레벨·장비·행동 경로를 먼저 남기고, 전투 불능·경로 단절·보상 누락 같은 오류를 우선 해결합니다.

## 최종 보고에 담을 증거와 남겨둘 한계

완료 보고에는 적용 전 문제·실제 수정·이유·장별 결과·실패와 재검사·미완료/차단·최종 소스 커밋·버전·APK 및 OTA 링크를 기록합니다. 직접 실행한 결과와 자동 Actions·이전 1.99.175 결과를 나눕니다. 장별 fixture나 종료 시나리오로 확인한 결과를 1장부터 정상 HP로 무중단 자연 완승한 결과로 표시하지 않습니다.

Android·iPhone 실기기 설치·터치·성능과 실제 Safari 검사는 실행 환경이 있는 경우에만 완료로 기록합니다. Safari 호스팅은 종전 체험 기간 만료 상태이며, 이 문서만으로 서비스가 재개됐다고 표시하지 않습니다. Firebase·Google 로그인·Play Console 출시와 의존성 보안·상표·법률 검토 역시 별도 실제 근거 없이 완료로 처리하지 않습니다. 공개 무료 이펙트 시안의 앱 적용 여부는 사용자 결정을 유지합니다.
