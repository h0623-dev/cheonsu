# 천수 종합 QA와 개선 계획

대상: 개발 중인 천수 전체 게임. 기준일: 2026-10-03. 작업 버전: 1.99.153.

## 현재 판단

30개 장은 피난민 구조, 기억을 빼앗는 전쟁의 조사, 옛 계약의 진실, 공동의 맹세라는 하나의 이야기로 이어집니다. 다만 후반 보스 표기와 장소 설명이 서사에 맞지 않는 부분이 있어 수정했습니다. 정식 출시 완료 상태는 아닙니다. PC 자동 QA와 실제 Android 설치·터치·발열·장시간 플레이 검증을 구분합니다.

큰 스타일시트(압축 전 약 937KB), 메인 JS(약 932KB), 모달 열기/닫기의 스타일 재계산 비용은 잔여 과제입니다. 바로 전면 분리하면 시스템 바/모달/전투 레이아웃의 회귀 위험이 커서 이번에는 실제 확인된 중복 계산을 먼저 제거했습니다. 후속 작업은 화면별 JS 지연 로딩, 사용하지 않는 누적 CSS 정리, 전장 스타일 영향 범위 제한 후 같은 시나리오를 반복 측정하는 순서입니다.

Firebase/Google 로그인은 선택 기능이며 플레이스토어 출시 자체의 필수 조건은 아닙니다. 현재 프로젝트의 제출 검사는 계정 연결 출시를 전제로 작성된 점을 별도로 검토해야 합니다. 클라우드 동기화는 구현되지 않았고 로그인 화면만 연결해도 저장 동기화가 되는 것은 아닙니다.

현재 `npm run release:check`에는 17개의 미충족 설정/검수 항목이 남습니다. 이 중 Firebase·인증서 연결 항목은 계정 기능을 포함해 출시할 때 필요합니다. 게스트 전용으로 출시한다면 인증 SDK 포함 여부와 관련 검사를 먼저 정리해야 합니다. 정책·권리·운영 정보·정식 서명·실기기 검수는 별도로 해결해야 합니다. 최신 개발 APK는 Play 제출용 정식 서명 AAB가 아닙니다.

현재 Android target API는 36입니다. 최신 제출 기준은 [Google 공식 target API 안내](https://developer.android.com/google/play/requirements/target-sdk)와 실제 콘솔에서 확인합니다. 해당되는 신규 개인 개발자 계정에는 최소 12명·연속 14일 비공개 테스트 조건이 있습니다. [Google 공식 테스트 조건](https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko). 계정과 콘솔 심사를 만들거나 완료한 것으로 간주하지 않습니다.
