# 설정 안전 영역 및 이어하기 QA

검증일: 2026-09-27. 버전 1.99.145 / Android 344.

## 발견 및 수정

1. 전투 설정의 화면 위쪽 위치와 최대 높이가 따로 계산되어 하단 나가기 버튼이 Android 시스템 버튼 영역까지 내려갔습니다. 최상위 모달의 전체 크기를 상하좌우 안전 영역에서 계산하고 헤더/나가기 3개 버튼을 고정했습니다. 긴 옵션 목록만 스크롤하며, 바깥 클릭/닫기/Escape와 포커스 제한을 지원합니다.
2. 과거 저장에서 뒤쪽 장 하나라도 완료되어 있으면 최대 완료 번호 앞의 모든 장이 열렸습니다. 이제 완료한 장은 재도전 가능하며, 신규 입장은 가장 먼저 미완료인 장만 가능합니다. 해금 목록은 별도 상태가 아닌 완료 기록에서 파생합니다. 오래된 `unlockedStages` 값은 신뢰하지 않습니다.
3. 편성 화면에서 저장 후 이어하면 편성 대상 상태가 비어 전투 시작이 반응하지 않았습니다. 유효한 출전 편성 대상까지 복원하고 잠긴 장 편성은 원정 화면으로 돌립니다. 이미 진행 중인 구버전 전투는 보존합니다.

## 1장 완료 저장 복구

실제 완료한 장은 사용자가 1장이라고 확인했습니다. 휴대폰 저장을 원격으로 직접 변경하지는 않았습니다.

- 완료 기록이 `[1]`이면 패치 후 이어하기만으로 1장 재도전과 2장 입장만 허용됩니다.
- 완료 기록 자체에 모든 장이 들어 있다면 정당한 전체 클리어와 자동 구분할 수 없습니다. 따라서 정상 저장을 일괄 초기화하지 않습니다.
- 이 경우 **설정 > 저장 > 클리어 진행도 복구 > 1장까지 완료 > 진행도 복구 적용**을 선택하고 확인합니다.
- 캐릭터, 경험치, 장비, 아이템, 골드와 탐색 기록은 그대로 두고 현재 전투를 나와 원정 화면으로 이동합니다. 완료/해금 목록만 복구합니다.
- 첫 복구 전 상태는 `cheonsu_v01_progress_recovery_backup`에 보관하며 반복 복구로 덮어쓰지 않습니다. **복구 전 원본 되돌리기**로 돌아갈 수 있습니다.
- 백업 공간이 부족하면 저장 변경을 중단합니다. 일반 자동 백업/이전 저장/수동 슬롯도 유지합니다.

## 회귀 검사

- 0~30장 완료의 모든 31개 경계, 뒤섞인 과거 완료, 잘못된 해금 캐시, 정상 전체 완료, 저장 호환, 진행도 복구/원본 보존/저장 용량 오류를 자동 검사합니다.
- 설정/이어하기 UI: 360x740, 412x915, 320x568, 740x360, 568x320의 이전 APK 335 모의 환경, 현재 APK 344 세로/가로, 1280x900 웹. 버튼 실제 클릭, 하단/좌우 안전 영역, 옵션 스크롤 중 위치, Tab/Escape, 저장 문자열 보존을 확인합니다.
- 진행도 UI: 1장 완료/잘못된 전체 해금, 뒤쪽 장 완료, 미완료, 정상 전체 완료, 편성 이어하기, 명시적 1장 복구, 확인 취소, 앱 재실행, 원본 복원을 확인합니다.
- 전투 조작, 마을/상점/장비/여관, 자동저장/재도전, 보조 마법 대상, 메뉴/설정/수동 저장/기록실, BGM 상태 전환, 자동 패치 모의 검사를 함께 실행합니다. 최종 실행 결과는 `BUILD_1.99.145.md`에 기록합니다.

모든 브라우저 검사는 사용자 세션과 분리된 Edge 컨텍스트에서 진행했습니다. 사용자 브라우저 저장이나 휴대폰 저장을 직접 초기화하지 않았습니다. 실제 갤럭시 기기 설치, 시스템 버튼 터치, 스피커 청음과 OTA 복구는 연결된 기기가 없어 미검증입니다.

30장 환경 이미지, 아군/적/보스 그림, 전투 동작과 공격/반격/이동 규칙은 변경하지 않았습니다. 신규 APK 및 동일 웹 번들의 서명 OTA를 제공하며 네이티브 호환 범위는 335~344입니다. 개인 키는 소스/Git/ZIP에 포함하지 않습니다.
