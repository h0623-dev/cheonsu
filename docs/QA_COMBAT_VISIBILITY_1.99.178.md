## 실제 게시 주소와 남은 조사

실제 Sites 주소의 이미지 응답을 읽으려 한 요청은 작업 환경 프록시의 **CONNECT 403 Forbidden**에 차단됐습니다. 이는 개발 환경의 네트워크 제한이며 사용자가 보는 검은 화면의 원인이라고 단정하지 않습니다. 프록시·TLS·인증 제한을 우회하지 않았습니다. 실제 휴대폰 플레이·사용자 기기의 렌더링을 직접 확인한 결과도 아닙니다.

같은 origin에 `graphics-check.html`을 제공하여 사용자 브라우저에서 1장 이미지의 HTTP 상태·종류·decode 여부를 확인하고, 실제 게임의 지도 크기·표시 스타일·이미지 naturalWidth·가리는 요소를 복사할 수 있도록 합니다. 페이지 자체는 저장 데이터 원문을 읽거나 변경하지 않습니다. ‘게임 화면에서 확인’은 기존 게임을 평소와 같이 실행하며 진행도는 게임의 기존 저장 동작을 따릅니다. 결과를 받아 로딩 실패·치수·레이어 중 실제 원인에 따라 후속 수정합니다. 진단 화면의 게시 완료 상태와 주소는 [웹 게시 안내](SAFARI_WEB.md), Android 결과는 [빌드 기록](BUILD_1.99.178.md)을 따릅니다.
