# 1.99.135 마을과 진행 패치

## 변경 사항

- 전투 명령줄, 마을 상단, 원정 지도 상단과 시설 내부에 아이콘+저장 버튼. 정보 숨김 상태에서도 전투 저장은 남습니다. 저장 결과를 알림으로 표시합니다.
- 클리어 판정 직후 보상/경험치/합류/다음 장 해금이 반영된 마을 체크포인트를 저장합니다. 승리 창에서 버튼을 누르거나 대화를 끝낼 필요가 없습니다. 저장 공간 부족은 실패 표시와 재시도로 처리합니다.
- 클리어 처리는 참조로 1회만 정산합니다. 재도전은 전투 경험치를 보존하되 골드, 소모품, 장비 드롭과 클리어 보상을 다시 지급하지 않습니다.
- 신규 게임은 1장만 입장 가능. 기존 테스트의 `unlockedStages` 전체 해금값은 더 이상 신뢰하지 않고 실제 `clearedStages` 기준으로 해금을 계산합니다. 기존 진행 중 전투와 이전 클리어/동료/장비/육성 기록은 보존합니다. 비연속적인 과거 클리어가 있으면 최고 클리어 장까지의 이전 장과 그 다음 장을 유지합니다.
- 신규 마을 이미지와 실제 지형 경로 이동. 시설 버튼/건물 표식/이동 버튼/지도 방향키로 이동하고, 도착하면 시설을 엽니다. 동료 중 이동 캐릭터를 변경할 수 있습니다.
- 상점: 소모품/장비 탭, 가격/수량, 구매 불가 상태. 장비점: 캐릭터 선택, 능력치/장비 슬롯/장착 가능 목록/해제. 여관: 무료 전원 회복. 훈련소: 훈련/스킬 강화/전직/탐색 기록 연결. 기존 고급 관리는 기사단 관리에 유지합니다.
- 회복과 수호는 대상이 미선택 상태로 열립니다. 직접 아군을 선택하고 사용을 확정합니다. 사거리/생존/회복 필요 여부/최대 인원을 검사하고, 취소는 행동과 쿨다운을 소모하지 않습니다. 자가 수호도 자신을 선택합니다. 자동 전투의 기존 AI 대상 선택은 유지합니다.
- 아군/적/보스 41종, 246개 전투 자세의 투명 여백을 제외한 높이와 발 위치를 보정합니다. 인간형은 같은 기준, 늑대는 자연스러운 사족 비율을 유지합니다. 공격 동작은 기존 프레임과 보법을 사용합니다.

## 저장과 이관

저장 키와 기본 데이터 구조는 그대로 유지합니다. 불러오기는 읽기 전용으로 처리해 저장 공간이 부족해도 기존 저장을 열 수 있습니다. 주 저장을 먼저 원자적으로 기록하고, 백업 공간 부족은 성공한 주 저장을 취소하지 않습니다. 저장 중인 공격/적 턴/명령 선택은 중간 상태 저장을 막습니다. 클리어 자동저장은 현재 PC/앱 내부 저장이며 클라우드 동기화가 아닙니다.

다른 PC에서는 소스 ZIP으로 개발을 이어가고, 플레이 진행은 기존 설정의 저장 내보내기/가져오기로 이동합니다. Android 업데이트 전 중요한 저장은 내보내기를 권장합니다. 디버그 서명 APK이며 정식 스토어용 서명은 아닙니다.
