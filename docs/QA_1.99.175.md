# 천수 1.99.175 · 11~50장 독립 QA 작업 기록

2026-10-14 KST 사용자는 기존 QA 결과에 의존하지 않는 새 QA 팀을 요청했고, 마지막 지시로 10장 이후(11~50장)에 집중하도록 지정했습니다. 이번 범위에서 직접 린트·테스트·브라우저 QA·산출물 검사를 허용한 요청입니다. 기존 검증 생략 스킬은 이 명시 요청의 범위 밖에서 계속 유지합니다.

## 진행 상태

수정·검사 중이며 아직 새 APK나 서명 OTA를 배포하지 않았습니다. 반복된 클라우드 환경 교체로 이전 미커밋 파일·검사 원본이 소실되었습니다. 재현 요약은 맥락으로 보존하되 최종 통과 증거는 현재 소스에서 다시 수집합니다. 작업 브랜치 `codex/qa-after10-175`에 소스와 검사 도구를 보존하며 공개 게임 채널은 최종 검사·서명·공개 다운로드 확인이 끝날 때까지 유지합니다.

## 재현되어 수정하는 문제

- 공격·수호 부적의 능력 보정이 경험치 획득 때 사라지지만 다음 전장에는 사용 플래그가 남는 문제.
- 신규 테오가 활잡이인데 근접 사거리로 생성되어 인접 공격에 반격하고 2칸 반격을 못하는 문제. 루카 등 동료의 현재 직업과 구형 생성 정보도 확인합니다.
- 쓰러진 아군이 생존 명단에서 빠지면서 전원 생존·전선 유지·S 등급을 잘못 인정하는 보상 문제와 적이 남아 있어도 소탕 보너스를 지급하는 문제.
- 비살상·지원 스킬 성공 후 해당 아군이 쓰러지면 전직 숙련이 사라지는 문제.
- 과거·가져오기 저장의 적 턴을 복원하면 적 행동이 재개되지 않아 멈추는 문제.
- 전장 배치 제목에 장 번호를 두 번 표시하는 문제.

각 장의 저장 시나리오에서 원래 적 HP를 유지한 실제 UI 이동·공격·스킬·적 턴을 검사합니다. 승패 정산과 합류·진행 검사는 별도의 종료 저장 시나리오로 구분합니다. 이러한 검사는 1장부터 50장까지 무중단으로 자연 클리어했다는 의미가 아닙니다. 브라우저 모바일 크기 검사와 Android 실기기 검사를 구분합니다.

최종 장별 결과·직접 검사·기존 Actions 자동 검사·새 APK와 서명 OTA 정보는 완료 후 이 문서와 BUILD 문서에 기록합니다.
