## 재현되어 수정하는 문제

- 공격·수호 부적의 능력 보정이 경험치 획득 때 사라지지만 다음 전장에는 사용 플래그가 남는 문제.
- 신규 테오가 활잡이인데 근접 사거리로 생성되어 인접 공격에 반격하고 2칸 반격을 못하는 문제. 루카 등 동료의 현재 직업과 구형 생성 정보도 확인합니다.
- 쓰러진 아군이 생존 명단에서 빠지면서 전원 생존·전선 유지·S 등급을 잘못 인정하는 보상 문제와 적이 남아 있어도 소탕 보너스를 지급하는 문제.
- 비살상·지원 스킬 성공 후 해당 아군이 쓰러지면 전직 숙련이 사라지는 문제.
- 과거·가져오기 저장의 적 턴을 복원하면 적 행동이 재개되지 않아 멈추는 문제.
- 전장 배치 제목에 장 번호를 두 번 표시하는 문제.
- 마레와 실반이 모두 검으로 분류되어 창·마법 상성과 무기 표시가 잘못되는 문제. 마레는 창, 실반은 마법으로 수정했습니다.

## 검사 증거의 구분

각 장의 저장 시나리오에서 원래 적 HP를 유지한 실제 UI 이동·공격·스킬·적 턴을 검사합니다. 승패 정산과 합류·진행 검사는 별도의 종료 저장 시나리오로 구분합니다. 이러한 검사는 1장부터 50장까지 무중단으로 자연 클리어했다는 의미가 아닙니다. 브라우저 모바일 크기 검사와 Android 실기기 검사를 구분합니다.
