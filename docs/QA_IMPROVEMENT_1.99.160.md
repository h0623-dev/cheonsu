# 1.99.160 전투 전 배치와 QA 상태

기록일: 2026-10-05. 대상 버전 **1.99.160 / Android359**입니다. 사용자는 전투 전에 배치할 수 있는 위치를 표시하고, 보유 캐릭터를 선택해 원하는 칸에 놓을 수 있는 단계를 요청했습니다.

## 동작

1. 원정에서 전장을 선택하면 전투 준비 단계에 진입합니다. 보유한 캐릭터와 실제 전장 지형, 배치 가능한 아군 진입 구역을 표시합니다.
2. 캐릭터를 선택한 뒤 표시된 칸을 누르면 배치하거나 위치를 옮깁니다. 이미 놓인 아군끼리는 자리를 교환할 수 있습니다. 아직 놓이지 않은 캐릭터를 아군이 점유한 칸에 추가하려면 먼저 빈 칸을 선택해야 합니다.
3. 출전 인원은 최대 15명이며 카일의 필수 출전 규칙을 유지합니다. 배치 해제로 출전을 제외하거나 자동 배치로 위치를 다시 정할 수 있습니다. 보유하지 않은 캐릭터와 적은 출전 대상으로 선택하지 않습니다.
4. 배치와 출전 인원을 확인한 뒤 `전투 시작`을 누르면 기존 도입 대화를 거쳐 전투로 들어갑니다. 도입 대화를 건너뛰어도 선택한 좌표가 유지되어야 합니다.

배치 구역은 아군 진입 방향에 따른 연결된 땅을 사용합니다. 막힌 지형·위험한 칸·적과 너무 가까운 칸은 제외합니다. 실제 출전 인원에 따라 생성되는 전장과 적의 최종 위치를 기준으로 배치 가능 칸을 계산하므로, 미리보기와 전투 시작에 서로 다른 적 배치를 사용하지 않습니다.

휴대폰에서는 캐릭터 카드와 배치 칸을 눌러 조작하며, 전장 내부를 가로·세로로 스크롤합니다. 전투 시작 전 배치 이동은 전투 턴이나 행동을 소모하지 않습니다. 캐릭터의 기존 대기 이미지를 사용하며 신규 원화를 제작하는 변경이 아닙니다.

## 저장과 이어하기

준비 화면에서 저장하면 선택한 장과 출전 인원, 수동 배치 좌표를 함께 저장하도록 연결합니다. 오래된 저장에 배치 준비 정보가 없으면 기존 자동 배치에서 시작합니다. 잘못된 좌표·중복 위치·미보유 캐릭터는 실제 전장의 유효한 배치로 보정합니다.

진행 중인 전투를 이어할 때는 저장된 지형·유닛·좌표·턴·행동 상태를 그대로 사용합니다. 새 배치 화면 때문에 기존 전투를 다시 생성하거나 아군과 적을 재배치하지 않습니다. 성장·장비·진행·골드·아이템·수집과 원복 기준 **1.99.154**를 보존합니다. [기본 원복 기준](ROLLBACK_BASELINE.md).
