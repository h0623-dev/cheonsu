# 1.99.147 전투 연출 및 기술명 정비

## 적용 내용

- 기본 공격: 검/창/도끼/방패/단검/야수/채찍/권격/활/포격/마법 11종 준비·접근·반동·복귀 동작. 피격·회피·처치도 같은 시간축으로 제어합니다.
- 아군 17명, 기술 34개에 새 전용 전신 자세 34개와 각각 다른 동선/효과를 연결했습니다. 이동한 그림 하나를 기울이는 방식만 사용하지 않고 기존 달리기/준비/회복 자세와 새 기술 자세를 교체합니다.
- 추가 습득 기술 4개도 별도 연출. 총 38개 기술의 동선과 효과 구성이 서로 다릅니다. 적 19종과 보스 5종은 무기·역할에 맞춘 기술 연출을 적용하고 기존 전투 이미지를 유지합니다.
- 화살은 발사부터 도착까지 이동, 창은 긴 관통 궤적, 검은 베기, 도끼는 내려찍기와 지면 균열, 치유는 광선/깃털/입자, 류트는 음표/음파, 빙결은 창/파동으로 구별합니다. 공통 장판 중심 연출은 제거했습니다.
- 삼연사·낙뢰 사슬·백호권 등은 여러 시각적 접촉과 반동을 표현하되 실제 피해 계산과 행동 소모는 기존 한 번을 유지합니다. 화면 체력은 마지막 타격에서 갱신합니다.
- 화면 흔들림/효과 끄기, 시스템 동작 줄이기, 1/2/3배속을 유지합니다. 스킬은 준비 동작을 볼 수 있도록 기본 공격보다 긴 시간 배율을 사용합니다.

## 명칭과 저장

- 기술 이름의 기준은 `CHARACTER_SKILLS`와 `DISCOVERY_TECHNIQUES`입니다. 스테이지 아군 초기값, 영입, 기존 저장의 파티 정규화, 강화·편성·정보 UI와 전투 컷인을 같은 기준으로 표시합니다. 강화 설명과 공격/회복/수호 분류도 과거 저장의 직업 필드 대신 현재 기술 정의를 따릅니다.
- 리나: 불꽃 화살 / 정밀 사격, 습득 기술 불사조 화살. 과거 `파이어볼` 표기는 복원 때 바로잡습니다.
- 테오: 삼연사 / 관통 화살. 레온: 관통 찌르기 / 질풍 돌격. 엘라: 치유의 선율 / 공명 파동. 진: 용염참 / 월광참. 세라: 암영 베기 / 빈틈 가르기.
- 기술 ID, 습득 ID, 쿨다운, 피해·사거리·대상 선택 규칙, 행동 횟수, 스테이지 진행, 성장·장비는 변경하지 않습니다. 저장을 초기화하지 않습니다.

## 구현 위치

- `src/data/duelChoreography.js`: 38개 기술 및 11개 기본 무기 시간표, 그림 선택, 접촉/음향 큐.
- `src/engine/useDuelAnimation.js`: Web Animations API, 반응형 좌표, 피격/회피, 취소 및 해제 처리.
- `src/components/DuelEffects.jsx`, `skill-presentation.css`: 궤적, 투사체, 보조술과 컷인.
- `public/art/skills-v1`: 게임용 자세. `docs/art/skills-v1`: 원본/참조/제작 기록.
- 기존 `combat-scene.css`의 장면 크기와 프레임 배치는 유지하고 새 연출 클래스에서 과거 CSS 동작을 비활성화합니다.
