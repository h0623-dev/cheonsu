# 천수 1.99.184 / Android 383 · 전투 간격과 자세별 신체 비율

2026-10-17 KST. 전투에서 양쪽이 너무 가깝고 준비 때 작다가 타격할 때 확대되는 사용자 신고를 보완합니다. 현재 제작·배포 진행 중입니다. 이전183의 자동 통과와 공개를 이번 문제 해결의 근거로 대신하지 않습니다.

## 원인과 구현

1. 일반 양쪽46%(휴대폰49%) 프레임을 좌우8~10%에 놓아 프레임 자체가 겹치고, 전신 배치기는 신체 간 최소 대기 거리를 확보하지 않았습니다. 새 준비 몸 구간은 무기·긴 망토·날개·꼬리를 제외합니다. 최종 화면에서 근접14%·원거리23%·지원18%의 폭을 몸 사이에 예약하고, 전체 실루엣/무기/잔상으로 공통 축소한 뒤에도 같은 간격이 남도록 홈 위치를 계산합니다. 보스의 상대 체격 비율은 유지합니다.
2. 긴 무기에는 접근량이 음수인 홈 위치가 가능했습니다. 무기 끝과 실제 상대 접점을 기준으로 홈 거리를 추가 확보하여 공격할 때 앞으로 접근하고 원위치로 복귀하게 합니다. 기존 접촉·타격 정지·피해·지원·완료 시계는 보존합니다.
3. B안 제조의 `bodyHeight` 정규화는 웅크리거나 무릎을 굽힌 자세까지 선 자세의 키로 키워 두개골·몸통이 커졌습니다. 원본 PNG에 같은 두개골/중심기관 축을 수동 근사 저작하고, 기존 제작 배치 변환으로 실제512원화 공간의 길이를 계산해 **기본67종 새3자세와 아군21명의 기존skill-b** 표시 비율을 맞춥니다. 선 키·무기 포함 전체 외곽을 새 확대 기준으로 사용하지 않습니다.
4. 신체 보정은 원본 조회API·manifest·원화·앵커를 바꾸지 않는 결투 전용 층입니다. 이미지·발 정렬·기술별 원화·무기 효과·접점 투영·전체 실루엣 배치가 같은 보정 배율을 사용합니다. 기본형 근접기술의 타격 직전 불필요한 중간스킬자세 삽입과 공격자의 몸 전체 늘리기/줄이기도 제거합니다. 회전·이동·발디딤과 실제 타격 자세는 이어집니다.
5. 효과 끄기·동작 줄이기에서도 정적 신체 배치를 먼저 실행하고 애니메이션만 생략합니다.

원본 입력은 `docs/art/style-b-v1/body-input-184-*.json`, 제작기는 `scripts/prepare-combat-proportions.mjs`, 런타임 데이터/계산은 `src/data/combatBodyProportions.*`입니다. 저작 좌표는 기존 생성 PNG의 동일 신체 부위를 보고 잡은 **수동 근삿값**이며 정밀 실측·게임 출력 QA 결과가 아닙니다. 완성 WebP를 다시 열거나 재인코딩하지 않습니다. 전직65형태의 독립 원화는 보존하며 대기 간격의 공통 규칙을 적용합니다. 실제 직원100명 고용이나 인력 QA팀을 운영한 결과가 아닌 AI 작업 역할 분담입니다.
