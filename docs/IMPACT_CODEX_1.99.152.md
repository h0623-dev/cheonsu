# 1.99.152 전투 타격 및 캐릭터 도감

## 전투 연출

- 적용 범위: 아군 17명, 일반 적 19종, 보스 5종의 일반 공격과 공격 기술. 아군 기본 기술 34개와 습득 기술 4개, 적 기술 및 반격에도 같은 재생 경로를 적용합니다.
- 준비 자세, 접근 시 교차 발 디딤, 무기 준비, 실제 발사/타격 자세, 반동, 방어적으로 물러나는 복귀를 분리했습니다. 연속 기술은 각 발사 사이에 다시 준비 자세를 취하며, 각 접촉에서 적 피격 자세와 반응을 표시합니다.
- 기존 2D 전신 자세와 기술 원화를 사용합니다. 그림 하나의 평행 이동만 추가한 것이 아니며, 새로운 3D 모델이나 다관절 스켈레톤 애니메이션을 제작한 것은 아닙니다.
- 자세별 그림 전체 높이를 동일하게 맞추던 보정을 제거했습니다. 원화 행의 공통 몸 크기를 유지하고 발 위치만 맞춰 무기를 높이 들 때 몸이 작아지는 현상을 줄였습니다. 대기 기준 아군/적 크기 정규화와 야수 비율은 유지합니다.
- 실제 화면 폭과 양쪽 캐릭터 간격으로 근접 거리를 구합니다. 타격 시 짧은 접촉 정지, 속성/무기별 섬광, 방사 파편, 충격파, 피격 밝기 변화, 발 디딤 먼지를 추가합니다.
- 여러 번 보이는 타격은 시각적 표현입니다. 피해량, 체력 정산 시점, 경험치, 반격, 사거리, 쿨다운, 행동 1회 소모는 변경하지 않습니다.
- 1/2/3배속, 효과/흔들림 설정, 동작 줄이기를 유지합니다. 화면 변경과 컴포넌트 해제 시 애니메이션을 정리합니다.

## 도감

- 타이틀의 도감 버튼 또는 기록실 > 도감·기록 > 도감에서 엽니다. 동료 17명, 일반 적 19종, 보스 5종을 모두 표시합니다.
- 최초 동료 4명은 컬러입니다. 나머지는 파티 보유 또는 해당 영입 장의 정확한 클리어 기록으로 컬러 해금합니다. 가장 뒤쪽 완료 장만 보고 중간 동료를 모두 해금하지 않습니다.
- 적과 보스는 현재 전장 미리보기의 실제 정체성과 클리어 기록으로 조사 완료합니다. 편성 변경으로 현재 전장에 없는 옛 병종은 원래 전장의 완료 시 옛 기록으로 복원합니다. 전투 늑대는 6장 옛 전장 기록입니다. 전투 배치나 난이도는 변경하지 않습니다.
- 미수집 그림은 물음표 대신 흑백으로 표시합니다. 카드와 상세창 모두 같은 상태를 사용하며 미수집 인물의 전기/기술 상세는 열지 않습니다.
- 이름/역할 검색, 수집 상태 필터, 동료/적군/보스/지역·시스템 분류, 수집률, 인물 상세와 기술/영입 조건, 이전/다음 인물, 닫기와 뒤로가기를 제공합니다. 기존 포토 진입을 보존합니다.
- 기존 저장의 파티/클리어 기록에서 계산하는 읽기 전용 기능이며 도감 열람은 저장을 쓰거나 보상을 지급하지 않습니다. 도감용 별도 저장 필드 없이 1.99.148~151 저장에 적용됩니다.

## 구현과 배포

- `src/data/duelPerformance.js`: 무기 준비/타격 시간표, 몸 동작, 접촉 정지, 파편 값.
- `src/engine/useDuelAnimation.js`, `DuelImpacts.jsx`: 동작/그림/피격/파편 재생과 정리.
- `src/data/characterCollection.js`, `CharacterCodex.jsx`: 영입 규칙과 읽기 전용 도감. `RECRUIT_BY_STAGE`는 게임 영입과 도감이 공통으로 참조합니다.
- Android 351 / API 36. 네이티브 지문은 1.99.151과 같아 APK 350~351에 서명 OTA를 제공합니다. Google 로그인은 여전히 프로젝트 미연결 상태입니다.
- "원복"은 여전히 1.99.148 / `f556e33e113b7f15b1fc1f515a201beded9a1aeb`를 뜻합니다. 공용 Git 이력을 강제 되돌리지 않습니다.
- 최종 검사와 산출물 해시는 `BUILD_1.99.152.md`를 참조하세요. 실제 Android 기기 설치/터치/체감 프레임과 스피커 청음은 별도 검증이 필요합니다.
