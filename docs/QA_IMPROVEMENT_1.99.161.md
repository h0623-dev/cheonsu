# 1.99.161 미션 실패 이후 흐름과 QA 상태

기록일: 2026-10-05. 대상 버전 **1.99.161 / Android360**입니다.

## 작업 범위

미션 실패 뒤의 처리를 정리하고 적의 스테이지별 HP와 숫자 레벨 처리를 확인합니다. 아래 실패 결과 보호 정책은 확정했으며 구현과 최종 검사는 진행 중입니다.

1. 미션 실패는 `lastBattleResult`로 저장합니다. 실패 뒤에는 훈련소와 성장 화면의 훈련 버튼, 실제 훈련 처리 모두를 차단합니다. 초기1회와 정상 승리 정산 후1회라는 기존 훈련 기회는 유지하며 실패로 추가 훈련 기회를 만들지 않습니다. 회복·장비 관리와 기존 경험치·수집 데이터는 유지합니다.
2. 철수 결과를 자동 저장하고 이전 저장 백업을 보존합니다. 구버전 저장의 정확한 철수 문구는 읽어서 실패 결과로 이어받으며 원본을 임의로 덮어쓰거나 기존 데이터를 삭제하지 않습니다. 구160에서 패배 뒤 원정으로 나갔다가 마을로 저장한 경로도 읽기 전용으로 이관합니다.
3. 실패 뒤 출전 준비는 실패한 장의 재도전으로 연결합니다. 이미 완료한 장과 해금된 전장의 기록을 낮추지 않습니다.
4. 보상 정산과 다음 장 해금은 실제 승리 결과를 확인한 경우에만 진행합니다. 실패·철수를 승리로 처리하여 보상이나 해금이 발생하지 않도록 보호합니다.

## 적의 성장 단계와 정보 표시

적의 HP·공격·방어는 기존부터 스테이지·종족·난이도·밸런스에 따라 보정됩니다. 이번에는 이 수치를 중복 강화하지 않고 누락된 숫자 레벨을 신규 생성에 부여합니다.

| 종류 | 레벨 계산 | 1~30장 범위 |
| --- | --- | --- |
| 일반 적 | `1 + floor((장 - 1) / 2)` | 1~15 |
| 정예 적 | 일반 레벨+1 | 2~16 |
| 보스 | 일반 레벨+2 | 3~17 |

아군의 기존 레벨업 HP+2와 적의 기존 장별 HP 증가를 참고한 성장 단계 표시입니다. 레벨만으로 HP를 다시 계산하지 않으며 같은 레벨이라도 종족·난이도·밸런스에 따라 HP가 다릅니다. 기본 적·추가 적·보스·증원을 새로 생성할 때만 적용합니다. 이미 진행 중인 저장 전투의 적 능력치·레벨·좌표·행동 상태를 이번 변경으로 재산정하지 않습니다.

출전 전 전장 정보에서 보스 HP·공격 표기를 현재 난이도로 계산한 실제 출전 전장의 유닛 수치에 맞추고 레벨을 함께 표시합니다. PC·휴대폰 전투의 적 정보에도 레벨을 표시합니다.
