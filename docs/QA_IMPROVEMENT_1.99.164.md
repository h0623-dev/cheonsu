# 천수 1.99.164 전장 배치 개선·검증 구분

게임 1.99.164 / Android 363. 작성일: 2026-10-06 KST.

작은 전투 준비 화면에서 배치 위치를 읽기 어렵고 아군 진영의 넓은 구역을 선택할 수 있던 문제를 수정하는 작업입니다. **사용자 지시에 따라 수정 후 별도 검증은 실행하지 않았습니다.** 이번 문서는 구현 범위와 자동 Actions 결과를 구분하며, 직접 QA 통과 보고서가 아닙니다.

## 전투에 들어가는 순서

1. 원정 지도나 대기실에서 스테이지에 진입합니다.
2. 해당 스테이지의 이야기 컷신을 진행합니다.
3. 실제 전장에서 승리·패배 미션과 시작 연출을 확인합니다.
4. 전장에 표시한 허용 칸에서 보유 캐릭터를 배치합니다.
5. 배치를 확정하면 첫 아군 턴이 시작됩니다.

배치 확정 뒤 같은 이야기 컷신을 다시 재생하지 않습니다. 편성 관리 기능은 필요할 때 별도로 열 수 있게 유지합니다. 새 전투 진입에만 이 순서를 적용하며 진행 중 전투 이어하기를 처음부터 다시 시작하지 않습니다.

## 배치 화면과 허용 칸

- 배치에 실제 전장과 캐릭터 표시를 사용하고 지도 확대·이동을 제공합니다. 보유 캐릭터를 선택한 뒤 표시된 칸을 눌러 배치하거나 이동합니다.
- 초기 아군 위치와 후방 중심의 최대 18칸을 허용합니다. 최대 출전 인원 15명과 주인공 필수 출전을 유지합니다.
- 아군 진영 전체를 배치 구역으로 열지 않습니다. 적과의 간격, 연결된 안전 지형, 회복·강화·위험 칸 제외 정책을 유지합니다.
- 이미 아군이 있는 허용 칸을 고르면 자리 교환을 지원합니다. 배치 해제·자동 배치·준비 상태 저장도 제공합니다.
- 이야기·미션·시작 연출이 진행되는 동안 배치 조작이나 전투 확정이 겹치지 않게 합니다.
