# 1.99.140 전장과 사운드 패치

## 화면과 저장

- 전투 시작/이어하기의 기본 상태는 정보 숨김입니다. `정보 표시`로 목표·설정·배율 조절을 다시 엽니다. 저장과 행동 버튼은 계속 표시됩니다.
- 넓은 화면에서는 전장 폭을 최대 1,120px까지 사용합니다. 휴대폰에서는 화면 폭 안에서 가로/세로로 전장을 스크롤합니다. 기본 배율 130%, 기본 2배속은 유지합니다.
- 신규 전장은 `terrainRevision: 3`입니다. 이전에 저장한 전투의 맵·위치·행동·탐색 진행을 다시 생성하지 않습니다. 새 전투 입장부터 변경 맵을 사용합니다.
- 작은 맵에 예전의 최소 26행을 강제로 덧붙이던 렌더링 경로를 분리했습니다.

## 사운드

외부 음원 없이 Web Audio로 연주하는 원곡입니다. 실제 관현악 녹음은 아니며, 배음·볼륨 곡선·비브라토·좌우 배치로 관악, 현악, 하프, 벨, 베이스, 타악 음색을 구성합니다.

- BGM 9종: 여명의 길, 별빛 아래의 쉼, 국경의 깃발, 숲의 속삭임, 성벽을 넘어, 눈 속의 서약, 황혼의 회랑, 지휘관의 결의, 천수의 마지막 빛.
- 곡마다 32마디, 약 60~107초. 주제·응답·차분한 중간부·재현부의 4구간, 화음·베이스·선율·분산화음·리듬. 장별 조성 변형과 6장 단위 보스/최종장 전용곡.
- 효과음 35종: 발걸음, 활, 검, 창, 중량 타격, 반격, 불/얼음/번개/치유/그림자 마법, 장착·아이템·저장·승리·패배 등.
- 주기파·노이즈 버퍼를 재사용하며, BGM은 짧은 구간만 미리 예약합니다. 별도 대형 음원 다운로드를 추가하지 않았습니다.
- 음악 끄기는 BGM만 정지. 전체 음소거·0%·앱 비활성화는 효과음까지 정지. 저장된 볼륨 설정은 유지합니다.

## 검증 방법

- `npm test`: 전체 회귀, 신규 30장 크기·연결·방향·증원, 최대 17명 배치·탐색 접근성, 구형 저장 유지, 음악 4구간/반복.
- `node scripts/verify-chapter-maps.mjs`: 실제 UI로 30장 진입, 휴대폰 대표 7장, 이미지·카메라·숨김 기본값·스크롤 후 저장 불변.
- `node scripts/verify-score-render.mjs`: 개발 서버에서 9곡 전체와 효과음 35종을 OfflineAudioContext로 렌더링해 비정상 샘플·무음·클리핑 검사.
- `node scripts/verify-audio-lifecycle.cjs`: 음악/전체 음소거, 백그라운드 전환과 재개, 예약 음원 정리.
- 전투 버튼, 사거리, 아이템 취소, 저장과 시스템 내비게이션 겹침, 터치/마우스 이동 회귀.
