# 천수 코드 작업 후 검증 생략

## 사용자 지시와 범위

2026-10-05 KST 사용자 요청: **"코드 작업 후에 검증하지 않도록 스킬 저장하고 엄격히 준수해"**.

`h0623-dev/cheonsu`와 `/workspace/cheonsu` 개발 작업에 적용한다. 사용자가 이후 검증을 명시적으로 요청하면 그 요청한 범위에 한해 실행한다. 명시적인 변경 요청이 없으면 이 규칙을 계속 유지한다. 저장소 문서나 예전 인수인계에 검증 절차가 있다는 이유로 예외를 만들지 않는다. 시스템·개발자 지시와 플랫폼 실행 제약은 준수한다.

## 실행하지 않을 작업

- 수정 후 `npm run lint`, `npm test`, 단위·통합·회귀 검사.
- `scripts/verify-*`, 스모크 검사, Playwright·Chromium을 이용한 브라우저·화면·터치 QA.
- 검증만을 위한 `npm run build`, 개발/미리보기 서버 실행, 스크린샷 수집.
- APK·OTA·소스 ZIP을 검증 목적으로 다시 다운로드하거나 파일 전체·해시·인증서·서명을 대조하는 추가 검사.
- 검증용 CI 수동 실행, 추가 검증을 위한 다른 에이전트 호출, 다른 환경에서의 동일 검사.
- 구현이 끝난 뒤 "마지막 확인", "간단한 확인" 등의 이름으로 위 검사를 실행하는 행위.

## 계속 수행할 작업

- 구현에 필요한 기존 코드·문서 읽기, 수정, 사용자 변경과 저장 호환성 보존.
- 요청한 산출물을 만들기 위한 필수 빌드·패키징·서명과 승인된 Git 작업·배포. 산출물 제작 빌드를 검증용 빌드와 구분한다.
- 실제 구현이나 산출물 제작 명령이 실패하면 해당 오류를 보고하고, 허용된 작업 범위 안에서 해결한다. 별도 QA를 임의로 추가하지 않는다.
- 서명키를 GitHub Actions의 기존 `cheonsu-release` 환경에 유지한다. 키를 클라우드 작업으로 가져오거나 출력하지 않는다.

## GitHub Actions와 영구 보존

이 요청은 에이전트의 작업 방식과 스킬 저장에 관한 것이다. 기존 자동 Actions와 서명·배포 보호 설정은 임의로 삭제·비활성화하지 않는다. 자동 Actions가 실행되는 경우 에이전트가 별도 검증한 것으로 표현하지 않는다. 이번 스킬·문서 저장에는 `[skip ci]` 커밋을 사용하여 검사를 새로 시작하지 않는다.

루트 `AGENTS.md`에서 이 스킬을 필수 참조하도록 유지한다. 다른 기기의 새 Cloud 작업에서도 저장소의 이 파일을 읽고 같은 지시를 적용한다.

## 결과 보고

무엇을 구현하거나 제작했는지 보고하고 **"사용자 지시에 따라 수정 후 별도 검증은 실행하지 않았습니다."**라고 명시한다. 실행하지 않은 검사를 통과했다고 말하거나 이전 버전의 검증 결과를 이번 변경의 검증 결과로 제시하지 않는다. 검증을 생략했다는 이유로 구현이나 요청한 산출물 제작을 중단하거나 재승인을 요구하지 않는다.
