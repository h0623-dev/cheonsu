## 과거 버전 1.99.163 기록

이 절의 공개 파일·검사 수치·해시는 **1.99.163 당시의 기록**입니다. 1.99.164 변경이나 새 배포 결과를 나타내지 않습니다.

**직전 공개 버전: 1.99.163 / Android 362.** 50장 확장과 로컬 게임 QA를 완료해 main에 반영했습니다. 새 APK·서명 OTA·소스 ZIP 발행과 실제 공개 다운로드·서명·전체 파일 대조를 완료했습니다.

기존 30장 결말을 보존하며 캠페인을 50장·9막으로 확장했습니다. 해안 침수 유적·백설 고원·지하 공명 공방·별빛 봉인지에 새 전장 20개와 전투 전후 장면 40개를 추가했습니다. 새 동료 마레·하린·에단·실반은 32·37·42·47장 첫 승리 후 전용 무기와 함께 합류하며, 보유 21명·출전 최대 15명을 지원합니다. 새 적 12종·지역 보스 4종과 21인 각 두 분기의 최상위 전직 42종, 새 지형·지역 음악·50장 기념 방어구를 실제 전투와 보상에 연결했습니다.

새 외형의 무기와 효과 위치를 최종 원화에 맞췄고, 채찍 접촉 위치·책 무기 종류 표시·작은 세로 화면의 동료 지원 창끝 잘림을 수정했습니다. 기존 성장·장비·수집·저장과 진행 중인 전투를 보존합니다. 자세한 구현·검증 범위는 [빌드·배포 기록](docs/BUILD_1.99.163.md)과 [QA 개선 기록](docs/QA_IMPROVEMENT_1.99.163.md)을 확인하세요.

## 다른 PC에서 시작

Node.js 24를 설치한 뒤, 개발 통합 ZIP을 풀고 `package.json`이 있는 폴더에서 실행합니다.

```sh
npm ci
npm run setup
npm run dev -- --host 127.0.0.1
```

터미널에 표시되는 주소를 엽니다. 소스와 게임 이미지는 모두 포함되어 있어 이미지 생성 도구나 API 키가 없어도 개발할 수 있습니다.

## 검사와 APK

```sh
npm test
npm run build
npm run android:apk
```

APK 빌드는 Android Studio, SDK Platform 36, JDK 21 이상이 추가로 필요합니다. 마지막 명령이 웹 빌드, Capacitor 동기화, Android 빌드를 순서대로 처리합니다.

결과: `android/app/build/outputs/apk/debug/app-debug.apk`
